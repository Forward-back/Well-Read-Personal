# 调用示例

本文给出个人版只读 MCP 的典型流程。工具参数全集见[工具参考](工具参考.md)；不同客户端的调用格式可能不同，这里用“工具名 + JSON 参数”表达语义。

个人版只有一个只读 Key：MCP 只暴露 17 个只读工具，包括检索、问答、读取 Agent、读取会话与分块，以及清理自建会话的 `delete_session`。写入、删除文档、建库、模型管理、租户与共享空间工具已从 MCP 删除；需要入库或管理知识库时使用 WellRead 前端。

## 1. 发现可用知识库

```text
list_knowledge_bases()
```

返回示例：

```json
{
  "success": true,
  "data": [
    {"id": "e2e3214b-...", "name": "示例知识库", "type": "document"}
  ]
}
```

确认 `id` 后，后续调用优先传 UUID，避免名称重名。

## 2. 混合检索

```text
hybrid_search(
  kb_id="e2e3214b-...",
  query="报销流程",
  vector_threshold=0.5,
  keyword_threshold=0.3,
  match_count=5
)
```

适合快速检索和调试；不需要创建会话，不产生 LLM 答案。

## 3. RAG 问答

```text
create_session(kb_id="e2e3214b-...", title="知识问答")
```

返回 `data.id` 作为 `session_id`，然后：

```text
chat(
  session_id="<session-id>",
  query="这份知识库主要讲什么？",
  knowledge_base_ids=["e2e3214b-..."]
)
```

返回：

```json
{
  "answer": "...",
  "references": [...],
  "_debug_events": [...],
  "session_id": "<session-id>"
}
```

`chat` 不传 `knowledge_base_ids` 时只能依赖模型自身知识，通常不是预期行为。流程结束后可调用 `delete_session(session_id=...)` 清理自建会话；这是工具面唯一的会话管理写操作。

## 4. Agent 多步问答

```text
list_agents()
get_agent(agent_id="<agent-id>")
create_session(kb_id="e2e3214b-...", title="Agent 会话")
agent_chat(
  session_id="<session-id>",
  query="对比两份文档的差异",
  agent_id="<agent-id>",
  knowledge_base_ids=["e2e3214b-..."]
)
```

Agent 配置为 `kb_selection_mode=none` 或 `selected` 且无内置 KB 时，不传 `knowledge_base_ids` 会失败。先用 `get_agent` 检查。

## 5. Gaze 页面

仅适用于 Gaze-enabled KB：

```text
gaze_index_view(kb_id="<gaze-kb-id>", limit=50)
gaze_search(kb_id="<gaze-kb-id>", query="实体关系", limit=10)
gaze_read_page(kb_id="<gaze-kb-id>", slug="entity/acme-corp")
```

普通 document KB 返回 400；改用 `hybrid_search`/`chat`。

## 6. 错误处理

- **400**：参数或 KB 类型不对；检查 `query` 与 Gaze KB 类型。
- **403**：调用了写工具，或 Key 已失效；改用只读流程，或在设置页重置 Key。
- **404**：ID 不存在，或调用了共享空间/租户工具；重新 `list_*` 确认。
- **超时**：`chat`/`agent_chat` 可增大 `WELLREAD_CHAT_TIMEOUT`；不要在超时后立即重复提交长任务。
- **网络错误**：检查 `WELLREAD_BASE_URL` 是否指向后端 API 根路径，而不是前端地址。

## 7. 安全建议

- 只读 Key 明文只显示一次，不要写进仓库或共享客户端配置。
- 网络传输必须设置 `MCP_SERVER_AUTH_TOKEN`；本机单用户优先 stdio。
- 需要入库、删除或调整模型时使用前端界面，不要为 MCP 设计写自动化。
