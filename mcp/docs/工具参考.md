# 工具参考

本文是个人版 MCP Server 的完整工具目录，共 17 个只读工具。工具名即 MCP 客户端看到的名称；参数使用 Python 类型标注生成 JSON Schema。

## 1. 通用约定

- **只读 Key**：个人版只有一个只读 Key（检索、问答、读取 Agent、会话历史）。不提供写入、删除、建库、模型管理、租户或共享空间工具。
- **KB 标识**：`kb_id` 参数同时接受 UUID 和知识库名称；名称解析失败或重名时优先使用 UUID。
- **分页**：`page` 从 1 开始，`page_size` 默认 20；返回结构由后端决定。
- **返回**：除 `chat`/`agent_chat` 外，工具返回后端 JSON 响应；`chat` 返回 `{answer, references, _debug_events, session_id}`。
- **错误**：后端 4xx/5xx 会以 `requests.HTTPError` 抛出；参数错误通常是 400，权限不足是 403，资源不存在是 404。

## 2. 知识库与内容

| 工具 | 签名 | 用途 |
|---|---|---|
| `list_knowledge_bases` | `()` | 列出知识库 |
| `get_knowledge_base` | `(kb_id)` | KB 详情；可传 UUID 或名称 |
| `hybrid_search` | `(kb_id, query, vector_threshold=0.5, keyword_threshold=0.3, match_count=5)` | 向量 + 关键词混合检索 |
| `list_knowledge` | `(kb_id, page=1, page_size=20)` | 列出 KB 文档 |
| `get_knowledge` | `(knowledge_id)` | 文档详情 |
| `list_chunks` | `(knowledge_id, page=1, page_size=20)` | 列出文档分块 |

## 3. 会话与问答

| 工具 | 签名 | 用途 |
|---|---|---|
| `create_session` | `(kb_id, max_rounds=5, enable_rewrite=True, fallback_response='Sorry, I cannot answer this question.', summary_model_id='', title='', description='')` | 创建绑定 KB 的会话 |
| `get_session` | `(session_id)` | 会话详情 |
| `list_sessions` | `(page=1, page_size=20)` | 列出会话 |
| `delete_session` | `(session_id)` | 删除自己创建的会话；`chat` 能力允许的会话管理操作 |
| `chat` | `(session_id, query, knowledge_base_ids=None, web_search_enabled=False)` | RAG 问答，返回答案与引用 |
| `agent_chat` | `(session_id, query, agent_id, knowledge_base_ids=None, web_search_enabled=False)` | Agent 多步问答 |

`chat` 需要先创建会话；建议始终传 `knowledge_base_ids`。`agent_chat` 的 `agent_id` 必填；Agent 的 `kb_selection_mode` 为 `none` 或 `selected` 且内置 KB 为空时，必须显式传 KB。

## 4. Agent

| 工具 | 签名 | 用途 |
|---|---|---|
| `list_agents` | `(page=1, page_size=50)` | 列出 Agent |
| `get_agent` | `(agent_id)` | 查看 `kb_selection_mode` 与内置 KB |

## 5. Gaze 页面

| 工具 | 签名 | 用途 |
|---|---|---|
| `gaze_search` | `(kb_id, query, limit=10)` | Gaze 页面全文检索 |
| `gaze_read_page` | `(kb_id, slug)` | 按 slug 读取页面 |
| `gaze_index_view` | `(kb_id, limit=50)` | 按类型读取页面索引 |

Gaze 工具只适用于 Gaze-enabled KB；普通 document KB 返回 400，改用 `hybrid_search` 或 `chat`。

## 6. 错误排查

| 现象 | 常见原因 | 处理 |
|---|---|---|
| 400 `query_text is required` | 检索参数为空 | 传非空 `query` |
| 400 Gaze 相关 | KB 不是 Gaze-enabled | 改用普通 KB 工具 |
| 401 | Key 无效或已重置 | 在设置页重新生成并更新 `WELLREAD_API_KEY` |
| 403 | Key 已失效 | 设置页重置 Key |
| 404 | KB/文档/会话 ID 不存在 | 先 `list_*` 确认 ID |
| 超时 | `chat` LLM/检索慢 | 调大 `WELLREAD_CHAT_TIMEOUT` |
