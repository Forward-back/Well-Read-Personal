# useAnimations 资产来源

- 上游：[useAnimations/react-useanimations](https://github.com/useAnimations/react-useanimations)

- 使用方式：仅提取 `lib/*.mjs` 中的 Lottie `animationData`；本项目不安装或运行 React 组件。
