Files: hand-drawn style animated GIFs: `calendar.gif`, `checklist.gif`, `book.gif`, `clock.gif`, `goal.gif`, `fire.gif`, `rocket.gif`, `brain.gif`, `chart.gif`, `trophy.gif`, `sparkles.gif`. Palette is ink/charcoal plus muted natural tones.
