# 术语与约定

> 状态：当前
> 最后更新：2026-11-04
> 目标读者：产品、开发、测试、运维

## 1. 业务术语

| 术语 | 含义 |
|---|---|
| Owner | 唯一使用者与管理员；拥有全部知识库、会话、精读、技能与配置 |
| 内部工作区 | 唯一内部 tenant，仅作业务归属；用户看不到也不能切换 |
| 知识库（KB） | 个人知识主题；包含文件夹、文档、标签与配置 |
| 文件夹 | 知识库内目录；没有权限主体语义 |
| 文档 / Knowledge | 上传文件、网页快照、手工 Markdown 或代码文件；有解析/归档/回收站状态 |
| 代码项目 | 本地目录或 Git 仓库，按语言符号分块后作为 `type=code` 知识入库 |
| 分块 / Chunk | 检索与引用单位；由 app 生成，RAG 只负责嵌入与索引 |
| 父块 / 子块 | 父子分块策略下的上下文块与检索块 |
| 文档版本 | 文档保存或重新解析前的自动快照；最多保留 50 个 |
| 会话 / 消息 | 问答上下文；消息保存引用与检索 trace |
| 检索 trace | 一次问答的召回、融合、重排等调试信息 |
| 精读 / Reading Run | 针对文档集合的逐节阅读运行；包含计划、问题、笔记、报告 |
| 技能 / Skill | 个人可复用的提示词与资源包；普通问答时可选择注入 |
| MCP | Model Context Protocol 外部接入层；只读访问知识库与会话 |
| 单 Key | 设置页生成的唯一只读 API Key；用于 MCP/CLI |
| RAG / ylsw | 检索与生成侧车；只做索引、检索、重排与答案生成 |

## 2. 已废弃术语

以下概念不属于个人版当前实现，文档与代码不应再引入：公司、部门、成员、邀请、角色等级、能力码、共享空间、KB/文档 ACL、CR、issue、评论、审批、治理台、审计导出、文档生效/废止日期、多租户、工作区切换、平台 API Key。

## 3. 文档约定

- 文档状态只用：`当前`、`优化中`、`重构中`、`规划`、`历史`。
- 日期只写在文档头；当前文档名不带日期、Phase 或批次。
- `01` 总览、`02` 需求与设计、`03` 进度与交接、`05` 演示与试用参与当前导航；`04` 只做历史追溯。
- 产品/功能文档写“为什么用、怎么用、业务规则、界面意图、差距、验收”，不复制 API 字段或数据库表结构。
- 文档与代码冲突时以当前代码与运行结果为准，把差异写入对应文档的“当前实现与差距”。

## 4. 路径与运行约定

- 仓库根：`app/`、`frontend/`、`rag/`、`mcp/`、`deployments/`、`scripts/`、`docs/`。
- 本地数据：`data/rag/`（gitignore），不要删除。
- compose 项目名固定 `app`，沿用命名卷；构建上下文见 `deployments/README.md`。
- 前端开发 `/api` 代理到 6152；RAG 语法检查用 `python -m compileall -q src`。
- Windows 本机可能因 duckdb/gjieba CGO 失败；后端完整测试以 Linux 容器为准。

## 5. 安全约定

- 密钥、模型 Key、数据库口令、owner 初始密码不进入 git、日志或文档。
- 单 Key 明文只显示一次；之后只显示掩码，可重置或撤销。
- MCP 只读；写入、删除、建库、模型与租户能力不在 MCP 工具面内。
- 文档与接口不记录用户原始问题的治理用途；运行日志只用于本地排障。
