# 落地页改用 Notion 极简语言

## 背景

2026-11-20 owner 要求首页落地页内容与样式大改，参考 notion.com 的落地页：极简但不缺内容，动态线条流畅，图标美观。此前的落地页按 [ADR 0007](0007-PostHog布局语言落地页与壳层改造.md) 迁移 PostHog「模拟应用」版式，信息密度偏高、视觉语言偏复古桌面；共享壳层（顶栏 + 左右栏 + 中央窗）仍然沿用 ADR 0007，本次只替换落地页内容与视觉。

## 决策

1. `/` 落地页重做为 Notion 式单页：大字号居中 Hero、主/次 CTA、提问入口、产品预览，Bento 功能区、三步工作流、使用场景、本地数据黑底段、收尾 CTA 与极简页脚。
2. 视觉基线：浅色暖白底 `#fbfaf8`、白色卡片、1px 浅描边、黑色主文字、低饱和辅助色；品牌绿 `#07c05f` 只做 CTA 与少量强调。暗色模式使用深底对应 token，不强制浅色。
3. 共享壳层结构保持不变；落地页仍是 AppShell 内的中央窗内容，左右栏、顶栏、设置入口与路由行为不变。
4. 实现继续使用 Vue 3 + TDesign Vue Next + 自绘 CSS；不引入第二套组件库。图标使用 TDesign 图标与自绘 SVG 线稿/几何装饰，不使用 emoji 或第三方图标包。
5. 动态线条使用轻量 SVG 路径虚线流动、连接线与低频浮动，配合 IntersectionObserver 入场；所有动效尊重 `prefers-reduced-motion`。
6. 保留现有业务闭环：Hero 提问框预填到 `/platform/creatChat`，建议问题可点击，场景卡与页脚入口跳转真实功能页；不新增后端接口。
7. 文案中英双语，落地页新增文案进入 zh-CN 与 en-US 词条；默认中文，跟随语言设置。
8. 验收以浏览器实测 `type-check`、测试、构建、控制台 0 错误为基础，最终由 owner 目视签收；自动化不能代替审美验收。

## 考虑过的替代方案

- **继续沿用 PostHog 版式，只换颜色与文案**：改动最小，但无法回应 owner 对极简密度与动态线条的要求。
- **逐像素复制 notion.com**：会引入 Notion 的品牌素材、文案与结构，不符合产品自有内容与商标边界；本次只迁移版式与视觉语言。
- **落地页改用 React/Notion 组件生态**：保真度高，但违反全前端 TDesign 单一组件栈与现有工程约束。
- **同时重做共享壳层**：会扩大改动面并破坏已验收的详情页结构，本次不纳入。

## 后果

- ADR 0007 中关于落地页版式（PostHog 模拟应用结构）的部分由本文取代；共享壳层结构、顶栏/左右栏与详情页规则继续有效。
- [落地页设计](../02-需求与设计/落地页设计.md) 与[界面规范](../02-需求与设计/界面规范.md) 需要同步为 Notion 极简口径；旧 PostHog 测量值只作历史参考。
- 落地页新增一组 `welcomeHome.*` 中英词条；后续改文案只改语言包。
- 动态线条与浮动卡使用 CSS/SVG animation，低性能设备可通过 `prefers-reduced-motion` 关闭。
- 仍不承担 SEO、公开注册与转化追踪；页脚只保留产品内入口与版本。
