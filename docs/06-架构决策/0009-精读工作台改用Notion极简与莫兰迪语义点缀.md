# 精读工作台改用 Notion 极简与莫兰迪语义点缀

## 背景

现有精读页沿用 TDesign 卡片与品牌绿体系：左栏全文、中栏轮次卡片、右栏分类笔记。owner 提供《WellRead 精读工作台 UI 原型》，要求对齐 Notion 简洁风与莫兰迪淡色高亮：减少圆角与组件感，用留白和发丝线分区；品牌浅绿不再作为唯一高亮，按内容语义使用多种低饱和色。原型之外的完整交互也已确认：跨知识库选文、三份候选答案与判定、阶段理解确认、笔记确认/编辑/驳回、草稿、暂停与终态停止、章节目录与回看。

## 决策

1. 仅精读页启用页面级视觉 token：3/4px 圆角、1px 发丝线、无阴影、白底与暖雾灰侧栏；不升级为全局风格，组件仍使用 TDesign Vue Next，通过页面 CSS 变量覆盖。
2. 品牌绿保留给主 CTA、进度与选中；内容语义使用鼠尾草绿（结论/当前段落）、雾霾蓝（提问）、燕麦米（阶段确认）、陶土粉（矛盾）、藕紫（术语），同时提供深色映射。
3. 工作台改为三栏：256px 章节目录 + 本会话摘要；中栏阅读流；312px 笔记；进入工作台自动使用共享壳层全屏，配置视图保持普通窗口；侧栏宽度不足 1100px 时右栏收为抽屉，760px 以下左栏也收为抽屉。
4. 页头为页内 48px：文档名、工作台/创建配置切换、进度、导出菜单、报告、暂停、停止；不重复共享壳层品牌栏。
5. 当前章节原文移入右侧覆盖抽屉，引用角标与「原文」入口打开抽屉；抽屉左缘可拖拽调宽，最大为页面宽度的一半，拖拽结束不会触发遮罩关闭；原文直接复用知识库的 `DocumentPreview` 渲染方式，图片按同一 Markdown 管线输出，可访问的受保护图片会补载，缺失文件的相对路径图片隐藏。章节回看不改变进度，显式「从本章继续」才推进。
6. 主栏顺序：可折叠编号思考链路（原始推理另开抽屉）→ 本轮 conclusions（正文内用 `[n]` 角标，结论下方列编号来源，标题去除 Markdown 标记）→ 行内问题 → 阶段理解确认 → 矛盾卡；自动推断问答收进思考链路，不保留「本轮产出」摘要。左栏章节目录按标题级别生成树：文档名为根，二级标题为下一级，依此类推，重复标题合并为同一节点。
7. 行内问题提供三份不同视角候选答案并标一份推荐，也可自写作答；提交后用精读模型统一判定并持久化答案、判定与解释；判定失败保留答案并可重试。
8. 阶段理解用 understanding 渲染；「确认无误」把当前轮 candidate 结论与术语转 confirmed，「需要纠正」记录纠正并在下一轮生效，「跳过」按当前理解存档。
9. 术语与结论支持确认、编辑、驳回与恢复；驳回不计入导出，可恢复为草稿。
10. 暂停使用现有可恢复的 stopped；新增终态 abandoned，停止后不可恢复但保留笔记与导出。
11. 创建配置支持跨知识库选文（最多 5 篇）：文档选择为文件树，根节点为知识库、逐级展开文件夹与文档；搜索框默认全局搜索全部知识库；已选文档在下方实时列出并可移除。另提供目标模板与自定义、确定性时长/轮次/token 估算、后端多草稿（自动命名、可重命名、最多 20 份、生成后保留）。
12. 跨知识库会移除精读计划的单库限制，检索按所选文档与多个知识库白名单执行；不新增权限体系，个人版仍由后端 owner 身份兜底。
13. 参考原型只迁移版式与视觉语言，不复制其品牌素材与文案；文案克制，只保留影响决策的提示。

## 考虑过的替代方案

- **沿用 TDesign 卡片，只换高亮色**：改动小，但无法回应 owner 对低圆角、留白分区与语义色的要求。
- **全局升级为 Notion/Morandi 风格**：视觉统一，但会波及已验收页面并扩大回归范围；本批只作为精读页例外。
- **只做视觉换肤，不补原型交互**：周期短，但目录、候选答案、阶段确认与草稿等核心交互仍缺位。
- **一次全量前后端交付**：返工风险集中在审美未定稿的后端契约上；采用前端骨架先验收、再补后端契约的顺序。
- **跨知识库拆到后续批次**：可减小本批范围，但 owner 明确要求文档可跨库选择，且精读入口会长期受限。
