# 复习 V2 采用自适应稳定性与会话报告

## 背景

首轮复习卡使用固定间隔 1/3/7/15/30/60/120 天，所有卡共享同一节奏；复习首页只有系统推荐队列，用户不能按主题挑卡，也无法看到单卡表现和每轮效果。固定间隔不满足用户提出的遗忘曲线要求，无法体现不同卡片的记忆难度。

## 决策

1. 调度改为自适应稳定性模型：每卡维护 `stability`；记住 ×3、模糊 ×1.5、忘记重置到 5；按 `R=e^{-t/S}` 和目标保留率 90% 计算间隔，限制 1–180 天。
2. 保留三档评分与旧 `review_level` 展示字段；存量卡按旧 level 推导 stability，保留 `due_at`、复习次数与到期节奏。
3. 新增复习会话：`daily` 与 `manual` 两种模式；会话保存计划卡快照、完成/放弃/过期状态、三档计数与复习日；同一会话同一卡片只评分一次。
4. 每日 30 张额度只约束 `daily` 会话；手动自选复习不占额度，单独记录并在统计中可见。
5. 单卡表现展示全量/近 5 次三档计数、近期忘记率、连续忘记、稳定度、到期与历史；连续 2 次忘记或近 5 次忘记 ≥40% 预警，累计 3 次忘记自动暂停。
6. 复习页内新增「复习 / 卡片 / 统计」标签；统计页使用 ECharts 展示趋势、卡组保留率、易忘卡、到期预测、实际 vs 理论遗忘曲线、会话历史与导出。
7. 卡组管理改为右键/悬停上下文菜单：新建子卡组、重命名、删除；删除非空卡组默认移动卡片，可选连带删除。
8. 分三段交付：数据与调度底座、交互与单卡表现、统计与报告；每段可独立验收。

## 考虑过的替代方案

- **继续用固定间隔**：实现简单，但无法体现卡片难度差异，也不满足遗忘曲线要求。
- **直接引入完整 FSRS/Anki**：更精确，但需要参数校准、迁移、长期调参与复杂测试，超出个人版当前维护能力。
- **只做手动选题**：解决挑选问题，但失去每日推荐节奏与间隔重复默认行为。
- **只做会话报告，不做单卡表现**：能看每轮结果，但用户无法定位需要补强的卡片。

## 后果

- 新增 `000002_review_sessions_stability`：卡片 stability/forget_streak、日志 session_id/stability、会话表；已有数据库需备份后增量升级。
- 复习 API 从无会话评分扩展为可关联会话；旧无 `session_id` 评分保留兼容。
- 统计页需要 ECharts 和新查询聚合；会话历史与报告依赖稳定 session_id。
- 复习页 UI 迁移到 shadcn-vue 需要单独验证旧 TDesign 页面不受 Tailwind 影响。
