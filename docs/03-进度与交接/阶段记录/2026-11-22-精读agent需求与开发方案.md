## 1. 输入与结论

review 两份外部建议后合并为一条路线：结构预读、逐章循环、全局综合、自测出卡。现有代码中的机械 quote 校验、检索补证、步数/token 硬顶、状态摘要与 JSON 重试保留复用，不重复建设。

真正缺口：独立结构遍、每章单提问与安静模式、用户理解档案、专门综合遍、自测题接入复习、双模型分层、严格 schema、精读评测指标。

## 2. 已确认决策

- 保留 `grill-with-docs` 产品口径，但只使用其追问与引用原则，不作为完整运行时 skill；不与普通问答共享可执行工具。
- 四段流水线，不引入 agent 框架；继续使用 Go 状态机与结构化输出解析。
- 每章最多一个提问；理解陈述确认不占提问预算；连续跳过两次进入安静模式。
- 抽取模型可非 thinking；综合模型必须 thinking；均缺省回退现有精读模型。
- 自测题先预览，用户选卡组与题目后手动导入复习 V3，不静默建卡。
- MCP 工具面保持 17 个，精读读取工具不纳入当前路线。
- 现有精读后端契约优先；契约验收后再进入精读agent引擎 P0。
