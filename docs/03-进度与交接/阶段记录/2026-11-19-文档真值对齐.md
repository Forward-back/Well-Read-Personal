## 2. 校正项

- 登录入口统一为 `/`；`/welcome` 重定向到 `/`。
- MCP 口径统一为「知识面只读、会话面仅自有会话」，工具面固定 17 个。

- 热力图行列口径改为「直接子卡组（可下钻）+ 标签/知识库回退列」。
- 填空卡、卡背来源图片、向量语义查重标注为 P2 未实现，不写成当前能力。
- 落地页状态、字重分层、左右栏映射与 ADR 0007/0008 的取代关系校正。
- 当前进度中把当时已完成、已验证与部署状态区分开，不把设计目标写成已验证能力。
