## 1. 范围

按 owner 当日对齐决策，对 2026-11-26 的 Agent UI 骨架做视觉收口，只改前端，不接后端：

- 页头下三栏工作台齐平全宽；左文档树固定 250px；中栏与右栏可独立折叠，允许全部收起并显示恢复入口；中右边界可拖拽调宽。
- 页头动作全部改图标按钮；不新增主题开关（主题只在右栏）与刷新按钮（界面规范禁止）。
- 亮色采用本机 VS Code `Default High Contrast Light` 配色；暗色沿用全站暖炭 token。
- UI 设置新增 Agent 专属颜色组；Agent 默认主操作色改为 VS Code 高对比蓝。

## 2. 已完成

- **布局**：去掉页面 24px 内边距与内层圆角边框；PageTopbar 底边即工作台顶边。三栏保持 250 / 自适应 / 392 基准。中栏、右栏各设折叠按钮；两者都收起时，工作区显示「展开编辑器 / 展开对话」恢复入口。
- **对话时间线**：对话栏改为竖向时间线，垂直线串起每轮节点，圆点颜色区分角色与状态/板块（用户与编辑为蓝、已完成读取为绿、Agent 文本为灰、Diff 为蓝、待确认为暖棕）。Agent 回答不再使用气泡或边框，直接排在时间线右侧；用户消息右对齐，使用透明底 + Agent 主操作色描边。编辑器收起时时间线铺满对话栏，用户框贴右边界、Agent 文本从左侧时间线后起排。移除顶部 chips 与工具节点内「风险级/返回/位置/来源」等小字，统一提高正文与元信息字号。
- **拖拽**：中右分隔条支持指针拖拽、方向键与 Home/End；宽度持久化到 `Gaze_<userId>_agent_chat_width`；对话栏最小 280px，最大到工作区中线（分隔条可在画面中央到最右侧之间移动），窗口缩放时按工作区宽度重新夹紧。
- **页头**：新任务（蓝底）、历史、版本、编辑器、对话均为图标按钮，带 tooltip 与 aria；保留 48px PageTopbar 结构。
- **配色**：亮色纸面 `#FFFFFF`、墨 `#292929`、次要文字 `#515151`、弱化 `#7F7F7F`、交互/边框 `#0F4A85`、焦点 `#006BBD`、警告 `#895503`、危险 `#B5200D`、新增 `#096D48`、选中底为蓝 10%；暗色按 GitHub Primer `dark-high-contrast`（`@primer/primitives@11.10.0`）：canvas `#010409`、muted `#151B23`、border `#B7BDC8`、fg `#FFFFFF` / `#D1D7E0` / `#B7BDC8`、accent `#74B9FF`、accent emphasis `#194FB1`、focus `#409EFF`、selection `#5CACFF1A`、success `#2BD853`、attention `#F0B72F`、danger `#FF9492`。
- **组件细节**：文档树补层级缩进、caret、计数与修改点；编辑器补行内代码、标题/行内代码蓝、增删行绿/红墨；工具节点、Diff、待确认卡、输入区统一到 Agent 语义 token；待确认卡补警示图标，驳回按钮改危险色。
- **身份**：对话栏头部头像由 W 方块改为问答回答使用的 robot 双色图标，名称改为 Gaze；图标 fill 跟随 Agent 主操作色，Agent 消息署名同步为 Gaze。
- **UI 设置**：「详情页外观」新增「智能体工作台」纸面/抬高面/边框；功能主操作色增加「智能体」，默认 `#0F4A85`，可恢复默认；暗色不受这些亮色设置影响。
- **中英文词条**：新增 Agent 折叠/展开、恢复、拖拽、修改标记与智能体颜色设置词条。

## 4. 边界

- 亮色 Agent 页面不跟随「详情页外观」的全局画布，而使用 Agent 专属纸面/抬高面/边框；三级文字与主操作色仍由现有设置控制。语义色（警告、危险、新增/删除）固定，不开放取色。
- 页面画布透明度对 Agent 不生效；Agent 纸面为实色。
- 窄屏 ≤900px 隐藏文档树，让编辑器与对话保持可用；≤1100px 隐藏输入区次要提示。
- 文档树、工具节点、Diff、待确认卡仍为静态数据；新任务、历史、版本、发送、确认、撤销仍为后端占位。
