# 复习 V3 热力图 v2、独立簇详情与四出口（2026-11-16）

> 状态：历史
> 范围：热力图行下钻/知识库回退/top-N、独立簇详情路由、警告规则最近窗口、拆分卡、新角度卡、根因推断
> 关联：[复习页 V3 设计](../../02-需求与设计/04-复习/复习页设计.md)、[复习卡与间隔重复](../../02-需求与设计/04-复习/复习卡与间隔重复.md)、[ADR 0006](../../06-架构决策/0006-复习V3采用四档评分与漏洞驱动闭环.md)

## 1. 结论

本批把漏洞闭环从「看热力图」推进到「进独立簇页并采取行动」：

- 热力图默认不再展开全部卡组 × 来源文档；行是当前范围的下一层卡组，列是标签，无标签回退知识库。
- 簇详情改独立子路由，页面结构对齐原型：强度公式/进度条、原因、参数表、根因区、四出口。
- 四个出口全部可用：重学、回原文、拆分卡片（AI）、生成新角度卡（AI）；根因按需调用 LLM，失败回退规则。
- 警告规则改为最近窗口：历史累计 `lapses` 不再永久触发警告；237 天稳定度 + 最近秒答会回到健康。

## 2. 关键决策

| 项 | 决策 |
|---|---|
| 行轴 | 当前 scope 的直接子卡组，聚合子树；scope 自身挂卡且有子组时加「本组卡片」行；默认 8 行，展开最多 50 |
| 列轴 | 标签优先；无标签回退知识库；再无来源归未分类；默认 10 列，展开最多 30；不再默认按来源文档分列 |
| 截断 | 超出显示上限合并为 `other_row` / `other_column`，不可点，显示「显示全部」；不静默丢数据 |
| 簇详情 | 独立路由 `/platform/review-v3/cluster/:rowGroupId?col=&scope=&direct=`；返回保留 scope |
| 警告规则 | 严重=可撑<3 或连续忘记≥2；警告=可撑<10 或最近一次忘记 或最近两次薄弱；观察=逾期≥3 天或最近一次想得慢 |
| 拆分 | AI 预览 → 用户勾选 → 新卡继承组/标签/来源；原卡暂停，日志保留，可手动恢复 |
| 新角度 | AI 预览 → 导入；原卡保持 active；沿用查重吸收 |
| 根因 | 页面先显示规则摘要；「AI 深入分析」按需调用；内存 TTL 15 分钟；失败回退规则 |

## 3. 实施

### 3.1 后端

- 警告规则：`review_vulnerability.go` 新增 `reviewCardLevelDetail`，返回级别 + 可读原因；`ReviewCard.VulnerabilityReason` 非持久化字段；performance 复用原因。
- 热力图 v2：`review_heatmap.go` 重写行/列聚合、top-N other、scope 路径、公式；新增 `ReviewHeatmapOptions`、行 kind/drillable、列 `knowledge_base`。
- 仓库：新增 `ListActiveCardsByGroupIDs`、`ListActiveSourcesByCardIDs`，避免子树聚合拉全租户；集合新增 `CreateDerivedCardsAndSuspend` 事务。
- 知识库回退：扩宽 `reviewKnowledgeResolver`，通过 `KnowledgeBaseRepository.GetKnowledgeBaseByIDs` 取知识库名，按 tenant 过滤。
- 簇详情：改用 `scope_group_id/row_group_id/column_key/direct` 直接构建，不再全量重建后查 NUL key。
- LLM：
  - `POST /review/cards/:id/split/preview|apply`
  - `POST /review/cards/:id/angles/preview`；导入复用 `/review/generations/import`
  - `POST /review/clusters/root-cause`
  - 新增 `review_actions.go`，复用模型解析、JSON 解析、查重与来源构造；根因 TTL 缓存。
- 无新迁移；SQLite/Postgres schema 不变。

### 3.2 前端

- 热力图：行标题可下钻、scope 路径、KB 列、`显示全部`、other 桶不可点；今日页删除内联簇详情。
- 路由：新增 `reviewV3Cluster`；scope 写入 query；从簇页返回保留 scope；`resume=1` 用于从簇页发起/继续会话后自动打开复习层。
- 独立页 `ReviewClusterPage.vue`：页头公式/进度条、原因条、参数表（选择/题干/可撑/累计忘记/连续忘记/最近评分/状态/建议/回原文）、根因区、四出口。
- AI 弹窗 `ReviewCardAIDialog.vue`：拆分/新角度共用；候选勾选、重复禁用、错误重试；拆分提示原卡暂停。
- 旧 `ReviewClusterDetail.vue` 删除，避免内联页面残留。

### P1：下一批

1. 卡片与统计页：56px 列表、批量栏、标签、表现抽屉、「立即复习」、重置、四档统计与空态。

### P2：已知限制

1. `other_row`/`other_column` 只支持展开，不支持直接下钻；展开上限 50/30。
2. 不提供文档级默认列；需要时后续加「按文档」第二模式。
3. 拆分/新角度没有 lineage 字段；派生关系只能靠复制来源与标签追溯。
4. 根因缓存是单进程内存，重启丢失；模型失败只回退规则，不重试。
5. 簇页「次日到期」仍是调度提示文案，不是次日到期数量；完成页同样。
6. 真实 LLM JSON 质量、延迟与成本未验证。
