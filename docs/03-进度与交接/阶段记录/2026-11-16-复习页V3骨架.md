# 复习页 V3 骨架预览（2026-11-16）

> 状态：历史
> 范围：V3 预览页壳、卡组二级栏、今日任务条、后端卡组到期数与队列连续天数；不含热力图、复习模式、卡片与统计

## 1. 结论

V3 页面以并行预览方式落地：现有 `/platform/review` 仍是 V2 shadcn 页面并保持可用；新页面挂在临时预览路由 `/platform/review-v3`，完成全部视图后替换主路由并删除 shadcn。本阶段只完成壳与今日视图，卡片、统计、热力图与复习模式仍是占位。

## 2. 对齐决策

- 重写方式：新建 V3 页面并行，V2 页面与未提交调整保留，切换时统一清理。
- 骨架边界：先完成 TDesign 页头、三视图切换、卡组二级栏、今日任务条；卡片与统计下一批迁移。
- 卡组管理：行悬停显示「更多」菜单，提供新建子卡组、重命名、删除；默认卡组只允许新建子卡组。保留底部「新建卡组」。
- 卡组待复习角标：仅统计 active、已复习且到期（含逾期）的卡；新卡只在任务条展示。后端 `ReviewGroupNode.due_count` 按子树汇总。
- 连续天数：今日队列接口直接返回 `streak_days`，任务条一次请求拿齐；预计分钟由前端按 30 秒/卡计算。
- 预览路由是临时入口，不进入侧栏导航；切换主路由时删除。

## 3. 实施

### 3.1 后端

- `ReviewGroupNode` 增加 `due_count`，卡组树按子树汇总今日到期卡。
- `ReviewQueue` 增加 `streak_days`，复用现有评分日志计算连续天数。
- 单测覆盖卡组子树到期计数与队列连续天数。

### 3.2 前端

- 新增 `frontend/src/views/review/v3/ReviewV3.vue`：TDesign 页头、三视图标签、预览标记、卡组增删改弹层。
- 新增 `ReviewGroupRail.vue`：约 200px 卡组栏，支持展开/收起、选择、卡片数、到期角标、悬停菜单、新建卡组；760px 以下隐藏并改用顶部下拉。
- 新增 `ReviewTodayView.vue`：任务条（到期、新卡、预计分钟、连续天数）、开始/继续/已完成/空态 CTA、移动端卡组选择、热力图与优先补强占位。
- 新增 `types.ts` 共享卡组扁平结构。
- `frontend/src/api/review.ts` 增加 `due_count`、`streak_days` 类型。
- 临时路由 `/platform/review-v3`，`meta.requiresAuth`；侧栏不展示。
