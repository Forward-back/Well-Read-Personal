### 2.2 引擎

- `reading_agent.go`：结构遍、逐章 agent 轮次、记忆蒸馏、综合遍、自测遍、最终落盘。
- 逐章规则：先陈述后提问；每章最多一问；快速档 0 问；连续跳过两次进入 quiet 并保持；驳回内容不进入后续。
- 角色模型：抽取模型可非 thinking；综合模型必须支持 thinking；创建运行时快照到 run。设置接口与页面提供两个角色模型并保留兜底精读模型。
- 严格校验：结构/综合/自测 JSON 手写校验；证据逐字匹配，非法证据丢弃；失败重试一次后降级并写步骤日志。
- 自测：每节 2–4 题、全运行最多 20 题；题目/答案/证据校验、去重；确定性 ID 保证重试不重复；新接口 `GET/POST /reading/runs/:id/self-tests[/import]`，逐题导入复习卡并标记 `imported`，重复导入幂等跳过。

### 2.3 前端

- 型号设置：默认精读模型、抽取模型、综合模型三个选择，抽取允许任意问答模型，综合只列 thinking 模型。
- 精读 API 增加阶段、模型快照、自测与双模型配置类型。
