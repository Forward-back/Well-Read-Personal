## 4. LLM 失败回退的真实证据

第一次复跑时根因接口返回 `source=rule`。后端日志为：

```
error=baseURL SSRF check failed: SSRF validation failed: DNS resolution failed for hostname api.deepseek.com: cannot verify if it resolves to safe IP
```

属于容器 DNS 瞬时失败。接口按设计返回规则摘要，未阻塞簇页；随后重试成功。本批脚本对根因最多重试 3 次，以区分瞬时网络问题与真实模型故障。该次失败没有写入文档为「LLM 不可用」，只作为回退路径真实可用的证据。
