# Agent 智能体 UI 骨架（2026-11-26）

> 最后更新：2026-11-26
> 关联：[当前进度](../当前进度.md)、[Agent 功能说明](../../02-需求与设计/07-agent/agent功能说明.md)、[Agent 原型](../../02-需求与设计/07-agent/Agent插件VSCode原型.html)、[验证记录](../验证记录.md)

## 1. 范围

按已对齐原型快速搭建「智能体 / Agent」UI 骨架：左栏第七项、独立 `/platform/agent` 工作台、文档树 / 编辑器与 Diff / Agent 对话三栏。本轮只做前端静态 UI 与占位交互，不接后端。

## 2. 已完成

- 导航与路由：左栏新增「智能体 / Agent」，`/platform/agent`；壳层增加 `app-shell--agent` 全宽工作台例外。
- 页面结构：48px PageTopbar；三栏工作台（250 / 自适应 / 392），响应式在窄屏收树/收对话；对话栏可折叠。
- 文档树：知识库/文件夹/文档、修改标记、当前版本 v12 卡。
- 编辑器：文档标签、面包屑、行号、Agent 插入摘要块、新增/删除行、Diff 高亮。
- Agent 对话：消息、角色/范围 chips、工具卡（读取 / L1 编辑）、Diff 预览、L2 待确认卡、`confirm_token` 签发占位、撤销占位、输入区。
- 兼容浅色/深色全站 token；未使用原型 VS Code 配色。
- 占位操作统一提示「后端接口待接入」：新任务、历史、版本、发送、确认、撤销；未伪造数据或成功结果。

## 3. 验证

- 前端 `type-check` 通过；597 项测试通过；i18n 缺失键 0。
- 5173 `/platform/agent` 渲染三栏工作台，控制台 0 错误。
- 未做 owner 视觉签收；生产前端镜像未重建。

## 4. 后端遗留

1. Agent 会话/消息/工具调用/待确认任务的表与 API；会话历史独立于问答。
2. 流式 Agent 运行接口（消息 + 工具卡 + pending 状态）。
3. 文档读取/写入工具与知识库权限守卫；写入必须走版本服务。
4. 版本服务：版本表/CAS/commit/读/diff/revert/409 冲突；见[版本控制技术方案](../../02-需求与设计/07-agent/MD文档版本控制_技术方案.md)。
5. confirm_token 签发/消费、pending task 过期与执行前 `current_seq` 复核。
6. 版本历史、Diff、回滚的 API 与真实数据接入。
7. Agent 模型选择与会话头部状态接入；当前均为静态占位。

## 5. 当前边界

- 页面使用静态 mock 文档与对话；未调用任何 Agent/版本/文档写接口。
- 工具卡、Diff、pending 卡为交互原型；新任务、历史、版本、发送、撤销、确认不产生后端事实。
- 无 Agent 专属深色基底；沿用全站中性暖炭 token。
