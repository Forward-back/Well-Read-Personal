## 1. 范围与结果

完成复习 V2 阶段三：复习页从 TDesign 迁移到 shadcn-vue + Tailwind，补齐三标签、统计页、会话历史与 CSV 导出，并在真实数据上完成浏览器验收。

- 复习页：复习 / 卡片 / 统计三标签。
- 复习主页：今日任务、今日进度、长期保留率、未完成会话恢复、薄弱项。
- 卡片页：搜索、状态筛选、多选、手动开始复习、合并、暂停/恢复、重绑、删除与撤销。
- 卡组：右键/悬停菜单新建子卡组、重命名、删除；空白处右键新建顶层卡组。
- 统计页：7/30/90 天切换、评分分布、评分趋势、7 天到期预测、卡组排行、易忘卡 Top10、实际 vs 理论遗忘曲线、连续天数、会话历史。
- 导出：整库 JSON 增加会话；会话历史支持 CSV 下载。
- 复习流：键盘翻面与三档评分、刷新恢复、来源摘录、表现抽屉。

## 2. 后端

- `GET /api/v1/review/stats?days=7|30|90` 返回扩展统计；非法天数回退 30。
- 新增 `ReviewStats` 聚合：按天趋势、评分分布、卡组排行、易忘卡、7 天到期预测、连续天数、实际/理论遗忘曲线、薄弱项。
- 保留 `reviewed_30d`、`remembered_30d`、`retention_30d`，兼容旧调用。
- `ReviewExport` 增加 `sessions`。
- 新增 `app/internal/application/service/review_stats.go`；接口 `Stats(ctx, days)`；handler 读取 `days` 查询参数。
- 服务测试更新：统计窗口、趋势长度、预测长度、卡组排行、评分分布、连续天数；导出断言会话字段。

## 3. 前端

- `views/review/Review.vue` 重写为 shadcn-vue 页面；移除 TDesign 组件与页面 Less。
- 新增 `views/review/ReviewGroupSidebar.vue`：卡组树、右键菜单、悬停 dropdown、空白右键。
- 新增 `views/review/ReviewStatsPanel.vue`：ECharts 按路由异步加载，统计卡片、图表、排行与会话表。
- 主题：`useTheme` 同步 `theme-mode` 与 `.dark`，shadcn 深色样式跟随现有主题开关。
- 页面局部补 `box-sizing: border-box`，避免 Tailwind Preflight 未全局启用导致 padding 撑宽。
- 安装 `echarts`。
- 修复 `scripts/build_images.sh` 前端构建残留的 `contracts` named context。

## 5. 限制与后续

- 平台壳层 `min-width: 600px`；移动端（<600px）不在当前范围，复习页在 600px 无横向溢出。
- 遗忘曲线需要同一张卡至少两次评分；样本不足时前端显示「数据不足」。
- 统计页会话历史只展示最近 50 条；CSV 下载未纳入自动化断言。
- 复习路由 Swagger 注解仍未补齐。
- 下一优先级：代码项目同步异步化与批量 ingest、App↔YLSW 一致性评估、OCR 失败状态落库、联网 Key 统一。
