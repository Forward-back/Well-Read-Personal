# 精读原文批注高亮（2026-11-27）

> 状态：当前
> 最后更新：2026-11-27
> 关联：[当前进度](../当前进度.md)、[交互式精读](../../02-需求与设计/03-精读/交互式精读.md)、[验证记录](../验证记录.md)

## 1. 问题

原文抽屉创建批注后，批注只出现在右栏列表，原文没有持续高亮；再次打开原文也找不到对应位置。

## 2. 实现

- 原文抽屉 DOM 增加批注渲染层：对当前文档文本节点做空白归一化匹配，命中批注 quote 后用 `<mark class="rv-annotation-highlight">` 包裹；跨多个文本节点时逐段包裹。
- 高亮末尾插入便签按钮 `.rv-annotation-pin`，点击后打开浮层，显示 quote、批注文字，以及打开原文、生成复习卡、删除入口。
- 打开原文抽屉、切换文档、批注新增/删除时重新应用高亮；先清理旧 mark/pin 再重绘，避免重复。
- 高亮颜色使用阅读页莫兰迪黄与燕麦底，暗色跟随阅读页 token；不改变右栏既有批注列表。
- 仅在原文抽屉渲染；右栏批注列表与批注生成复习卡链路不变。

## 3. 验证

- 浏览器验收：在真实精读运行上创建批注，原文抽屉出现 1 个高亮和 1 个便签；点击便签浮层显示 quote、批注文字与操作；测试批注已删除。
- `npm run type-check` 通过；i18n 缺失键 0。
- 生产 `build` 通过。

## 4. 边界

- 仅对原文抽屉当前文档的可见文本做匹配；quote 在渲染后文本中不存在（例如只存在于未展开的 Markdown 语法、图片或表格结构）时不出现高亮，但右栏批注仍保留。
- 便签落在选中文本末尾；不自动扩展到整句。
- 同一段文本多处出现时按顺序匹配第一个未占用的 occurrence。
