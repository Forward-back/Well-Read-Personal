## 1. 结论

全局壳层由「左菜单 + 铺满内容区」改为：

- 顶部 52px 顶栏：左侧 WellRead 品牌 logo（沿用原左侧栏的 WellReadSerif 字标），右侧个人设置与 GitHub 主页入口；不再放搜索、新对话或完整导航。
- 左侧主菜单常驻；右侧 68px 辅助栏只保留主题切换与帮助/关于，不再与主导航重复；两栏统一为奶油半透明圆角面板。
- 内容区改为悬浮圆角窗口，带独立窗口栏与右上角「全屏」「退出」两个按钮；退出后整个详情窗消失，只保留草地、左右栏和八键；「打开工作区」或导航可恢复。
- 全屏时窗口与顶栏无缝贴合，左右/底部保留 8px 空隙；左右栏与八键隐藏。
- 背景使用 PostHog 草地纹理；右下角八个立体按键依次为 `W e l l R e a d`，为独立装饰层，不参与交互。窗口打开时按键位于窗口后方；退出窗口后完整可见。
- 窄屏/缩放：≤1280 左右栏变窄，≤1000 左栏收为 64px 图标栏，≤700 顶栏降至 42px；中央窗口与按键同步收缩。
- 图标统一换为 Icons8 手绘风格：静态 PNG（菜单/搜索/更多/关闭/全屏/GitHub/主题/帮助等）与动态 GIF（日历/目标/火箭/火焰/书/图表/奖杯等），颜色限定为墨色/灰白与低饱和自然色，不再使用蓝紫高饱和图标。

## 2. 关键实现

- `views/platform/index.vue`：顶栏 + 左右栏 + 悬浮窗口 + 全屏/消失状态；草地背景固定在 `.main`，UI 在独立层；内容根背景统一为浅奶油绿。
- `components/layout/AppTopBar.vue`：品牌、折叠菜单、设置、GitHub。
- `components/layout/AppRightRail.vue`：主题切换、帮助/关于，无主导航重复。
- `components/layout/AppHelpDialog.vue`：快捷键、版本/提交、GitHub、Icons8 署名与 PostHog 背景来源说明。
- `components/layout/GardenKeys.vue`：八键 SVG 装饰层。
- 复习页替换 lucide 图标为 Icons8 手绘资产；卡片抽屉 `attach="body"`，避免被顶栏遮挡。
- 背景资产：`frontend/src/assets/img/app-bg/grass.jpg`；手绘图标：`assets/icons/hand/`；动态图标：`assets/icons/animated/`。均带 README 与来源/署名说明。
