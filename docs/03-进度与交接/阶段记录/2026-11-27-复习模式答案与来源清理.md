## 1. 范围

按 owner 截图反馈，清理复习模式答题卡（`ReviewMode.vue`）的冗余文案与失效入口，并修复来源摘录未渲染 Markdown 的问题。只改前端与浏览器验收脚本，不改后端与调度。

## 2. 已完成

- 题面底部移除「来源摘录 / 回原文」整块；原回原文是路径为空时的兜底文字，不可点击，且与答题面下方的可用入口重复。
- 答题面来源摘录改用现有 Markdown 渲染管线（与答案、解析同一 `renderChatMarkdown` + 安全清洗）；标题、列表、粗体正常显示，不再出现 `###`、`**` 原始语法；无摘录时保留空态文案。
- 答案标题去掉 `Answer ·` 前缀，只保留「答案」；移除「正在复习：今日队列」与卡内队列标签的重复表述。
- 来源摘录标题样式改为普通字重，不再大写/加字距；渲染后的来源正文统一 14px、软墨色，标题与列表不再使用浏览器默认大字号。
- 验收脚本 `review_v3_mode_acceptance.js`：来源 fixture 改为含标题、列表、粗体的 Markdown；新增「来源区不得出现 `###`/`**`」断言；补 `/api/v1/chunks/by-id/*` mock，消除来源图片读取产生的 404。
