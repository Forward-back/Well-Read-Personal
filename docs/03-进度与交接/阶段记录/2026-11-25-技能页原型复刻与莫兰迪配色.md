# 技能页原型复刻与莫兰迪配色（2026-11-25）

> 状态：当前
> 最后更新：2026-11-25
> 关联：[当前进度](../当前进度.md)、[技能原型](../../02-需求与设计/06-技能/skills-prototype.html)、[技能页面实现与后端差距](../../02-需求与设计/06-技能/技能页面实现与后端差距.md)

## 1. 范围

按 `docs/02-需求与设计/06-技能/skills-prototype.html` 重做技能目录、添加/编辑、详情与问答端技能选择四屏。白底保持不变，组件平铺；补充莫兰迪低饱和配色和编辑区可读性。

## 2. 已完成

- `/platform/skills` 改为内部三视图：目录、编辑、详情；保留现有 catalog API。
- 目录新增搜索、全部/启用/禁用筛选、列表/网格切换、调用统计占位、问答范围与更新时间。
- 编辑器由弹窗改为整页布局：上传 .md/在线撰写、名称/版本/何时使用字段、质量引导、Markdown 编辑/分屏/预览、字数计数、示例模板。
- 详情页新增启停开关、使用反馈占位、12 周趋势占位、试运行占位、版本历史当前版本、生效范围（仅问答）。
- 问答端技能选择由扁平下拉改为面板：搜索、自动匹配占位、不使用技能、启用技能描述与问答范围、禁用技能灰显。
- 配色：白色画布；灰绿 `#5C6B51` / `#46523C` 主操作；沙黄 `#96794B` 版本与质量引导；陶土 `#A2685C` 危险操作；暖灰 `#E3DCCE` 描边；浅暖灰分区。
- 编辑器可读性：字段 14px、Markdown 14px/1.95、预览 15px/2.05，扩大编辑区宽度与最小高度。
- 编辑器体验收口：名称/描述/正文必填标识；版本标选填；缺字段 inline 报错并聚焦；新建技能自动保存本地草稿并恢复；取消、模式切换、模板覆盖二次确认；默认「编辑」态；文案统一「字符」；tab/计数/错误补齐可访问性属性。
- Markdown 正文复用知识库文档全文的 `renderDocumentPreviewMarkdown`（marked + GFM + KaTeX + highlight.js + 清洗）；编辑/预览固定高度、各自滚动、滚动条隐藏；支持覆盖中央应用窗内容区的页内全屏，按钮或 Esc 退出。
- 删除未使用的 `SkillCatalogSettings.vue`。

## 5. 已知边界

- 技能按产品硬规则只用于普通问答；原型中的 Agent 范围未实现。
- 自动匹配仍是禁用占位，当前默认“不使用技能”；手动选择走现有 `skill_id`。
- 统计、版本历史、试运行需要后端接口，见差距文档。
- 自动草稿只覆盖新建技能；编辑已有技能用取消确认防止丢失，不自动恢复旧草稿。
- 版本字段只做辅助提示，不强制 semver，后端仍接受任意版本字符串。
