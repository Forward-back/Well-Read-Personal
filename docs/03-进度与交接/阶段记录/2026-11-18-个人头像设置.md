# 个人头像设置

> 状态：当前
> 日期：2026-11-18
> 关联：[个人版账号与访问](../../02-需求与设计/个人版账号与访问.md)、[界面规范](../../02-需求与设计/界面规范.md)、[落地页设计](../../02-需求与设计/落地页设计.md)、[当前进度](../当前进度.md)

## 1. 范围与结论

为单 owner 账户增加可设置的个人头像，并让落地页顶栏的「个人设置」入口使用头像。本轮不改多账号、角色、ACL 或 API Key 权限模型。

结论：

- 头像上传使用前端居中裁切 256×256 的 PNG/JPEG/WebP data URL，后端解码后限制 384KB。
- 头像存储在 `users.avatar_data`（TEXT），`/auth/me` 的 `avatar` 优先返回上传值，空时回退 `users.avatar`。
- 更新接口 `PUT /api/v1/auth/me/avatar`，仅 owner JWT 会话可写；只读 API Key 未在白名单内。
- 设置 → 账户与助手 → 用户信息新增头像行；顶栏入口为 28×28 方形圆角头像，无头像时显示首字母。

## 2. 后端变更

- 新增 `000004_user_avatar_data` 迁移（Postgres 与 SQLite），增加 `users.avatar_data TEXT`。
- `types.User` 增加 `AvatarData`（`json:"-"`），`ToUserInfo` 输出时优先使用它。
- `UserService.UpdateUserAvatar` 读取用户、写入头像数据并保存。
- `AuthHandler.UpdateAvatar`：校验 data URL 前缀、base64、解码大小与真实 MIME；空字符串表示清除。
- 路由：`PUT /api/v1/auth/me/avatar`，不声明 API Key 白名单，机器 Key 拒绝。
- Swagger 重新生成，`/auth/me/avatar` 已进入 `docs/swagger.json`。

## 3. 前端变更

- `api/auth/index.ts` 新增 `updateMyAvatar`；`stores/auth.ts` 新增 `setAvatar`。
- `views/settings/UserProfile.vue` 新增头像行：选择图片、居中裁切 256×256、JPEG 预览、保存、移除；选择前校验类型与 5MB 原文件上限。
- `views/welcome/Welcome.vue` 顶栏个人设置入口改为头像按钮：28×28、8px 圆角、`object-fit: cover`；无头像显示用户名/邮箱首字母。
- i18n 新增 `userProfile.avatar.*` 与 `error.auth.updateAvatarFailed`。
