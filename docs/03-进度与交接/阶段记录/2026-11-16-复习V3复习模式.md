# 复习 V3 复习模式与重学入口（2026-11-16）

> 状态：历史
> 范围：全屏复习层、四档评分、键盘流、Markdown 答案、来源条、完成页、会话恢复/冲突弹层、簇详情「重学这 N 张」

## 1. 结论

复习模式以全屏层接入 V3 预览页，不再依赖 V2 页面。今日 CTA 会恢复已有会话或创建 `daily` 会话；簇详情「重学这 N 张」创建 `manual` 补强会话，已有 active 会话时弹层二选一，不静默切换。会话与评分仍由后端判定，前端只做展示与交互。

主路由 `/platform/review` 仍是 V2；本批只在 `/platform/review-v3` 生效。

## 2. 实施

### 2.1 复习层

- 新增 `ReviewMode.vue`：固定全屏层，页头「暂存退出 / 进度 / 队列名」；单卡约 760px。
- 题干居中；未翻面时全宽「显示答案（空格）」。
- 答案区支持 Markdown、代码块、图片与解析；长答案内部滚动；来源条显示摘录与「打开原文」，无可用来源时隐藏。
- 严重卡红色横幅：连续忘记优先、其次第 N 次忘记、否则「记忆可撑不足 3 天」；警告卡橙色「近期薄弱」标签，不用红色横幅。
- 严重/警告参数条：记忆可撑、忘记次数、建议间隔（由到期时间与上次复习时间推导，缺数据为「—」）。
- 四档评分：忘记 danger、想得慢 warning、想起来 success、秒答蓝色自定义；显示 1–4 快捷键。
- 键盘：空格/回车翻面，1–4 评分，Esc 暂存退出；输入框聚焦时不响应。
- 评分成功自动下一张；失败保留当前卡与已翻面状态，显示错误与「跳过此卡」；不自动前进。
- 完成后显示本轮完成页：完成数、四档计数、连续天数、次日到期提示；返回复习首页。
- 会话卡片来自 `GET /review/sessions/active` 或创建接口返回的剩余卡；卡详情单独请求以获取漏洞级别与来源。

### 2.2 会话编排

- `ReviewV3.vue` 负责会话状态：`daily` 今日队列、`manual` 漏洞补强、已有会话恢复、冲突弹层。
- 今日页 CTA：有 active 会话直接恢复；否则创建 `daily` 会话。后端返回冲突时重新读取 active 会话并恢复。
- 簇详情新增「重学这 N 张」，N = 严重 + 警告；无异常卡时不渲染。
- 已有 active 会话时从簇发起补强：弹层「继续当前 / 放弃并开始补强」。
  - 继续当前：打开原会话。
  - 放弃并开始：`force_new=true` 创建手动会话；旧会话已完成日志保留。
- 暂存退出只关闭层，不放弃会话；回到今日页刷新队列、热力图与 active 会话，任务条显示「继续复习」。

### 2.3 来源与安全

- 「打开原文」通过 `getKnowledgeDetails` 解析知识库 ID，再以 `knowledge_id + chunk_id` 新标签页打开；失败提示来源不可用。
- 来源只取 active 且有 `knowledge_id` 的记录；无来源时整个来源条隐藏。
- 答案 HTML 经 `sanitizeMarkdownHTML` 清洗后渲染；不引入新的内容渲染链路。
