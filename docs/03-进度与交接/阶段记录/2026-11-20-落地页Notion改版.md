# 落地页 Notion 极简改版

> 日期：2026-11-20
> 关联：[当前进度](../当前进度.md)、[落地页设计](../../02-需求与设计/05-落地页/落地页设计.md)、[ADR 0008](../../06-架构决策/0008-落地页改用Notion极简语言.md)、[界面规范](../../02-需求与设计/00-通用与界面/界面规范.md)

## 1. 范围与结论

按 owner 要求，将 `/` 落地页从 PostHog 模拟应用版式重做为 Notion 式极简单页：大字号 Hero、真实 DOM 产品预览、Bento 功能网格、三步流程、使用场景、深色本地数据段、收尾 CTA 与极简页脚。共享壳层（顶栏、左右栏、中央窗）保持不变。

- 页面底色 `#fbfaf8`，白色卡片 + 浅描边，主文字黑色；品牌绿 `#07c05f` 仅做 CTA 与少量强调。
- 动态线条：3 条低透明度 SVG 虚线路径流动 + 产品浮卡 7s 低频浮动 + 入区淡入上移；`prefers-reduced-motion` 全部关闭。
- 图标使用 TDesign 线性图标与自绘 SVG；产品界面用真实 DOM，不用截图。
- 中英双语，文案进入 `welcomeHome.*` 语言包；语言切换即时生效。
- 暗色模式提供对应 token，不再强制浅色。
- 架构图用 Archify 生成两个自包含 HTML，iframe 嵌入；透明背景、莫兰迪淡色；点击节点显示语义 Passport 与关联关系，支持平移/缩放；嵌入时隐藏完整工具栏。
- iframe 按内容高度自动撑开并监听容器尺寸变化，保证图例完整可见；架构图下方小字提示已移除。

## 2. 内容结构

Hero（标题「你的知识，该随叫随到」+ 提问框 + CTA）→ 信任条 → Bento（问答 / 知识库 / 复习 / 精读 / MCP）→ 平台/RAG 可交互架构图 → 三步工作流 → 使用场景 → 本地数据深色段 → 收尾 CTA → 页脚。

保留业务闭环：建议问题填充、Hero 提交预填 `/platform/creatChat`、场景卡跳精读/知识库/复习、本地数据段跳系统健康、页脚跳各功能区。

## 3. 实现

- 重写 `frontend/src/views/welcome/WelcomeHome.vue`；移除旧三标签演示、四步切换、统计卡与 PostHog 卡片结构。
- 新增 `welcomeHome.*` 中文词条与英文补丁（80 个键）。
- 动态线 SVG、浮卡与 hover/入场动画全部 CSS/SVG；无新增依赖。
- `prefers-reduced-motion` 下关闭流动线、浮卡、入场位移和平滑滚动。
- 暗色模式通过 `html[theme-mode="dark"]` 作用域覆盖页面、卡片、产品预览与浮卡。
