# 落地页克隆对齐（PostHog 布局语言）

> 状态：当前
> 日期：2026-11-18
> 关联：[落地页设计](../../02-需求与设计/落地页设计.md)、[界面规范](../../02-需求与设计/界面规范.md)、[当前进度](../当前进度.md)、[ADR 0007](../../06-架构决策/0007-PostHog布局语言落地页与壳层改造.md)、[ADR 0005](../../06-架构决策/0005-UI组件沿用TDesign并停止shadcn-vue迁移.md)

## 1. 范围与结论

本轮只做需求对齐与文档更新，不写页面代码、不运行采集、不改路由。结论：

- 用 ui-clone-skills 把 posthog.com 首页的版式语言迁移到 WellRead，布局保真优先，视觉语言其次，背景是重点提取对象。
- 交付形态是登录后独立落地页 `/welcome`，整页骨架（Header + Hero + 六个内容分区 + Footer），不套现有 platform 壳层。
- 技术路线为 Vue 3 + TDesign + 自绘 CSS；ui-clone 只做采集、提取与视觉对照，不产出 React 实现。
- 落地页验收通过后启动壳层替换（顶部导航），功能详情页后续逐页对齐；本期不动详情页。

## 2. 关键决策

1. **布局映射**：Hero + Ask 输入、知识消化四步、核心能力四卡、使用场景、功能区矩阵、收尾 CTA、Footer；文案换成 WellRead 中文草稿。
2. **内容边界**：不复制 PostHog logo、吉祥物、客户 logo、评价与图库；产品展示区用 Vue 自绘示意面板，不用截图。
3. **字体**：不引入 RoundHog/Squeak；正文 DM Sans、展示字 Bricolage Grotesque 候选，自托管并逐项校准字号行高。
4. **强调色**：保留品牌绿 `#07c05f`；背景采用 PostHog 米灰系统 `#eeefe9` / `#e5e7e0` / 白卡片。
5. **动效**：完整交互；CSS/VueUse/Swiper 优先；无法等价实现时先报告，不静默降级；尊重 `prefers-reduced-motion`。
6. **Hero 提问**：提交后跳转真实问答页并预填，不做演示假对话。
7. **主题**：首版仅浅色；暗色是否在壳层批次保留另定。
8. **验收**：指标化口径（背景色值、容器/栅格/间距、字号行高、圆角边框阴影、响应式、动效 timing）+ owner 目视签收。
9. **证据**：ui-capture + 提取阶段全跑，证据存 `tmp/ref/posthog-home/`，已加入 `.gitignore`。
10. **文档**：新增落地页设计与 ADR 0007；界面规范与 CLAUDE.md 标注过渡期口径；进度写入当前进度与本记录。
11. **壳层**：验收后全壳层重做，采用参考站的「顶栏 + 左侧图标栏 + 右侧辅助栏 + 中央应用窗」；删除旧壳代码与引用，旧手绘图标与背景资源文件保留。
12. **入口**：`/welcome` 为顶层 `requiresAuth: true` 路由，现有导航加入口；登录默认跳转不变。

## 6. 风险与限制

- 完整交互可能依赖 React 生态实现，Vue 等价方案存在降级风险。
- 中文字体度量与参考站不同，排版校准可能产生记录在案的偏差。
- 首版仅浅色；现有暗色主题在落地页强制浅色，离开后恢复。
- 过渡期新旧视觉并存，详情页在各自批次前不迁移。
- 参考站使用窗内滚动；滚动条、锚点与键盘行为需要单独验证。
- 整页插画背景为位图资产，不复用；CSS 替代方案在氛围上可能有差异。
- 参考站可能改版，采集时间点与证据路径必须固定。
