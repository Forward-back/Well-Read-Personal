## 1. 范围与结论

本轮新增「设置 → UI 设置」，把原「账户与助手」中的常规显示项移入，并加入可替换的壳层背景。范围只覆盖前端设置页、共享壳层外层背景与对应后端接口；不改主题 token、中央窗、登录页与其他分区。

决策：

- 设置导航新增第六分区「UI 设置」，位于「账户与助手」之后；旧深链接 `?section=general` 映射到 UI 设置。
- 常规设置（语言、主题、界面字体、代码字体、字体大小、Lite 自动更新）整体迁入 UI 设置；账户与助手只保留资料、头像、密码、提示词、问答模式、联网搜索与聊天记录。
- 背景默认草地；5 张内置壁纸固定不可删除；用户上传原图不压缩，单张 ≤10MB，最多 10 张，上传后可删除，删除当前选中项回退草地。
- 自定义背景只作用于平台共享壳层外层（当前草地位），不进入登录页，不改变中央暖米纸应用窗。
- 选中的背景由后端持久化；上传文件存 `LOCAL_STORAGE_BASE_DIR/backgrounds/<userID>/`，数据库只存元数据。前端另用 `localStorage` 缓存选择以避免启动闪烁。
- 详情页外观：UI 设置内新增「详情页外观」，提供暖米纸/纯白/浅灰/淡绿预设 + 自定义取色器与 0–100% 透明度；字体颜色按主文字、次要文字、占位文字三级分别取色；品牌绿、链接、状态色与代码高亮不覆盖；只作用于详情页画布与文字 token，卡片与输入框保持实色；仅亮色生效；与主题/字体一致存 localStorage。
- 详情页画布改为单层渲染：AppShell 的 `.app-window` 使用 `--w-detail-bg`，页面根节点透明，避免多层半透明叠加导致透明度不可预测。
- 字体颜色只覆盖亮色详情页的 `--td-text-color-primary/secondary/placeholder`；未设置时回退 TDesign 原 token，重置会清除覆盖而不是写入近似灰值；禁用态、品牌、链接、状态与代码高亮保持原样。
- 修复「界面字体」只在 TDesign 输入框生效的问题：共享壳层原先把 `--w-font` 固定为 DM Sans，覆盖了 `--app-font-family`；现改为 `var(--app-font-family)`，标题、菜单、左/右栏与正文统一跟随设置。代码字体仍由 `--app-font-family-mono` 驱动 Markdown/工具结果代码块；新增 Courier New 等宽选项，避免 Windows 上系统/Consolas/Cascadia/通用等宽实际指向同一字体、切换看不出差异。默认「系统默认」现在落到真实系统字体栈，不再强制 DM Sans。
- 语言设置修复：此前只注册 `zh-CN`，切英文无资源可用。恢复 monorepo 重构时删除的历史 `en-US` 语言包，新增个人版词条补丁 `en-US-extra.ts`（1020 个键，含复习/精读/知识库/编辑器/技能/聊天/用户资料），语言下拉收敛为简体中文与 English，接入 TDesign `en_US`，切换时同步 `<html lang>`。壳层左右栏、设置导航、UI 设置/背景设置/详情页外观、复习/精读/知识库主文案已英文化。落地页、账户资料、模型/接入/关于设置、帮助与会话抽屉仍有历史硬编码中文，留待下一批清理。
- 左栏功能切换：再次点击当前功能隐藏中央应用窗（`.app-stage` 下沉淡出，`aria-hidden`/`inert`），按钮保持激活；再点恢复。切换其他功能、顶栏首页或路由变化会自动恢复。问答的会话栏折叠改回只由聊天页左上角专用按钮控制。

## 2. 实现

- 内置壁纸：`frontend/public/backgrounds/wallpaper-1..5.jpg`，由 `src/constants/backgrounds.ts` 生成选择项；不进入 JS 包。
- 前端：`views/settings/Settings.vue` 增加 UI 分区；新增 `views/settings/BackgroundSettings.vue`、`DetailAppearanceSettings.vue`、`stores/background.ts`、`api/background/index.ts`、`composables/useDetailAppearance.ts`；`views/shell/AppShell.vue` 绑定 `backgroundStore.imageUrl` 并用 `--w-detail-bg` 绘制详情页画布，深色模式沿用原压暗滤镜与暗色窗底。
- 后端：迁移 `000005_user_backgrounds`（Postgres/SQLite）新增 `users.background_choice` 与 `user_backgrounds` 表；新增背景仓库、服务、handler；文件按 MIME 签名校验 JPEG/PNG/WebP，写入 app 数据卷并经鉴权接口读取。
- 接口：`GET/POST /api/v1/auth/me/backgrounds`、`DELETE /api/v1/auth/me/backgrounds/:id`、`GET /api/v1/auth/me/backgrounds/:id/file`、`PUT /api/v1/auth/me/background`；均为 owner JWT，未在 API Key 白名单中声明。

## 4. 未完成与限制

- 前端生产镜像仍为旧版本，6151 暂不包含 UI 设置与背景功能；5173 可用。
- 内置壁纸固定不可删；暂无排序、重命名与裁剪。
- 详情页外观仅亮色模式生效；暗色模式保持既有暗色窗底与白色字阶，不自适应所选颜色。
- 透明度只作用于页面画布；卡片/输入框保持实色，避免低透明度影响阅读。
- 字色只覆盖 TDesign 主/次/占位 token；硬编码的代码高亮、状态色、厂商徽标色与按钮白字不跟随全局字色。
- 背景文件与应用数据同卷，随 `app_data-files` 备份；删除用户/清理卷会同时移除上传背景。
- FAQ 等其他设置未决项不受本批影响。
