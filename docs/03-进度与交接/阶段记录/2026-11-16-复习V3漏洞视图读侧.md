# 复习 V3 漏洞视图读侧（2026-11-16）

> 状态：历史
> 范围：今日页漏洞视图的读侧闭环：热力图、优先补强、系统洞察、簇详情、回原文 chunk 定位；不含重学、复习模式、卡片与统计

## 1. 结论

按 owner 2026-11-16 对齐，本批只做漏洞视图读侧，避免在复习模式尚未落地时把「重学这 N 张」做成空壳。今日页现在能读取服务端漏洞聚合、按卡组过滤、进入簇详情并回到原文；簇详情主 CTA 与复习层随下一批上线。

主路由 `/platform/review` 仍是 V2 页面；本批改动只在临时预览路由 `/platform/review-v3`、共享知识库深链与验收脚本中。

## 2. 实施

### 2.1 热力图与今日视图

- `ReviewV3.vue` 增加 `getReviewHeatmap` 请求与独立 loading/error/seq，卡组切换、卡组重命名/删除后刷新热力图。
- `ReviewHeatmap.vue`：行=卡组（含非叶子虚拟行）、列=标签/来源文档/未分类；四级色阶与「暂无数据」灰格；格子显示加权强度与严重卡数；tooltip 给出簇级别、强度、总卡数与各等级计数；仅观察/警告/严重可点击；最多 3 格获得品牌绿描边；列超宽横向滚动，行标题 `position: sticky`；空态分「无卡片」与「无评分」两种引导。
- `ReviewPriorities.vue`：top 3 严重/警告簇、观察簇数量摘要、点击进入簇详情。
- 系统洞察：展示后端规则引擎返回的单条 message。
- `vulnerability.css` + `ReviewLevelTag.vue`：漏洞色阶独立于品牌绿；深色模式覆盖观察与健康色；级别标签统一。
- i18n：`review.v3.level/rating`、热力图、优先补强、簇详情与回原文文案。

### 2.2 簇详情

- `ReviewClusterDetail.vue`：页内子视图，返回保留卡组选择；头部显示路径、级别、加权强度、严重/警告/观察计数。
- 异常卡表格只列严重/警告/观察；56px 行高、首列固定；列含题干、记忆可撑、忘记次数、最近评分、建议、状态、回原文。
- 建议列只用可读文本「重学 / 再观察」，本批不渲染重学按钮。
- 来源失效行内「回原文」禁用并给出提示；异常卡唯一来源时底部显示「打开原始笔记」。
- 数据刷新后无异常卡时显示「本簇已无异常卡」并允许返回。
- 加载失败显示重试，不空白。

### 2.3 回原文 chunk 定位

- 知识库详情原本支持 `?knowledge_id=`，本次新增 `?chunk_id=` 深链。
- `KnowledgeBase.vue` 将 `chunk_id` 传给 `DocContent`，关闭抽屉时清空。
- `DocContent` 新增 `initialChunkId`：打开文档后切到分块视图；目标不在当前页时用 `getChunkByIdOnly` 取 `chunk_index`，按 25 条/页计算页码并请求，`details.md` 更新后重试滚动高亮。
- 顺带修复 `handleChunkPageChange` 只接受对象、评论跳转却传数字的旧问题。
