## 1. 范围

完成精读agent P0 的前置后端契约，并把 2026-11-21 前端骨架中的演示状态接到真实接口；同时收掉精读工作台当日视觉问题。精读agent引擎 P0（结构遍、综合遍、自测出卡、双模型）尚未开始。

## 2. 已完成

### 2.1 后端契约

- 新增 `000006_reading_contract` 迁移，PostgreSQL 与 SQLite 各有 up/down：
  - `reading_drafts`：owner 私有精读草稿；
  - `reading_understandings`：按 run、section、round 保存理解确认/纠正/跳过；
  - `reading_questions`：新增 `options`、`judgment`、`judgment_reason`、`judged_at`。
- 跨知识库：
  - `buildSections` 不再拒绝多知识库，返回知识库 ID 集合；
  - `ReadingPlan` 增加 `knowledge_base_ids`，`ReadingSection` 增加 `knowledge_base_id`；
  - 语义检索按多个知识库 ID 与选中文档白名单执行；单库旧计划回退 `knowledge_base_id`；
  - 追加文档时合并知识库集合。
- 草稿：新增 list/create/update/delete 接口，最多 20 份、每份最多 5 篇文档，owner 校验。
- 问题候选与判定：
  - 精读提示词要求每个问题提供 3 个候选视角与 1 个推荐；
  - 问题节点持久化候选、判定、判定理由与判定时间；
  - 用户作答后同步调用精读模型判定；失败保留答案，可通过独立 judge 接口重试；
  - 事实题不再自动生成用户结论，裁定题仍生成用户来源结论。
- 理解确认与笔记：
  - 理解陈述落库，确认/纠正/跳过通过接口持久化；确认时把当前轮 candidate 结论与 candidate 术语转 confirmed；
  - 术语、结论支持更新文本与状态，驳回为 `rejected`，可恢复为 candidate；
  - 驳回内容不进入下一轮摘要、报告与 JSON 导出。
- 运行控制：
  - 新增终态 `abandoned`；暂停仍为可恢复的 `stopped`；
  - 新增终止接口，已完成任务不可终止；
  - 新增章节跳转接口；目标章节及之后章节重置为未读，避免跳章后仍从旧进度推进。

### 2.2 前端接入

- 草稿从 localStorage 改为后端 CRUD；保存、载入、重命名、删除均走真实接口。
- 阶段理解确认、纠正、跳过走真实接口；刷新后读取后端状态。
- 笔记确认、驳回、恢复、编辑走真实接口；分类与驳回标签按真实状态显示。
- 问题卡读取服务端候选答案；提交后显示判定与理由，判定缺失时可重试。
- 终止按钮调用 `abandon` 接口；章节回看后的“从本章继续”调用跳转接口。
- 跨知识库原文图片补载按当前文档所属知识库解析，不再固定使用计划单库。

### 2.3 当日视觉修正

- 阅读笔记右栏左边缘可拖拽调宽，最大到应用窗中线，宽度记忆；窄屏抽屉禁用。
- 笔记分类 tab 按类别高亮；全部视图卡片按类别着色。
- 来源引用悬停只覆盖文字；点击引用打开原文后按 quote 定位并高亮，找不到时回退标题。
- 原文抽屉页头的全屏与关闭按钮统一为 30×30、居中、深色。
