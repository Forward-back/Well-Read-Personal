## 1. 范围与结论

本轮按 owner 逐页反馈做视觉对齐，范围覆盖问答页、知识库新建/设置、复习今日/卡片页。只改前端源码与静态图标，不改后端接口与调度规则。

结论：

- 问答改为桌面内联会话栏，历史搜索改为覆盖式页面，引用面板与定位波浪约束在详情主区域内。
- 知识库新建/设置改为详情页；文件夹弹窗挂载详情页内并虚化背景；分块设置页头回归文档流。
- 复习页使用静态 Icons8 图标，卡组栏全高直角且不提供折叠，今日页热力图与优先补强上下排布，卡片页新增树形卡组筛选与吸顶批量栏。
- 本轮只在 5173 dev 验证，未重建 `gaze-ui:personal`，owner 视觉签收未完成。

## 2. 问答页

- 点击左栏「问答」：不在聊天页时进入 `/platform/creatChat`；已在聊天页时切换会话栏（窄屏打开抽屉）。
- 新建对话与 `/platform/chat/:chatid` 共用 `ChatWorkspace`，桌面内联 260px 会话栏；会话栏默认展开，状态持久化；900px 及以下回退抽屉。
- 会话栏头部提供搜索入口；搜索页覆盖聊天主区域，显示会话标题与第一条用户问题，不生成摘要。首条用户问题依赖后端 `first_user_message`，当前 6152 旧镜像尚未返回该字段。
- 会话栏不提供网页/API 通道筛选；RAG/直连仍在输入栏。
- 引用详情面板：非窄屏 `position:absolute` 约束在聊天主区域，不覆盖顶栏/右栏/会话栏；窄屏保留 fixed 遮罩。面板打开期间隐藏会话栏折叠/展开按钮，并禁止「问答」入口切换会话栏。
- 定位波浪按「输入框左侧空白的一半」内缩；左栏展开时贴聊天列左边，折叠/全屏时右移。
- 非全屏聊天页内容左右各 32px 留白；全屏保持原 960px 内容宽。

## 3. 知识库

- 新建知识库改为 `/platform/knowledge-bases/new` 详情页；知识库设置改为 `/platform/knowledge-bases/:kbId/settings` 详情页；编辑器复用原分区导航与表单。
- 详情页背景使用米纸色 `var(--td-bg-color-page)`；内容区水平留白 64px，表单项间距 24px。
- 知识库详情齿轮、列表卡片设置、解析器设置、模型使用详情中的知识库引用均走设置详情页。
- 文件夹新建/移动弹窗挂载到 `.knowledge-layout`，`show-in-attached-element` 居中，遮罩 `blur(6px)`，不覆盖壳层。
- 分块设置页头改为普通文档流，去掉白底与吸顶。
- 模型选择器修复：第二次点击触发器可关闭下拉，不再只展开。
- FAQ 新建口径仍存在文档与实现的未决冲突，owner 选择暂不处理。

## 4. 复习页

- 页头删除「学习 / 复习」眉题；副标题改为「有节奏地复习，找出薄弱点」。
- 内容区桌面 padding `28px 48px`，760px 以下 `16px 20px`。
- 今日页：左侧 200px 卡组栏贯穿内容区上下、四角直角、不提供折叠；热力图与今日优先补强上下排布；任务卡上方两角直角。
- 卡组新建：移除底部「新建卡组」；「全部卡组」行菜单提供新建卡组，各卡组行菜单提供新建子卡组。
- 卡片页：卡组筛选改为按钮 + 树形弹层，默认只显示顶层，可逐级展开；选中深层卡组自动展开父级；弹层与筛选框同宽左对齐、上边无缝、直角、滚动条隐藏但保留横纵滚动。
- 卡片页：移除顶部卡片数量与新建按钮加号；面板与列表上方两角直角；批量栏 `position: sticky; top:0`、四角直角；修复 TDesign tabs 的 `overflow:hidden` 导致 sticky 失效。
- 图标：复习页内容/装饰图标替换为 Icons8 静态透明 PNG；TDesign 组件自带图标保留；移除动态 GIF、白底与重影；署名改为 `Icons by Icons8`。
