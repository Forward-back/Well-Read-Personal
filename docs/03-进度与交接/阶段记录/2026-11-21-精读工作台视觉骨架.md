## 1. 范围与结论

按 owner 提供的精读工作台原型与 grill 对齐结果，先完成前端视觉与交互骨架：

- 页内 48px 页头：文档名、工作台/创建配置切换、进度、导出菜单、报告、暂停、停止。
- 三栏：256px 章节目录 + 本会话摘要；680px 阅读流；312px 笔记。
- 进入工作台自动全屏；配置视图自动退出全屏；窗口宽度不足 1100px 时右栏收抽屉，760px 以下左栏也收抽屉。
- 主栏：编号思考链路（原始推理抽屉）→ 本轮 conclusions → 行内问题（候选/自写/提交）→ 阶段理解确认 → 矛盾卡；移除旧全文左栏与「本轮产出」摘要。
- 当前章节原文改为覆盖抽屉，复用知识库的 `DocumentPreview` 渲染；抽屉最大为页面宽度的一半，可拖拽调宽并记忆宽度，拖拽到遮罩区松手不会关闭；受保护图片补载，缺失相对路径图片隐藏；全屏预览按钮位于抽屉页头右侧。
- 左栏章节目录按标题级别生成树：文档名为根，二级/三级/四级标题逐级展开，重复标题合并；结论引用改为 `[n]` 角标 + 结论下方编号来源，标题去除 Markdown 标记。
- 创建配置：文件树选文（根为知识库，逐级展开文件夹与文档；搜索框默认全局搜索）、已选文档实时列表、深度行、目标 chips、确定性预估、草稿列表（localStorage 演示）。
- 页面级 Notion/Morandi token：3/4px 圆角、发丝线、无阴影；品牌绿只做主行动，内容按语义使用鼠尾草/雾霾蓝/燕麦/陶土/藕紫；深色映射同步。

## 2. 当前实现与限制

已完成前端骨架与现有接口适配：

- 目录、会话摘要、笔记 tabs、原文抽屉、报告编辑与导出继续使用现有数据。
- 行内作答调用现有 feedback 接口，只记录答案；LLM 判定、三份候选答案待后端接口。
- 阶段确认、笔记确认/编辑/驳回/恢复、停止终态为本地演示状态；跨页刷新会回退。
- 草稿保存在 localStorage；跨知识库后端仍限制单库；“从本章继续”仍为提示。
- `type-check`、597 项测试、`npm run build` 通过；5173 实测工作台/配置/全屏/600px/深色/原文抽屉/行内作答/阶段确认/草稿保存通过，控制台 0 错误。
