## 1. 结论

复习主路由已切到 V3，`gaze-ui:personal` 已重建并部署。卡片页与统计页从占位替换为可用页面：

- 卡片页：56px 紧凑行、服务端搜索/状态/卡组/标签/仅今日到期筛选、批量删除/移动/追加标签/重置（上限 100）、表现抽屉（四档计数、近期忘记率、连续忘记、历史）、立即复习、单卡编辑与重置、新建卡片（带知识来源）、删除卡片恢复。
- 统计页：全局口径四 KPI、四档分布与趋势、7 天到期预测、遗忘曲线、卡组排行、优先复习建议、四档会话历史、CSV（`easy_count` 放末尾）。
- V2 页面保留为隐藏路由 `/platform/review-v2`，不进入侧栏；生成、合并、重绑孤儿、JSON 导出等能力暂留在该页，待对等批处理后再删。

验收中发现并修复一个真实后端缺陷：批量删除写入 `deleted_at`，但列表查询未使用 `Unscoped`，导致「已删除」筛选永远为空、恢复入口不可用。修复后 repository 测试覆盖「已删除可见、正常过滤隐藏、恢复后暂停」。

## 2. 本批改动

- 路由：`/platform/review` 指向 `ReviewV3.vue`（name `review`）；`/platform/review-v3` 重定向到主路由；簇详情改为 `/platform/review/cluster/:rowGroupId`，旧路径重定向；V2 挂在 `/platform/review-v2`（name `reviewV2Legacy`）。
- 新增 `ReviewCardsView.vue`、`ReviewStatsView.vue`，按 tab 异步加载；切 tab 自动回到顶部。
- 卡片页复用现有 `/api/v1/review/*`：列表、批量、重置、表现、创建、编辑、状态、删除/恢复、知识库与文档选择。
- 后端 `ListCards` 在显式请求 `deleted` 状态时使用 Unscoped；新增 repository 测试。
- 真实验收脚本：新增 `review_v3_cards_stats_acceptance.js`；已有 V3 验收脚本改指主路由；`review_v3_skeleton_acceptance.js` 改为等待真实卡片/统计页。
- 验收 README 增加卡片/统计脚本说明。
