# 旧壳退场与共享壳层

> 状态：当前
> 日期：2026-11-18
> 关联：[ADR 0007](../../06-架构决策/0007-PostHog布局语言落地页与壳层改造.md)、[落地页设计](../../02-需求与设计/落地页设计.md)、[界面规范](../../02-需求与设计/界面规范.md)、[当前进度](../当前进度.md)、[个人头像设置](2026-11-18-个人头像设置.md)

## 1. 范围与结论

本轮把旧 `views/platform/index.vue` 壳层退场，落地页与所有 `/platform/*` 详情页统一到新的共享 `AppShell`。旧 Menu、AppTopBar、AppRightRail、GardenKeys 代码与引用删除；旧手绘图标与草地资源文件保留，但不再用于壳层。

结论：

- `/` 是落地页，`/welcome` 重定向 `/`；登录成功默认进 `/`，带安全 `redirect` 时回原业务页。
- 共享布局为「顶部品牌栏 + 左侧功能图标栏 + 右侧辅助栏 + 中央应用窗」。
- 设置从左栏移除，只保留右栏入口；设置路由按普通详情页渲染，不再弹遮罩。
- 详情页支持顶栏全屏/退出；壳层滚动条视觉隐藏；浅色详情底统一为暖米纸色 `#F7F5F0`。
- 品牌选中/高亮恢复亮绿 `#07c05f`，不再使用深绿 `#067a3d` / `#056a34`。
- 暗色模式保留，壳层与落地页均跟随 `html[theme-mode]`。

## 2. 布局设计

- 顶栏：40px 浮动条，距顶部/左右各 8px；左侧 WellRead serif 字标；右侧详情页全屏/退出按钮与个人设置头像。
- 左栏：112px 宽；首页 + 问答、知识库、精读、复习、技能；问答点击打开会话抽屉，不直接重置当前会话。
- 右栏：112px 宽；帮助、设置、主题切换、GitHub、回到顶部、退出登录。
- 中央窗：80%×95%、20px 圆角、max-width 1200px；内容在窗内滚动；浅色窗底 `#F7F5F0`，暗色使用壳层暗色 token；外层保留草地背景。
- 设置不再占用左栏；右栏设置进入 `/platform/settings`，详情页内没有遮罩层和关闭按钮。
- 旧窗口栏、全屏/关闭两个悬浮按钮、八键装饰与旧 Menu 会话列表不再存在。

## 3. 详情页设计

- 详情页根节点填满中央窗内容区（`height:100%` / `flex:1`），页面内部自行滚动；壳层内容容器为 flex 列。
- 全屏与退出：顶栏右侧单按钮切换；未全屏显示方形图标，全屏显示 X 图标。全屏时隐藏左右栏，窗口从顶栏下沿（距视口顶 48px）开始，左右各 8px 与顶栏对齐，底部贴到视口底；顶栏下方两角改直角。退出全屏恢复居中窗、圆角与左右栏。
- 新建对话页：标题距窗顶 48px；推荐问题区可滚动；输入框 `margin-top:auto` 常驻页面底部，底部保留 24px 留白。
- 聊天页：`.chat` 与 `.chat_thread` 使用 `flex:1; min-height:0` 填满高度，消息区内部滚动，输入框始终贴底，底部保留 20px 留白；移除旧的 `calc(100vw - 260px)` 与 `min-width:400px` 侧栏假设。
- 问答会话抽屉：网页/API 是同一会话列表的来源筛选；网页为页面内创建，API 为外部 API/MCP/Agent 创建。支持新建、打开、置顶/取消置顶、重命名、清空消息、删除；不再包含退出登录。
- 设置页：普通详情页；页面内「模型未配置」「联网搜索」等深链接仍使用设置弹窗模式。
- 壳层内所有元素的滚动条视觉隐藏（Chromium/Firefox），滚轮、触控板与拖拽滚动保留。

## 4. 品牌绿规定

- 选中卡片、分段控件、标签与高亮文字统一使用亮绿 `#07c05f`。
- 选中背景 `#e9f8ec`；hover `#08dd6e`；active `#06b04d`。
- 不使用深绿 `#067a3d` / `#056a34` / `#044f27` 作为选中文字或图标；这些颜色不再是壳层高亮 token。
- 实心主按钮如白字对比度不足，可局部使用更深的填充色；不要为了按钮对比度回改全局高亮 token。
- 暗色模式使用自己的浅亮绿（`#53d98d` / `#7be0a7`），与浅色 token 分开。

## 5. 代码变更

- 新增 `views/shell/AppShell.vue`：共享布局、全屏状态、会话抽屉入口、全局设置弹窗、命令面板、上传/拖拽、主题切换与移动导航。
- 新增 `views/welcome/WelcomeHome.vue`：从旧落地页提取内容，移除自带壳层，接入共享窗滚动。
- 新增 `components/layout/SessionDrawer.vue`：网页/API 会话列表与操作。
- 删除 `views/platform/index.vue`、`components/menu.vue`、`components/layout/AppTopBar.vue`、`components/layout/AppRightRail.vue`、`components/layout/GardenKeys.vue`、`components/UserMenu.vue` 及旧 Menu 会话分组 helpers/tests。
- 路由：`/` 共享壳层 + 落地页；`/platform/*` 作为子路由；`/welcome` 重定向 `/`；登录默认 `/`。
- 设置页：新增页面模式；仅非设置路由保留弹窗模式。
- 品牌绿/暖米纸/滚动条/全屏/输入区样式更新见 `AppShell.vue`、`WelcomeHome.vue`、`Settings.vue`、`creatChat.vue`、`chat/index.vue`。

- 最近一批 UI 细化（设置页模式、全屏、亮绿、滚动条隐藏、聊天/新建对话输入区、左栏设置移除）尚未重新执行 `type-check` / `build`，也未重建前端镜像。

- 设置弹窗模式仍供页面内深链接使用；从右栏进入设置走普通详情页。
