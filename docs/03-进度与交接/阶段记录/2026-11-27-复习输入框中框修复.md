# 复习输入框中框修复（2026-11-27）

> 状态：当前
> 最后更新：2026-11-27
> 关联：[当前进度](../当前进度.md)、[界面规范](../../02-需求与设计/00-通用与界面/界面规范.md)、[验证记录](../验证记录.md)

## 1. 问题

复习页新建/编辑卡片、卡片组选择等位置，TDesign 输入框/选择器/文本域聚焦时出现「框中框」：外层是 TDesign 控件的 1px 焦点边框，内层又有一圈 2px 描边。owner 要求去掉内框并排查全站同类组件。

## 2. 原因

不是 TDesign 重复画边框，而是两层焦点样式同时作用在不同 DOM 层级：

- TDesign Input/Select/Textarea 的外层控件（`.t-input`、`.t-textarea__inner`）负责 1px 边框与焦点边框；Select 内层还有一个原生 `<input class="t-input__inner">`。
- 复习页在 `review-ui.css` 用 `.review-v3 :focus-visible` / `.review-mode :focus-visible` 给所有后代加 `outline: 2px solid #5a7688`。键盘聚焦或文本输入聚焦时，内层原生 input/textarea 也命中该规则，形成第二层框。
- 同类问题会在任何「TDesign 控件 + 页面级 `:focus-visible`」组合中出现；自定义 `.rv-input/.rv-textarea/.rv-select` 已有边框与焦点底色，同样不需要 outline。

## 3. 修复

- 在 `review-ui.css` 的全局 focus-visible 规则后增加高优先级复位：复习作用域内的 `.t-input__inner`、`.t-textarea__inner` 以及 `.rv-input/.rv-textarea/.rv-select` 聚焦时 `outline: none`；按钮等非表单控件仍保留 outline 作为键盘焦点提示。
- 在 `theme.css` 增加全局兜底：`.t-input__inner`、`.t-textarea__inner` 的 `:focus` / `:focus-visible` 不再画 outline；焦点视觉由 TDesign 外层控件的边框承担。TDesign 原有细绿焦点边框保留，无障碍焦点仍可见。
- 输入框、选择器、文本域现在只保留一层边框；Select 下拉、文本域、编辑卡片实测无框中框。

## 4. 验证

- `cd frontend && npm run type-check`：通过。
- `review_v3_mode_acceptance.js`（5173，mock）：全步骤通过，控制台 0 错误。
- 浏览器实测：新建卡片卡组选择聚焦后内层 input `outline` 为 none，外层仅 1px 焦点边框；编辑卡片文本域聚焦后 `outline` 为 none，仅保留 1px 边框。
- 未做全站逐页截图；全局兜底只影响 TDesign 内层原生输入，按钮与链接焦点未改。
- owner 于 2026-11-27 确认视觉打磨到此为止。

## 5. 边界

- 不改变 TDesign 组件的边框、圆角与焦点色，只去掉重复的内层 outline。
- 自定义无边框输入仍需自行提供 focus-within 样式；本次只复位已有边框的复习输入壳。
