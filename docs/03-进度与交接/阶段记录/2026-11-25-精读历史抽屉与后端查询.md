# 精读历史抽屉与后端查询（2026-11-25）

> 状态：当前
> 最后更新：2026-11-25
> 关联：[当前进度](../当前进度.md)、[交互式精读](../../02-需求与设计/03-精读/交互式精读.md)、[界面规范](../../02-需求与设计/00-通用与界面/界面规范.md)

## 1. 范围

把原本混在问答会话抽屉里的精读历史迁到精读页面，并提供精读专用的非进行中运行列表、卡片详情、重命名与打开能力。

## 2. 后端

- 新增 `GET /api/v1/reading/runs/history`。
- 仓库新增 `ListHistoryRuns`：按 tenant/user 过滤，只查 `finished`、`stopped`、`abandoned`，按 `updated_at DESC`，默认 50 条、上限 200。
- 服务新增 `ListHistory`：补充关联会话标题、文档摘要（标题/文件名/知识库）、阅读进度、目标与深度。
- 无迁移、无新增表、无字段变更。
- 重命名不加精读字段，复用 `PUT /api/v1/sessions/:id` 更新关联会话标题。
- 热重载后端已编译 282 路由；正式 `gaze-app:personal` 镜像仍为 2026-11-24 版本，不含该接口。

## 3. 前端

- 精读顶栏在「精读工作台 / 创建配置」右侧新增「历史」按钮。
- 右侧历史抽屉：
  - 卡片显示名称、状态、日期、已读/总章节、文档数量。
  - 点击卡片展开文档列表、阅读目标、阅读深度与「打开精读」。
  - 「重命名」内联编辑，保存后更新会话标题。
  - 左边缘支持拖拽拉伸，范围 320–760px（且不超过视口 80%），支持方向键调整，宽度写入 localStorage。
  - 空态、加载失败重试、标题与文档名省略。
- 打开历史运行后写回 `run_id` 查询参数并加载该运行。
- 问答会话抽屉过滤带 `reading_run_id` 的会话，不再混入问答历史。

## 4. 验证

- 5173 冒烟通过：历史抽屉打开、18 条历史列表、卡片展开、打开历史运行并进入工作台，控制台 0 错误。
- 前端 `type-check` 通过；后端仅热重载编译通过，未跑后端单元/集成测试。
- 抽屉拉伸与最新前端未跑自动化测试，未重建镜像。

## 5. 已知边界

- 历史只含 `finished/stopped/abandoned`，`failed` 不进入。
- 名称复用会话标题，改名只影响该会话；问答端已隐藏精读会话。
- 问答端过滤在分页数据上执行，精读会话较多时页大小与总数可能不完全一致。
- 历史接口未写 Swagger 注解。
