## 1. 范围

本批处理 P0-A8 owner 视觉对齐中的复习页：以 `视觉效果参考.html` 为方向，采用透底 Notion 块与品牌淡绿/莫兰迪配色。按 owner 要求，视觉阶段统一在 Vite dev server `http://localhost:5173` 查看，不逐项重建前端镜像；生产镜像仍为对齐前版本。

## 2. 已确认规则

- **Notion 骨架**：内容直接落在壳层画布上，不新增白色页面底板；块用 1px 细边框、6/10px 小圆角、留白分区；阴影只留给模态与下拉/浮层。
- **交互高亮**：所有点击与交互高亮（tabs、分段控件、选中行、焦点环、主 CTA）统一品牌亮绿 `#07c05f`，选中底 `#e9f8ec`，hover `#08dd6e`，active `#06b04d`；莫兰迪色不替代交互高亮。
- **辅助配色**：莫兰迪色用于严重/警告/观察、图表与装饰；参考中的鼠尾草绿不是交互高亮色。
- **全窗口口径**：新建卡片、编辑卡片、卡片表现、从知识库生成复习卡改为铺满复习详情区的页面视图，不弹小窗；是否全屏由壳层全屏按钮决定。立即复习的会话同样占用详情页，不再强制视口全屏。
- **横向舒展**：去掉 760/880/960/1440 窄列限制，表单、卡片表现、生成页、统计块按详情页宽度左右对齐。

## 3. 已落地

- 复习页 token：Notion 中性色、品牌绿、莫兰迪语义色、暗色映射；TDesign 品牌与状态变量在复习页作用域内覆盖。
- 页头、tabs、今日任务的淡绿 callout、卡组灰面板、热力图/优先补强/统计块的细边框与留白；统计 KPI 图标底透明，图表换莫兰迪色板。
- 卡片页：新建/编辑/卡片表现改为内联详情页并带返回；编辑前关闭表现页，避免被覆盖。
- 从知识库生成复习卡改为内联详情页；复习会话改为替换 tabs/列表直接占用详情页，修复列表从下方透出的问题。
- 下划线样式统一：复习 tab 激活使用品牌绿；所有 `box-shadow` 在复习页内移除，分组筛选下拉保留浮层阴影。
- 规则同步写入[界面规范](../../02-需求与设计/00-通用与界面/界面规范.md) §3.1 与 CLAUDE.md。
