# 页面顶栏与视觉收口（2026-11-25）

> 状态：当前
> 最后更新：2026-11-25
> 关联：[当前进度](../当前进度.md)、[界面规范](../../02-需求与设计/00-通用与界面/界面规范.md)、[技能页原型复刻](2026-11-25-技能页原型复刻与莫兰迪配色.md)

## 1. 范围

按 owner 反馈继续做页面级视觉优化。视觉优化转为常驻流程：每次结合真实页面反馈小步调整，不再以单批视觉签收作为结束条件。

## 2. 全局容器

- 非精读页面统一使用中央应用窗内容容器：最大宽 1200px、居中、左右 `padding: 24px`。
- 精读工作台保留自身三栏版心。
- 复习页原 10% 内边距由壳层容器接管，不再叠加。
- 页面直接铺白底；组件保持实色、发丝线，不引入阴影体系。

## 3. 页面顶栏

- 新增共享 `PageTopbar`：48px 高、底部发丝线、左侧标题/副信息、右侧操作。
- 标题与副信息 `min-width:0 + ellipsis`；操作区 `flex:none`；≤760px 自动换行，操作区横向滚动且隐藏滚动条。
- 复习：标题为当前视图名；今日/卡片/统计移到右侧，去掉左侧小字说明，标题 16px。
- 技能：标题「技能」+ 数量摘要 + 右侧「添加技能」。
- 知识库：面包屑作为左侧主信息，操作按钮右侧；副标题与解析/存储提示移到顶栏下方；长知识库名省略。

## 4. 对话页

- 推荐问题去掉卡片边框/底色/阴影，改纯文本网格；3 列，≤960px 两列，≤600px 单列。
- 取消两行截断与横向裁切，长问题自动换行。
- 欢迎区顶部 96px、组间距 48px；输入框下移后底部留白约为调整前一半。

## 5. 技能编辑器

- 正文复用知识库文档全文 Markdown 渲染（marked + GFM + KaTeX + highlight.js + 清洗）。
- 编辑/预览固定高度、各自内部滚动，滚动条隐藏。
- Markdown 框支持页内全屏：覆盖中央应用窗内容区，不覆盖顶栏与左右栏，按钮或 Esc 退出。
- 技能页配色为白底 + 莫兰迪灰绿/沙黄/陶土；编辑器字号与行高提升。

## 6. 验证

- 1440px、600px 下顶栏无横向溢出；复习/技能/知识库顶栏高度 48px。
- 推荐问题无边框、透明底、无阴影，无横向溢出。
- 技能 Markdown 预览生成标题、列表、代码块、表格；编辑/预览独立滚动；页内全屏尺寸与 `.app-window__content` 一致。
- 前端 `type-check` 通过；最新一批未复跑测试与生产构建，未重建 `gaze-ui:personal`。

## 7. 边界

- 顶栏内部仍按各页业务保持不同操作，不强行统一按钮。
- 视觉优化常驻；后续页面细节继续按 owner 反馈调整并更新本记录或新阶段记录。
