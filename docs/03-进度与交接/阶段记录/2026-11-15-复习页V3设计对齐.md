## 2. 关键决策

1. **四档评分**：忘记、想得慢、想起来、秒答。秒答稳定度 ×5、等级 +2（封顶 L6）；忘记重置稳定度 5、回 L0、次日到期；想得慢 ×1.5；想起来 ×3 +1。
2. **秒答独立统计**：保留率 =（想起来 + 秒答）/ 总评分次数；历史会话秒答按 0，不反推。
3. **取消自动暂停**：`lapses >= 3` 不再自动暂停。严重卡保持 active，由漏洞规则标记；手动暂停与孤儿仍排除；历史自动暂停卡由用户显式恢复。
4. **今日队列**：到期 + 新卡；到期优先，新卡最多 20，总量最多 100；手动与补强会话不占每日额度。
5. **漏洞簇**：卡组 × 列；列优先标签，无标签回退来源文档标题，再无来源归「未分类」；多标签卡分别计入各列，分母允许重叠。
6. **加权强度**：严重 1、警告 0.5、观察 0.25、健康 0、暂无数据 0 但计入分母；60% / 40% / 20% 分四档；簇级别再与簇内最高卡级别取较高者，避免单张严重/警告卡被新卡稀释后隐藏；无已复习卡为「暂无数据」。
7. **优先补强**：最多 3 条严重/警告簇；全站最多 3 个簇获得视觉强调，热力图仍全量着色；观察簇只显示数量摘要。
8. **补强会话**：从簇详情发起，N = 严重 + 警告卡；观察与健康卡不进入；立即开始手动会话，不改变今日队列。
9. **会话冲突**：已有 active 会话时，从簇或抽屉发起新会话必须弹层二选一「继续当前 / 放弃并开始补强」；不得静默返回旧会话。
10. **批量与重置**：批量删除/移动/追加标签/重置，上限 100，全量校验后单事务执行，任一失败整批失败；删除软删除，重置只改调度字段。
11. **TDesign 路线**：全前端统一 TDesign；Tailwind 只做布局与间距；禁止新增 shadcn/reka 依赖；V3 替换后删除 `src/components/ui`、`components.json` 与相关依赖。
12. **视觉与术语**：品牌绿只用于主 CTA、选中、进度与关键数据；状态色小面积使用；界面不直出 L0/L1、稳定度、D/S/R；不使用 emoji。

## 4. 边界情况确认

- 所有卡未复习或只有新卡：热力图全部「暂无数据」，提示完成一次复习，并提供批量打标签入口。
- 簇内部分卡已复习：未复习卡计入分母、权重 0，强度被稀释；tooltip 说明总卡数。
- 超过 3 个严重簇：热力图全量着色，优先补强只取前 3，其余仍可点击。
- 多标签卡：进入每个标签列，百分比不可相加；tooltip 说明重叠。
- 文档标题重复：按来源 ID 分列，不合并；标题过长截断并 tooltip。
- 来源失效：先用下一条 active 来源；全部失效为孤儿，不进入热力图，回原文禁用并提示。
- 手动暂停与历史自动暂停：不计入热力图与队列；历史自动暂停不静默恢复。
- 评分重复提交：前端立即禁用；服务端按会话与客户端请求 ID 幂等。
- 评分失败：保留当前卡与翻面状态，显示重试，不自动进入下一张。
- 会话中卡被删除/暂停/转孤儿：返回冲突，前端提示跳过并继续剩余队列。
- 跨 04:00：旧会话过期，未完成卡回队列；历史保留。
- 批量部分卡失效：整批失败，不做部分成功；刷新后重试。
- 追加标签超 10 个：整批失败并提示数量，不静默截断。
- 重置进度时卡在会话中：允许重置；会话快照保留，后续评分从重置后状态起算。
- 统计样本不足：保留模块与卡片位，显示明确阈值文案；保留率无评分显示「—」；到期预测全 0 不画柱。
- 600–760px：今日页单列，热力图与簇详情表格横向滚动；600px 以下不承诺布局但不得脚本错误。
- 控制台 0 错误；加载失败显示重试，不显示空白页。
