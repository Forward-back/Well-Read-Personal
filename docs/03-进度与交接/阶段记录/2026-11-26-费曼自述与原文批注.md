## 4. 已知边界

- 费曼评估只依据当前章节原文；跨章节综合的复述可能被判遗漏，属刻意限制。
- 批注按 quote 锚定，不做字符区间持久高亮；重复文本按首次匹配章节/分块保存。
- 批注生成卡片默认以批注正文为题、quote 为答案，用户可在弹窗中修改；重复题面仍走既有复习卡吸收规则。
- 费曼结果注入提示词但不写入长期 run memory；历史记录保留在独立表与报告中。
