## 4. 风险与已知边界

### 4.1 精读

- 2026-11-22 精读契约代码未部署：迁移 6 未应用、Swagger 未重生成、完整后端容器测试未通过，真实链路未验收。不得把源码编译通过当成功能完成。
- 精读问题判定在反馈请求内同步调用模型，可能增加作答等待；判定失败保留答案并允许重试，但尚未做真实模型超时/降级验收。
- 章节跳转会把目标章节及之后章节重置为未读，用于“从本章继续”；这是刻意的进度回退，不得改为只移动光标而不影响自动推进。
- 精读agent P0 仍是规划；必须先完成现有精读后端契约验收，否则逐条裁决、候选答案与理解档案会重复建接口。
- 精读agent 将把“精读模型必须支持 thinking”改成按角色判定：抽取模型可非 thinking，综合模型必须 thinking；实施时同步改设置文案、校验与测试。
- 精读 `state_version=3` 与旧结构化运行并存；旧运行不得被强制迁移，新分支测试必须覆盖 v2 继续 Step/Feedback。

### 4.2 复习 V3

- `/platform/review` 为 V3；V2 页面、shadcn 依赖与 Tailwind token 已删除，不得恢复 V2 路由或引入第二套组件库。
- 漏洞警告使用最近窗口；历史“曾经忘记一次”的卡可能降为健康，这是刻意修复，不得恢复永久 `lapses` 规则。
- 热力图默认 8 行/10 列，超出合并 other；展开上限 50/30，other 不可点。不能把 other 当完整覆盖，也不能一次拉全量卡组×文档。
- 热力图多标签卡进入多个簇，各列分母重叠；界面必须用 tooltip 说明重叠规则。簇级别与强度可能不一致，必须同时显示强度与级别。
- 取消自动暂停是刻意设计：严重卡持续进入队列与热力图；历史暂停卡不会静默恢复，孤儿重绑与恢复卡均保持暂停。
- 拆分后原卡暂停且无 lineage；派生关系只能靠来源与标签追溯。
- 软删除恢复默认隐藏已删除卡；只有显式筛选 `deleted` 才使用 Unscoped，恢复后状态为 `suspended`。
- 真实 daily 验收脚本会跳过其他 active 会话，避免误写 owner 正在进行的复习；任何写真实调度的脚本先确认归属。历史曾误开 owner 会话并写入一条评分，已按日志精确回滚，脚本已补保护，见[阶段记录](阶段记录/2026-11-17-复习V3对等与清理.md)。
- 复习页视觉验收仍未通过；TDesign 重写后必须由 owner 实机或截图确认。

### 4.3 部署与数据

- 个人版要求全新数据库；旧企业库不能原地升级。升级前备份 PostgreSQL、SQLite、`data-files`、外部 MySQL 与 `data/rag/faiss_index.bin`。
- `RAG_DATA_DIR`/`LOCAL_MODELS_DIR` 必须正确挂载；`data/rag/` 不进入 git/镜像，删除后模型与索引需要重建。
- RAG 只接收 App 分块；没有 `chunks` 的 `/ingest` 会 400。不要再恢复 RAG 侧解析/分块。
- RAG 不接收 ACL/部门/密级；范围过滤只有知识库/文档白名单。
- FAISS HNSW 不支持物理删除；大量删除或向量错位后运行 `rebuild_faiss.py`。
- 上传背景原图存 `app_data-files` 卷的 `backgrounds/<userID>/`，不压缩、单张 ≤10MB、最多 10 张；重建数据卷会丢失上传背景。
- 本地 Docker 构建依赖 daemon `mtu=1400` 与 `--network=host`（docreader/ylsw）；换机器需重新确认。
- Windows 本机 Go 测试可能因 duckdb/gojieba CGO 失败；后端测试以 Linux 容器结果为准。

### 4.4 安全、UI 与外部接入

- 平台壳层最小宽度 600px；移动端与推送通知不在当前范围。
- MCP 工具面固定 17 个，知识面只读、会话面仅自有会话；不新增知识写入、模型、租户或共享空间工具，精读读取工具不纳入当前路线。
- `.env`、模型 Key、数据库口令、owner 初始密码不得进入 git、日志与文档；单 Key 只显示掩码。
- UI 组件统一 TDesign；复习 V3 是 TDesign 页面结构与漏洞交互的参考实现，不启动其他页面的 shadcn 迁移。
- 直连模式必须配置开启思考的问答模型；未配置时直连不可用。
