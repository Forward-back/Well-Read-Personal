# 页面与提示词

> 状态：规划
> 最后更新：2026-11-01
> 目标读者：前端、后端、产品、测试
> 关联：[需求与范围](需求与范围.md)、[数据模型与认证](数据模型与认证.md)、[实施计划与验收](实施计划与验收.md)

## 1. 页面总原则

- 个人版只服务一个使用者，界面不表达“谁被授权看到什么”，只表达“我的知识在哪里、我要怎么读”。
- 侧栏固定五项：问答、知识库、精读、技能、设置。登录后默认进入问答。
- 不设独立运维工作台、治理页、管理页、共享空间页；企业页面直接删除，不做隐藏入口。
- 所有页面不再出现角色、部门、成员、共享、ACL、发布、审批、审计、CR、reviewer 等概念。
- 能力码从路由与菜单移除；路由只区分是否需要登录。
- 保留现有视觉语言与组件体系，减少无必要的重绘。

## 2. 页面结构

### 2.1 登录页

- 只保留登录表单与产品介绍。
- 删除注册、邀请注册、OIDC 按钮、组织加入、工作区选择。
- 文案改为个人阅读助手语境，明确“本地部署、数据只在本机”。
- 首次启动无 owner 时，由后端用环境变量创建；登录页不承担创建流程。
- 登录成功直接进入问答，不进入 onboarding 或工作区选择。

### 2.2 问答

保留现有问答主流程，目标结构：

| 区域 | 内容 |
|---|---|
| 左侧 | 新对话、历史会话、删除会话 |
| 中间 | 消息流、流式回答、引用卡、追问输入、停止生成 |
| 引用抽屉 | 引用文档、片段、打开文档、精读选中文档 |
| 范围选择 | 默认“全部知识库”，可切换单个知识库 |
| 技能选择 | 选择个人已启用技能，可选择不使用技能 |

要求：

- 默认跨全部知识库检索；切换单库后，当前会话后续检索限定在该库，并明确显示范围。
- 回答必须带可定位引用；引用卡不得显示“依据版本/权限”以外的企业概念。
- 引用抽屉中的“精读这些文档”保留，进入精读时自动带入文档。
- 历史会话、会话重命名、删除、检索 trace 入口保留；不显示部门、共享、可见范围。
- 删除“共享空间”“治理”“管理”等侧栏入口，也删除聊天页中的成员、@提醒、审批类按钮。
- 不新增收藏、分享链接、导出对话等当前没有的能力。

### 2.3 知识库

保留多知识库与文档管理能力，但所有操作都在 owner 权限下直接生效。

#### 知识库列表

- 新建、复制、打开、删除知识库；删除需二次确认并说明会删除文档、版本与索引。
- 不再显示共享状态、部门、可见范围、发布状态。
- 知识库卡片菜单保留设置与删除；不再按角色隐藏。

#### 知识库详情

- 文件夹树、文档列表、标签、元数据、解析状态、批量操作。
- 文档上传、网页导入、手工录入、重新解析、编辑、删除。
- 归档与回收站：归档文档默认不参与检索；回收站可恢复或彻底删除。
- 不再有生命周期日期、生效/废止、定时流转状态。
- 不再有共享管理、发布、库内权限、ACL 页签。
- 文件夹与文档操作直接生效，不再校验角色或 ACL。

#### 文档详情与编辑

- 文档正文编辑、分块查看、元数据、标签、引用来源。
- 保存前自动生成版本快照；重新解析前也生成快照。
- 版本列表保留最近 50 个，支持对比与回滚；可手动清理旧版本。
- 删除 CR 提交、评论、issue、审批、合并、chunk 锁入口。
- 版本对比只服务个人回溯，不再出现 reviewer、审批状态、合并门槛。

#### 知识库设置

个人版中知识库设置统一归 owner，页签合并为：

- 基本信息
- 模型
- 解析
- 分块
- 图像与多模态
- 高级
- 存储
- 数据源

删除共享管理与库内权限。知识库内可直接选择已配置的模型、解析器和存储；设置页不再跳转独立运维台，而是跳转全局设置对应分区。

### 2.4 精读

保留完整精读工作台，删除企业权限与治理语义。

- 入口：精读侧栏、问答引用抽屉、知识库选中文档。
- 开始页：选择文档、三档深度、确认阅读计划。
- 工作台：左栏全文、中间逐步阅读与提问、右栏笔记与引用；自动推进、暂停、停止、恢复。
- 问题卡、矛盾裁定、报告编辑、版本、Markdown/JSON 导出保留。
- 删除 shared-in 精读、逐文档 ACL 复核、部门看板精读聚合、阅读审计与管理员批量迁移入口。
- 导出覆盖统计按实际读取章节计算，不再输出权限复核结果。
- 精读策略固定为个人阅读策略，不再读取部门技能；提示词改个人阅读语境。

### 2.5 技能

- 显示个人技能列表，支持新建、编辑、启停、删除、查看版本与哈希。
- 删除部门归属、可见范围、只读技能、per-skill grant、公司只读视图。
- 技能页只有 owner 可见，不存在“能看不能改”的状态。
- 问答技能选择器只列出已启用技能；删除“部门启用”与授权提示。
- 技能模板中的企业术语必须替换为个人阅读与知识管理语境。

### 2.6 设置

侧栏设置入口进入单一设置页，五个分区：

#### 账户与助手

- 邮箱、用户名、修改密码、登出。
- 全局系统提示词编辑：默认内置个人阅读助手提示词，可恢复默认。
- 语言与基础偏好（沿用现有可保留项）。

#### 模型与引擎

- 模型供应商、模型目录、默认问答模型、默认精读模型、思考模型开关。
- Ollama、解析引擎、向量引擎、存储后端配置。
- 保留连通性测试；删除公司/部门级模型隔离与能力限制。
- 模型 Key 只显示掩码；编辑与保存需二次确认。

#### 外部接入

- MCP 服务说明与连接地址。
- 单一 API Key：生成、掩码查看、重置、撤销。
- 删除多 Key、能力范围、知识库白名单、Agent 管理面。
- 明确提示 MCP 为只读访问，Key 泄露需立即撤销。

#### 系统健康与队列

- 应用版本、启动时长、数据库迁移状态、解析服务状态、存储状态、模型配置状态、队列积压与失败任务。
- 知识索引健康：文档数、分块数、向量覆盖情况。
- 提供刷新与失败任务重试；删除系统审计、平台告警配置、账号运维、成员与部门设置。
- 可在设置内触发索引重建与生命周期清理的替代动作（归档清理、旧版本清理）。

#### 关于

- 版本、构建信息、开源许可、数据目录说明。
- 明确个人版定位与本地数据位置。

### 2.7 删除的页面与路由

以下页面与入口整体删除：

- 共享空间页。
- 治理台、公司看板、部门看板、审计日志页。
- 管理工作台、成员管理、部门管理、审计员管理、知识库设置委派页。
- `/ops` 运维工作台七个分区与双身份切换。
- CR 列表、CR 详情、CR 审批、issue 与评论协作页。
- 注册、邀请注册、组织加入、工作区 onboarding、租户切换。
- Settings 中的成员、部门、系统管理、技能只读等企业分区。

## 3. 文案与术语

### 3.1 必须删除的词

界面、提示词、空态、错误提示、帮助文案中不再出现：

- 公司、企业、组织、部门、员工、成员、同事、团队。
- 管理员、系统管理员、公司管理员、部门负责人、知识库管理员、编辑、只读成员。
- 共享、发布、可见范围、授权、权限、ACL、白名单、密级。
- 治理、看板、审计、合规、审批、驳回、合并、审阅人、审计员。
- 租户、工作区、空间切换、邀请、加入组织。
- “联系管理员”“申请权限”“无权限访问”等企业流程提示。

### 3.2 替换方向

| 原表达 | 个人版表达 |
|---|---|
| 我的工作台 | 我的知识库 / 首页 |
| 共享空间 | 删除，不替换 |
| 部门知识库 | 我的知识库 |
| 成员/用户 | 删除，不替换 |
| 知识库管理员设置 | 知识库设置 |
| 系统运维台 | 设置 |
| 公司治理 | 删除，不替换 |
| 审批通过后生效 | 保存后生效 |
| 无权限查看 | 删除，资源不存在时按不存在处理 |

## 4. 提示词改造

### 4.1 全局助手提示词

- 默认角色：个人阅读与知识管理助手，帮助用户理解、整理和回顾自己的资料。
- 语气：直接、清楚、可执行；不模拟企业客服或组织流程。
- 回答规则：优先使用检索到的文档；无法从资料确认时明确说明；引用必须可定位；不编造事实与出处。
- 不包含公司、部门、员工、合规、权限、审批等约束。
- 允许在设置页编辑全局提示词；技能可以在其范围内覆盖风格与任务指令，但不得突破引用与不编造规则。
- 提供“恢复默认提示词”。

### 4.2 问答提示词

- 保留指代改写、多轮追问、引用绑定与检索 trace。
- 删除部门、密级、ACL、共享范围等上下文注入。
- 默认全库检索时，提示词不声明“用户属于某部门”；单库检索时只说明当前资料范围。
- 不记录或展示原始问题用于治理；本地检索 trace 仅用于排障。

### 4.3 精读提示词

- 保留结构化阅读、五拍、三道门、问题卡、报告生成的既有能力。
- 删除 shared-in、部门限定、审计与管理员迁移相关提示。
- 阅读目标改为个人理解与笔记沉淀，不再出现“为部门输出结论”“合规复核”等要求。
- 导出说明只描述覆盖范围与局限，不输出权限复核结果。

### 4.4 技能模板

- 技能模板中的角色设定改为个人助手或特定任务助手。
- 删除部门、审批、共享、合规话术。
- 保留技能的可复用结构与启用/禁用逻辑。

## 5. 当前实现与差距

| 当前页面 | 目标 |
|---|---|
| 侧栏含新对话/知识库/精读/共享空间/治理/管理 | 五项：问答/知识库/精读/技能/设置 |
| 登录含注册、邀请、OIDC、工作区 onboarding | 只留密码登录 |
| 知识库含共享、发布、ACL、生命周期 | 删除，保留归档与回收站 |
| 文档编辑走 CR 审批与合并 | 直接保存，自动版本快照 |
| 精读含 shared-in、ACL 复核、部门聚合 | 个人精读，无权限复核 |
| 技能按部门与授权管理 | 个人技能库 |
| 独立 `/ops` 七分区 | 单一设置页五分区 |
| 治理与审计页面 | 删除，仅保留设置内健康摘要 |
| 企业提示词与文案 | 个人阅读助手提示词与个人化文案 |

## 6. 验收

- 侧栏只有五项，登录后默认进入问答；不存在共享空间、治理、管理、运维入口。
- 页面与路由中不存在角色、部门、共享、ACL、审批、审计相关按钮、页签与提示。
- 知识库可完成新建、导入、编辑、归档、回收站、版本对比与回滚。
- 问答默认全库、可切单库，引用可打开文档并进入精读。
- 精读可完成计划、推进、停止恢复、报告与导出，且无权限复核输出。
- 技能可新建、编辑、启停、删除并在问答中选择。
- 设置五分区均可打开并保存；模型、解析、存储、系统提示词、MCP Key、健康检查可用。
- 全局搜索前端源码，企业术语只存在于历史归档或迁移说明中，不出现在用户可见文案。
