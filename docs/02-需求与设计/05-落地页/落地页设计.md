# 落地页设计（Notion 极简语言）

## 1. 目标与非目标

目标：

- 以 notion.com 落地页为风格参考，做极简但不缺内容的登录后首页。
- 用大字号 Hero、产品实景预览、Bento 功能区、三步流程与使用场景，讲清「本地知识库 + 可引用问答 + 精读 + 复习」闭环。
- 动态线条流畅但克制：SVG 路径流动、浮动卡与滚动入场，尊重 `prefers-reduced-motion`。
- 图标美观：TDesign 图标 + 自绘 SVG 线性装饰，不引入第二套组件或图标库。
- 中英双语，文案只维护在语言包；保留真实业务跳转与提问预填。

非目标：

- 不复制 Notion 的 logo、插画、客户素材、文案或页面结构细节。
- 不重做共享壳层（顶栏、左右栏、中央窗）；不重做详情页。
- 不做公开营销站、SEO、注册、转化追踪或外部分析埋点。
- 不使用截图展示产品界面；产品预览用真实 DOM 自绘。
- 不引入 React、shadcn/reka、第三方图标包或第二套组件库。

## 2. 路由与入口

- `/`：共享 `AppShell` 内的落地页；`/welcome` 重定向到 `/`；登录成功默认进 `/`。
- 顶栏提供全屏切换；全屏后隐藏左右栏，落地页内容宽度扩到窗口的 `calc(100% - 48px)`，产品预览最大 1240px。
- 左栏「首页」指向 `/`；其余功能区仍走左栏与右侧辅助栏。
- Hero 提问提交后预填到 `/platform/creatChat`；建议问题点击填充输入框；场景卡与页脚入口跳真实功能页。

## 3. 页面结构

页面共七段，文字只做点缀与必要信息补充：

| 区块 | 内容 | 交互 |
|---|---|---|
| Hero | 超大标题「你的知识，随叫随到」、一句副文案、主/次 CTA、提问框与建议问题 | 提问预填跳转；次 CTA 滚到功能区 |
| 产品预览 | 左侧功能导航 + 聊天与引用示例；右侧浮动「知识库」「今日复习」卡；背景连接线流动 | 纯展示，不伪造可点击产品功能 |
| Bento 功能区 | 问答、知识库、复习、精读、MCP 五张卡片；每卡标签 + 标题 + 一句描述 + 迷你界面示意 | 卡片 hover 轻抬升 |
| 架构图 | 「平台架构 / RAG 架构」两张可交互图；透明底、莫兰迪淡色；Archify 渲染，内嵌 iframe | 点击节点查看 Passport 与关系；拖动平移、滚轮缩放 |
| 工作方式 | 收进来 → 查得到 → 记得住三步；背景虚线连接 | 滚动入场 |
| 使用场景 | 读论文、写代码、长期学习三张入口卡 | 点击进入对应功能页 |
| 收尾 CTA | 「让资料开始为你工作」+ 开始提问 / 创建知识库 | 跳问答与知识库 |

已删除：顶部徽标、Hero 底部小字、信任条、本地数据深色段、页脚。

### 3.1 文案约束

- 文字只做点缀与必要说明；不写与标题同义的段落，不写操作说明（如「点击节点查看关系」），不重复卖点。
- 区块标题用含具体信息的短句（≤12 字），不用空泛口号。
- Bento 卡片保留标签、标题与一句功能描述（≤20 字）；删除卡底元信息行。
- 提问框占位符只写「问点什么…」，示例由建议问题芯片承担。
- 中英两套文案同步维护，删除废弃词条。

## 5. 动效

- 背景流动线条：3 条低透明度 SVG 虚线路径，`stroke-dashoffset` 16–30s 循环；步骤区另有一条短连接线。
- 产品预览浮卡：7s 上下 7px 浮动，错开相位；不使用弹跳或夸张旋转。
- 入区动画：`IntersectionObserver` + 18px 上移淡入，0.55s；只在首次进入触发。
- Hover：卡片上移 2–3px、边框加深；按钮用 TDesign 状态。
- 架构图：Archify 生成的自包含 HTML 以 iframe 嵌入，透明背景 + 莫兰迪 token 覆盖；点击节点打开语义 Passport 并高亮关联边，支持拖动/缩放；embed 模式不显示完整工具栏。
- 性能与可访问性：`prefers-reduced-motion: reduce` 关闭所有路径/浮卡动画、取消平滑滚动与入场位移；无 WebGL、无视频、无 heavy 动效库。

## 6. 素材与图标

- 产品预览、图表、热力图与文件列表全部为真实 DOM/CSS，不使用截图。
- 架构图由 Archify 生成，源 JSON 与透明/Morandi 覆盖样式在 `docs/05-演示/架构图/`，产物在 `frontend/public/diagrams/`。重新生成时先运行 `deliver architecture`，再把 `embed-overrides.css` 注入产物 `<head>`；当前产物已注入。
- 图标使用 TDesign Vue Next 线性图标；品牌徽标、放大镜、闪光等使用自绘 SVG。
- 不使用 emoji、Icons8 动态图标或第三方图标包。
- 外层草地由共享壳层提供；落地页自身不新增位图装饰。
- DM Sans 字体文件自托管，已存在于 `frontend/src/assets/fonts/`。

## 7. 文案

- 全部落在 `welcomeHome.*` 语言包，中英各一套；语言切换即时生效。
- 中文标题：**你的知识，随叫随到**；主 CTA：开始提问；次 CTA：看看它怎么工作。
- 英文标题：**Your knowledge, ready when you are**；主 CTA：Start asking；次 CTA：See how it works。
- 功能卡标题：问得准，也答得有据 / 资料收进来就整理好 / 让重要的内容定期回来 / 长文慢慢读，边读边留下 / 对你的工具保持开放。
- 文案不出现公司、部门、成员、共享、ACL、审批、治理等企业概念；按 §3.1 控制层级与长度。

## 8. 验收

- 1440、1100、860、600px 无横向溢出；Bento 与场景卡按断点折叠。
- 主/次 CTA、建议问题、提问框与场景卡行为正确；预填到真实问答页。
- 中英切换后落地页全部文案跟随；暗色模式使用深色 token。
- 流动线、浮卡、入区动画正常；`prefers-reduced-motion` 下全部关闭。
- 文字层级符合 §3.1：无眉题、无重复说明、无操作提示。
- 控制台 0 错误；`npm run type-check`、`npm test`、`npm run build` 通过。
- owner 实测目视签收；自动化通过不等于审美通过。

## 10. 风险

- Notion 风格只迁移版式与视觉语言，不复制其品牌素材与文案；避免产生商标混淆。
- 大字号中文标题在不同字体回退下换行不同，需在 Windows/浏览器实测。
- 深色模式覆盖较多组件，后续新增区块需同时补深色 token。
- 动效使用 CSS/SVG，低端设备若出现掉帧，优先降低虚线动画与浮卡频率。
- 与 Notion 的视觉相似度属主观验收项，以 owner 签收为准。
