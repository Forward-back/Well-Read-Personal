# 技能页面实现与后端差距

> 状态：当前
> 最后更新：2026-11-25
> 关联：[技能视觉原型](skills-prototype.html)、[当前进度](../../03-进度与交接/当前进度.md)、[界面规范](../00-通用与界面/界面规范.md)

## 1. 页面范围

按 [skills-prototype.html](skills-prototype.html) 复刻四屏：

- 技能目录：搜索、状态筛选、列表/网格切换、详情/编辑/启停/删除。
- 添加/编辑技能：上传 .md 或在线撰写，frontmatter 字段、质量引导、Markdown 编辑/分屏/预览。
- 技能详情：启停、使用反馈、试运行、版本历史、生效范围。
- 问答端技能选择：面板化搜索、自动匹配占位、不使用技能、启用/禁用技能列表。

视觉保留原型的信息架构和抖动圆角；底色使用白色，组件平铺在白底上；主色改莫兰迪灰绿，版本用沙黄，危险操作用陶土，次要分区用浅暖灰。编辑器正文使用 14px 等宽字体、1.95 行高，预览使用 15px 衬线字体、2.05 行高。

## 2. 当前实现

- 目录、创建、更新、上传 .md、启停、删除、编辑读取均接现有 `/api/v1/skills/catalog` 接口。
- 编辑器正文复用知识库文档全文 Markdown 渲染；编辑/预览固定高度、各自滚动、隐藏滚动条；Markdown 框支持覆盖中央应用窗内容区的页内全屏。
- 编辑器必填标识、自动草稿（新建）、取消/模式切换/模板覆盖确认、inline 校验与字符计数已落地；自动草稿不覆盖已有技能编辑。
- 技能只用于普通问答；原型中的 Agent 生效范围不实现，页面只显示“问答”。
- 目录的最近 30 天调用次数、详情页调用统计、最近调用、12 周趋势暂显示占位。
- 详情页版本历史只显示当前版本。
- 试运行入口保留，按钮禁用并提示接口待接入。
- 问答端“自动匹配（推荐）”置灰展示，当前默认仍为“不使用技能”；手动选择启用技能走现有 `skill_id`。
- 已禁用技能在问答端灰显且不可选。

## 3. 后端待补能力

### 3.1 技能使用统计

- 需要按技能返回：近 30 天调用次数、最近一次调用时间、近 12 周调用分桶。
- 数据来源建议：问答请求成功记录 skill_id、会话、模型与时间；失败调用不计入或单独标记。
- 页面接口可并入目录详情或单列 `GET /api/v1/skills/catalog/:id/usage`。
- 需明确统计口径：只统计普通问答、去重规则、取消/失败请求是否计入。

### 3.2 版本历史

- 每次保存生成历史记录：版本号、保存时间、变更摘要、正文快照或 diff、操作者。
- 页面需要 `GET /api/v1/skills/catalog/:id/versions`；当前版本标记与历史回看是后续能力。
- 版本号唯一性与升版规则需后端校验，前端不能仅依赖输入。

### 3.3 试运行

- 需要 `POST /api/v1/skills/catalog/:id/try`：输入示例问题，返回是否命中、命中理由、预期检索/步骤摘要。
- 必须与正式问答隔离，不消耗问答额度；不得执行技能脚本；不写真实会话。
- 模型调用失败要返回可读错误，前端保留输入并允许重试。

### 3.4 自动匹配

- 当前 `skill_id` 为空表示“不使用技能”，没有自动匹配语义。
- 若要实现原型默认项，需要显式选择模式，例如 `skill_selection_mode: auto | none | manual`，并返回命中技能与理由。
- 自动匹配必须可关闭、可观测，且不得绕过技能只用于普通问答的边界。

### 3.5 生效范围

- 当前技能只用于普通问答；原型中的 Agent 范围不落地。
- 若未来允许 Agent 使用技能，需要单独立项并写 ADR，先改产品硬规则，再改接口与页面。
