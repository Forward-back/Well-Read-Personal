## 1. 背景与审核结论

### 1.1 现有实现

复习 V2 已具备卡组树、卡片管理、三档评分、每日/手动会话、会话恢复、单卡表现、统计页与导出。复习页当前为「复习 / 卡片 / 统计」三标签，复习流嵌在复习标签内。

### 1.2 原诊断的过期项

原始优化说明中的两项判断已经过期：

- 「复习页没有开始入口」：现有页面已有今日队列与开始复习入口。
- 「翻卡自评闭环不存在」：现有代码已有单卡翻面、三档评分、键盘操作与会话恢复。

真正的问题不是功能完全缺失，而是主任务不够突出、漏洞不可见、算法状态不可读、复习流的视觉与信息层级差。

### 1.3 仍需解决的问题

1. 今日页没有把「今天该做什么、从哪开始」做成首屏主任务。
2. 没有漏洞热力图与漏洞簇详情，弱项无法定位到知识块。
3. 三档评分无法区分「想得慢」与「秒答」，调度信号不够细。
4. 自动暂停会把最反复忘记的卡从队列与热力图里移走，与「补强漏洞」冲突。
5. 卡片列表信息密度低，缺少批量打标签、移动、删除与重置进度。
6. 统计页空图、易忘卡 Top10 红色轰炸、没有优先复习建议。
7. 界面直出等级与原始分数，用户无法理解。
8. 复习页视觉未获 owner 认可；组件路线需要统一回 TDesign。

### 1.4 原型与最终设计的差异

`review-redesign.html` 只作为视觉与交互参考，不照抄数据、色值或页面数量。

| 项 | 原型 | 最终设计 |
|---|---|---|
| 页面范围 | 7 个页签，含知识图谱、设置 | P0 为今日、复习模式、漏洞簇详情；卡片与统计保留为标签；图谱与设置延后 |
| 主色 | `#10B981` | 现有品牌绿 `--td-brand-color` |
| 状态色 | `#F59E0B` / `#EF4444` / `#3B82F6` | 映射 TDesign warning / error / info token |
| 圆角 | 10px / 14px | 3px / 6px，沿用 TDesign 圆角体系 |
| 图标 | emoji | lucide 图标，不使用 emoji |
| 数据 | 虚构 D/S/R、四档评分、4 个红色簇 | 真实数据只有稳定度、漏答、连续忘记；四档评分本轮新增；最多突出 3 个簇 |
| 样本不足 | 部分图表隐藏 | 保留模块并显示明确空态 |
| 每格文案 | `60% / 3/5 异常` | 加权强度；格子显示强度与严重数，簇详情展开完整构成 |
| 队列 | 强化队列插入今日 | 点击「重学」立即开始手动会话，不改变今日队列 |

## 2. 目标与非目标

### 2.1 目标

1. 打开复习页到开始第一张卡不超过 2 次点击。
2. 单卡复习（看题、翻面、评分）在键盘流下不超过 10 秒。
3. 用户能看到「哪个知识块红了」，并从热力图进入簇详情、补强或回原文。
4. 界面上不出现 L0/L1、稳定度原始值、难度分数等算法黑话。
5. 样本不足时不画空图，所有警告配至少一个行动出口。
6. 复习、卡片、统计三个入口共用一个清晰的信息架构，不出现第二个一级标题。

### 2.2 非目标

- 不引入完整 FSRS；不持久化 D/R 参数。
- 不做 LLM 拆卡、换问法、自动标签。
- 不做知识图谱、设置页、移动端专项（<600px）。
- 不做多会话并存、推送通知、社交化。
- 不改知识库入库、RAG 检索与 MCP 工具面。
- 不新增角色、ACL、共享空间或多租户概念。

## 3. 设计体系

### 3.1 组件与视觉

- 组件统一使用 TDesign Vue Next；Tailwind 只做布局与间距，不引入第二套组件库。
- 视觉目标为 TDesign 视觉语言 + 品牌绿；禁止 shadcn 默认灰黑色板。
- 统计图使用 ECharts，颜色读取 TDesign CSS 变量。
- 图标使用 lucide；不使用 emoji 作为状态或行动图标。
- 品牌绿只用于主 CTA、当前选中、进度与关键品牌数据；状态色只用于 badge、评分按钮和状态列，不做大面积填充。
- 漏洞色阶独立于品牌绿，用于热力图与漏洞强度条。

### 3.2 色彩语义

| 色层 | 用途 | 禁止 |
|---|---|---|
| 品牌绿 `--td-brand-color` | 主 CTA、选中、进度、关键数字 | 状态标签、漏洞强度填充 |
| success | 已记住、正面结果 | 品牌主操作 |
| warning | 想得慢、警告簇、提醒 | 大面积背景 |
| error | 严重、严重簇、忘记 | 普通正文 |
| info | 秒答、信息提示 | 警告与错误 |
| 漏洞四级色阶 | 热力图格子、强度条 | 与品牌绿混排 |

漏洞四级级别（热力图颜色）：

- 严重：强度 ≥ 60%。
- 警告：40%–59%。
- 观察：20%–39%。
- 健康：< 20%，但簇内至少有一张已复习卡。
- 暂无数据：簇内没有已复习卡。

基础级别按强度分档；若簇内最高单卡级别高于基础级别，取较高者，避免单张严重/警告卡被新卡稀释后隐藏。强度数字仍按加权公式显示，不因级别提升而改写。图例注明「底色为簇级别，数字为加权强度」。

### 3.3 术语翻译

界面禁止出现内部等级与原始分数。统一翻译：

| 禁用 | 替代 |
|---|---|
| `正常 L0 ×1` | 已记住 · 复习 1 次 |
| `L1 ×1 ×忘记` | 记忆不稳 · 忘记过 1 次 |
| `稳定度: 9 天` | 记忆可撑约 9 天 |
| `忘记 0/1 0%` | 第 1 次复习就忘记 |
| `下次到期: 2026/11/15` | 9 天后（悬停显示具体日期） |
| 漏洞原始指数 | 漏洞强度 60% |
| `lapses` / `D` / `S` / `R` | 忘记次数 / 材料难度 / 可撑天数 / 当前记得概率 |

### 3.4 页面密度

| 页面 | 密度 | 结构 |
|---|---|---|
| 今日页 | 双栏中密度 | 左侧约 200px 卡组栏；右侧任务条 + 热力图 + 优先补强；1440 首屏可见关键信息 |
| 复习模式 | 居中中密度 | 单卡约 720px；题干、答案、评分固定层次；漏洞信息只对异常卡展开 |
| 漏洞簇详情 | 标准中密度 | 头部强度与主 CTA；异常卡表格约 56px 行高；底部行动出口 |
| 卡片页 | 紧凑 | 56px 行高；题干 + 单行元数据；默认隐藏复选框 |
| 统计页 | 两栏仪表盘 | 四 KPI；2×2 图表；排行与建议；空态保留模块位 |

760px 以下今日页变单列，卡组栏收进顶部下拉；热力图与簇详情表格横向滚动，首列与行标题固定，不另做一套卡片流。

### 3.5 页头与操作分级

- 每个标签只有一个页头：标题、一句说明、操作区。
- 今日页唯一主 CTA 是「开始今日复习」；生成、导入、导出收进「更多」。
- 卡片页主 CTA 是「新建卡片」。
- 统计页导出为次级操作。
- 不再提供「刷新」按钮；数据变更后自动更新。

### 3.6 状态与空态

- 正常/已记住不显示 badge；严重、警告、暂停、孤儿、来源失效显示语义标签；从未复习显示灰点。
- 所有警告必须有至少一个行动按钮。
- 所有图表样本不足时保留卡片位，显示明确引导文案，不隐藏模块，不画空轴。
- 空状态必须给出下一步：打标签、开始复习、生成卡片、调整筛选或返回。

## 4. 信息架构

路由保持 `/platform/review`，默认进入今日视图。

```
复习模块
├── 今日视图（默认）
│   ├── 卡组二级栏
│   ├── 今日任务条 + 开始/继续复习
│   ├── 漏洞热力图
│   └── 今日优先补强
├── 漏洞簇详情（今日视图内子视图，可返回）
├── 复习模式（全屏层）
├── 卡片标签
└── 统计标签
```

- 不新增独立路由页面；漏洞簇详情使用页内子视图，返回按钮回到今日视图，保留卡组选择。
- 复习模式为全屏层，Esc 暂存退出；会话保留，今日页显示「继续复习」。
- 卡片与统计保留标签，不另起路由。
- 统计为全局口径，不跟随卡组选择；进入统计时卡组栏隐藏或显示只读的「全部卡组」。

## 5. 页面规格

### 5.1 今日视图

**卡组栏**：约 200px，树形展示；节点显示子树卡片数与今日到期数；选中节点过滤今日任务、热力图与卡片列表；「全部卡组」为默认。窄屏收进顶部下拉。卡组行悬停显示「更多」菜单，提供新建子卡组、重命名、删除；默认卡组只允许新建子卡组；底部保留「新建卡组」。今日到期数只统计 active、已复习且到期（含逾期）的卡，不含新卡。

**任务条**：返回剩余到期数、新卡数、预计分钟、连续天数；预计时间按每卡约 30 秒估算，至少 1 分钟。主 CTA：

- 无进行中会话且队列非空：「开始今日复习」。
- 有进行中会话：「继续复习」，直接恢复。
- 队列为空且今日已完成：「今日已完成」，展示完成统计。
- 队列为空且今日未完成：「今日暂无待复习」，引导创建或生成卡片。

**漏洞热力图**：

- 行：有 active 卡的叶子卡组；标签显示完整路径，避免同名卡组混淆。非叶子卡组自身挂有卡片时生成同名虚拟叶子行，避免卡片从热力图丢失。
- 列：卡片标签；无标签卡片回退主要来源的文档标题；无来源则归入「未分类」。
- 多标签卡片分别计入每个标签列；各列卡数与分母允许重叠，百分比不可相加。
- 同一文档标题同名时按来源 ID 分列，标签用相同标题并以 tooltip 区分，不按标题合并。
- 格子显示加权强度与严重卡数；底色按簇级别，tooltip 同时给出总卡数、强度与级别。无已复习卡显示灰格「暂无数据」，不可点击。
- 只有观察、警告、严重格子可点击进入簇详情；健康格不可点击，避免无行动的空白页。
- 图例固定在热力图下方，包含簇级别色阶、强度数字说明与「暂无数据」。
- 数据为空时显示引导文案，并提供「批量打标签」入口。
- 列数超过可用宽度时横向滚动，行标题固定；列顺序按列内最高簇级别、列强度总和、名称稳定排序。

**今日优先补强**：

- 只列严重与警告簇，按强度降序、严重卡数降序、名称排序。
- 最多 3 条；每条显示强度、簇名、严重/警告摘要与「去补强」。
- 观察级不进入警告列表，只在底部显示「观察中 N 个簇」的灰色摘要。
- 全站视觉强调最多 3 个簇；获得强调的簇就是优先补强排序前 3 名，不足 3 个按实际数量。热力图仍全量着色，但只有这些格子获得描边或强调。
- 点击条目或格子进入簇详情，不直接开始会话。

**系统洞察**：

- 规则引擎，不做 ML。同一行出现 ≥2 个严重簇时提示「该卡组多个子主题同时告急」；同一列跨卡组出现 ≥2 个严重簇时提示「该主题跨卡组普遍薄弱」。
- 最多显示一条洞察；多条命中时按严重簇数降序、行优先于列稳定排序，无命中时不显示。

### 5.2 复习模式

- 顶部：返回/暂存、进度 `3 / 7`、队列名（今日队列或簇补强）。
- 题干：大字号居中，提示先回想。
- 操作：全宽「显示答案（空格）」；答案区支持 Markdown、代码块与图片；长答案内部滚动，不撑破页面。
- 严重卡：题干上方红色横幅；有忘记次数用「第 N 次忘记」或「连续忘记 N 次」，否则用「记忆可撑不足 3 天」，不伪造 0 次忘记。
- 警告卡：用橙色「近期薄弱」标签，展示参数条，但不使用红色横幅。
- 参数条仅严重/警告卡显示：材料难度不可用时显示「记忆可撑」「忘记次数」「建议间隔」，不伪造 D/R。
- 来源条：有可用知识来源时显示来源文档/摘录与「打开原文」；无来源时隐藏，不显示空按钮。
- 评分四键：1 忘记、2 想得慢、3 想起来、4 秒答；颜色依次 error、warning、success、info。
- 评分后自动进入下一张；全部完成显示完成页：完成数、四档计数、连续天数、次日到期。
- Esc 暂存退出；空格翻面；1–4 评分；输入框聚焦时不响应快捷键。
- 若已有进行中会话而用户从簇或抽屉发起新会话，先弹层选择「继续当前 / 放弃并开始补强」，不得静默返回旧会话。

### 5.3 漏洞簇详情

- 头部：簇名、级别 badge、加权强度、严重/警告/观察卡数、主 CTA「重学这 N 张」。
- 异常卡表格列：题干；记忆可撑天数；忘记次数；最近评分；建议；状态。
- 建议列只显示可读动作：严重/警告显示「重学」，有可用来源显示「回原文」，观察显示「再观察」；不生成 LLM 建议。
- 行内提供「回原文」；只有整簇唯一来源文档时，底部额外显示「打开原始笔记」。
- 底部行动出口本轮只启用「重学这 N 张」与「回原文」；拆卡、换问法不显示，避免空壳。
- 重学数量 N 为严重 + 警告卡；观察与健康卡不进入强化会话。
- 无异常卡的簇不生成入口；若从异常数据返回后簇变为健康，显示「本簇已无异常卡」并允许返回。

### 5.4 卡片页

- 56px 紧凑行：题干、卡组、复习次数、可撑天数、异常状态。
- 筛选：搜索、状态、卡组、标签、仅今日到期；筛选变化自动刷新，无刷新按钮。
- 复选框默认隐藏，行 hover/focus 出现；选中后顶部浮现批量栏。
- 批量操作：删除、移动卡组、追加标签、重置进度；批量上限 100 张。
- 批量打标签为并集追加，不覆盖已有标签；删除标签只在单卡编辑抽屉做。
- 标签规则：去首尾空白、忽略大小写去重；单标签 1–32 字符；每卡最多 10 个标签。
- 卡片表现抽屉：右上角关闭；底部动作「立即复习」「编辑卡片」「重置进度」，不出现「取消」。
- 重置进度只重置调度字段：等级回 0、稳定度回初始 10 天、漏答与连续忘记归 0、到期设为当前复习日并立即进入今日队列（仍受每日额度限制）；复习日志、统计与历史保留。
- 重置后漏洞按新调度字段与最近 5 次评分重算；日志保留，近期多次忘记的卡可能仍为警告，不立刻变健康。
- 暂停/孤儿卡显示状态与恢复入口；孤儿卡不可开始复习，先重绑来源。

### 5.5 统计页

- 全局口径，不跟随卡组选择。
- KPI：总卡片、已复习、保留率（附「健康区间 ≥80%」）、连续天数。
- 图表：评分分布、评分趋势、到期预测、遗忘曲线；四档评分中秒答独立成色。
- 保留率 =（想起来 + 秒答）/ 总评分次数。
- 空态阈值：评分分布总次数 <5、遗忘曲线有效卡 <10、卡组数 <3 时显示引导文案，但保留模块。
- 卡组排行、优先复习建议各占一卡；优先建议最多 3 条，使用建议性文案 + CTA，不做易忘卡 Top10 红色列表。
- 会话历史显示四档计数；历史会话没有秒答数据时按 0 显示，不反推。
- 导出包含秒答；旧 CSV 列保持兼容，新增列放在末尾。

## 6. 规则

### 6.1 今日队列

```
今日队列 = 到期卡 + 新卡
到期优先；新卡最多 20 张；总量上限 100。
```

- 到期包含逾期与今日到期；逾期最久优先。
- 新卡按创建时间；到期卡用满额度时不出新卡。新卡指复习次数为 0 的卡，评分后立即退出新卡额度。
- 今日完成数只统计 `daily` 会话与无会话的历史评分；手动、补强会话不占每日额度。
- 卡组子树只缩小范围，不重置额度。
- 04:00 为日界；跨日未完成的 `daily` 会话过期，未完成卡回到下一次队列。
- 同一会话同一卡最多评分一次；重复提交按客户端请求 ID 幂等处理。

### 6.2 四档评分与调度

| 评分 | 键 | 稳定度 | 等级 | 到期 |
|---|---|---|---|---|
| 忘记 | 1 | 重置为 5 天 | 回 0 | 次日，不在当轮重出 |
| 想得慢 | 2 | ×1.5 | 不变 | 按新稳定度计算 |
| 想起来 | 3 | ×3 | +1，封顶 6 | 按新稳定度计算 |
| 秒答 | 4 | ×5 | +2，封顶 6 | 按新稳定度计算 |

- 间隔按 `R=e^{-t/S}`、目标保留率 90% 计算，限制 1–180 天。
- 忘记累计漏答与连续忘记；其他评分将连续忘记归零。
- 取消 `lapses≥3` 自动暂停。卡片保持 active，由漏洞规则标记；用户可在卡片页手动暂停。
- 手动暂停与孤儿仍不进入队列；恢复暂停卡时连续忘记归零、忘记次数保留；孤儿必须先重绑来源。
- 孤儿重绑来源后保持暂停；用户显式恢复后才进入队列与热力图，不因重绑自动回到队列。
- 历史数据中已自动暂停的卡不会静默恢复；它们在卡片页可见，由用户选择「恢复复习」。
- 秒答计数独立写入会话与统计；历史会话秒答为 0。

### 6.3 单卡漏洞级别

只对 active 卡评估。使用卡片字段与最近 5 次评分；无评分记录时归为「暂无数据」，不判为健康。

| 级别 | 条件 |
|---|---|
| 严重 | 可撑 <3 天，或忘记次数 ≥3，或连续忘记 ≥2 |
| 警告 | 非严重，且忘记次数 ≥1，或可撑 <10 天，或最近 5 次中忘记+想得慢 ≥2 |
| 观察 | 非以上，且逾期 ≥3 天，或最近一次为想得慢 |
| 健康 | 非以上，且至少复习 1 次 |
| 暂无数据 | 复习次数为 0 |

多条件命中时取最高级别。卡片被手动暂停或孤儿时不计入热力图与优先补强。

### 6.4 簇强度与簇级别

簇为「卡组 × 列」的组合。强度按卡级别加权：

| 卡级别 | 权重 |
|---|---|
| 严重 | 1 |
| 警告 | 0.5 |
| 观察 | 0.25 |
| 健康 | 0 |
| 暂无数据 | 0，但计入分母 |

```
簇强度 = 簇内权重和 ÷ 簇内 active 卡总数
```

- 例：5 张卡中 3 张严重、1 张警告、1 张健康 → (3 + 0.5) / 5 = 70%，簇级别为严重。
- 簇内有已复习卡时按 60/40/20 分档；没有任何已复习卡时为「暂无数据」，显示灰格。
- 簇级别取强度分档与簇内最高卡级别的较高者；强度数字单独显示，避免单张严重/警告卡被新卡稀释后隐藏。例：10 张卡中 1 张严重、9 张未复习 → 强度 10%，级别仍为严重。
- 多标签卡在多个簇中分别计入，热力图各列分母允许重叠。
- 今天优先补强只取严重与警告簇；观察簇不告警。
- 全站最多 3 个簇获得视觉强调；不是只计算 3 个簇。

### 6.5 标签、来源与热力图列

- 标签是跨卡组的主题；卡组决定行，标签或来源文档决定列。
- 有标签的卡片只按标签入列，不再按来源文档重复入列；无标签卡片才回退来源文档标题。
- 主要来源失效但仍有其他 active 知识来源时，使用下一条 active 知识来源标题。
- 所有知识来源失效的卡为孤儿，不进入热力图。
- 无标签且无可用来源的卡片进入「未分类」列。
- 来源文档标题来自知识库记录；不在卡片表冗余存储标题。
- 标签列为空时不显示空列；空标签、仅空白标签不参与。

### 6.6 卡片批量与重置

- 批量操作先校验全部卡片归属与状态，再在单事务内执行；任一卡片不存在、已删除或不属于当前 owner 时整批失败，不做部分成功。
- 批量删除为软删除，可在卡片页恢复；不删除复习日志。
- 批量移动只改卡组，不改调度。
- 批量追加标签与已有标签求并集，不删除；结果仍受每卡 10 个标签上限约束，超限整批失败并提示。
- 重置进度保留日志与统计；重置后热力图与队列在下一次读取时重算。
- 重置与批量操作不影响已存在的会话计划快照；会话内卡片状态变化按 7.1 处理。

### 6.7 回原文

- 使用卡片的 primary 或首条 active 知识来源。
- 跳转到对应知识库详情的文档定位；必须同时解析出知识库与知识条目。
- 来源已删除、不可用或解析不到知识库时，按钮禁用并提示原因；不跳到空页。
- 从复习模式打开原文不结束当前会话；返回后仍可继续。
- 簇详情行内入口定位到该卡来源；只有整簇唯一来源时提供簇级入口。

## 7. 边界情况

### 7.1 会话与并发

- 已有进行中会话时，今日页显示「继续复习」；从簇或抽屉发起新会话必须弹层二选一。
- 「放弃并开始」先放弃旧会话再创建新会话；旧会话已完成部分的日志保留，仍计入统计与今日完成数。
- 两个标签页同时评分：服务端按会话与客户端请求 ID 幂等；第二个重复请求不重复推进调度。
- 卡在会话中被删除、暂停或转孤儿：提交评分返回冲突，前端提示跳过该卡并继续剩余队列；不静默吞掉错误。
- 会话跨 04:00：旧 `daily` 会话过期；未完成卡回队列。手动会话按同一规则过期，避免长期悬挂。
- 跨 04:00 后继续评分返回会话过期；前端提示重新开始，已完成日志保留，未完成卡回队列。
- 队列为空但存在 active 会话：优先显示继续会话，不显示「暂无任务」。
- 强化会话的卡片与今日队列重复时，只影响本次手动会话，不重复占用每日额度。

### 7.2 漏洞与热力图

- 所有卡都未复习：所有格子为「暂无数据」，提示完成一次复习后生成漏洞图。
- 簇内只有新卡：同样为「暂无数据」，不显示 0% 健康绿。
- 簇内部分卡已复习、部分未复习：未复习卡计入分母但权重为 0，强度会被稀释；tooltip 说明总卡数。若簇内存在严重/警告卡，簇级别至少为该卡级别，不因稀释变健康。
- 所有簇都是警告但无严重：簇强度可能低于 60%，显示警告级，不升级为严重。
- 超过 3 个严重簇：热力图全部着色，优先补强只取前 3；其余簇仍可点击查看。
- 多个标签列强度相同：按严重数、警告数、名称稳定排序，避免刷新跳动。
- 文档标题重复：按来源 ID 分列，不合并；tooltip 显示来源路径/知识库。
- 来源文档标题过长：列宽受限，标签截断并 tooltip 全文。
- 标签过多：热力图横向滚动，不做隐藏；空标签不渲染。
- 卡片无标签无来源：归入「未分类」；未分类簇可点击，但行动只有重学与编辑，不显示回原文。
- 手动暂停卡曾严重：不计入热力图；卡片页显示暂停状态与恢复入口。
- 历史自动暂停卡：不自动恢复；用户在卡片页恢复后才重新进入队列与热力图。
- 恢复暂停卡：连续忘记归零、忘记次数保留；历史多次忘记卡恢复后仍可能为严重，不自动降级。
- 孤儿卡：不计入热力图，不可重学；卡片页提示重绑来源。

### 7.3 评分与调度

- 重复点击评分：前端立即禁用按钮；服务端幂等，重复请求不重复加漏答或推进等级。
- 同一卡在同一会话已评分：拒绝第二次并返回当前卡片状态，前端跳过。
- 评分请求失败：保留当前卡与已翻面状态，显示重试；不自动进入下一张。
- 秒答在历史统计中无数据：显示 0，不按「想起来」反推。
- 旧无会话评分：保留「当日最后一次为准」的兼容行为，计入今日完成数。
- 忘记评分后当日不再出现：符合 V2 规则；次日重新进入队列。
- 时钟跨日：以服务端 04:00 日界为准，前端不本地推算到期。

### 7.4 卡片与批量

- 批量选择超过 100 张：禁止继续选择并提示上限。
- 批量操作部分卡已删除：整批失败，刷新列表后重试。
- 批量追加标签导致某卡超过 10 个：整批失败，提示具体卡片数量，不静默截断。
- 重置进度时卡片在 active 会话中：允许重置；会话计划仍保留该卡，后续评分照常写回，但调度以重置后状态为起点。
- 删除卡片可从回收/恢复入口恢复；恢复后调度状态保留，不自动回到今日队列。
- 卡片编辑题干命中重复哈希：拒绝保存并提示已有卡，不自动合并。
- 卡片答案超过 200 字：只在簇详情显示「建议拆卡」提示，不提供未实现的拆卡按钮；本轮不自动拆卡。
- 来源失效：先使用下一条 active 来源；全部失效时行内「回原文」禁用并提示原因。
- 标签为空字符串或全空白：拒绝保存；标签大小写不同视为同一标签。

### 7.5 统计与空态

- 评分分布总次数 <5：显示「需要至少 5 次评分才能绘制」。
- 遗忘曲线有效卡 <10：显示「需要至少 10 张卡多次复习才能绘制」。
- 卡组数 <3：排行模块保留并显示引导，不隐藏。
- 无会话历史：显示空态与「开始今日复习」入口。
- 保留率没有评分：显示「—」，不显示 0%。
- 到期预测全为 0：显示空态，不画全零柱。
- 优先复习建议没有异常：显示「暂无需要优先处理的卡」，不显示红色列表。
- 统计页不跟随卡组：卡组栏隐藏或只读，避免用户误以为已过滤。

### 7.6 窄屏与主题

- 600–760px：今日页单列；热力图横向滚动，首列固定；簇详情表格横向滚动。
- 600px 以下不在当前支持范围；不承诺布局，但不得出现脚本错误。
- 浅色/深色：TDesign token 自动切换；ECharts 在主题切换后重绘；热力图色阶在深色下保持对比度。
- 键盘：所有按钮可 Tab 到达，焦点可见；Esc 退出复习层；空格翻面不滚动页面；输入框内不触发快捷键。
- 控制台不得有错误；加载失败显示重试，不显示空白页。

### 7.7 性能与数据量

- 千卡规模热力图目标 ≤500ms；聚合在服务端完成，前端不拉全量日志自行计算。
- 热力图列数增长时只横向滚动，不截断数据。
- 统计页 ECharts 按路由异步加载；切换标签不重复初始化。
- 批量操作上限 100，避免长事务与长时间锁表。

## 8. 数据与接口边界

本节只描述概念边界，字段与迁移以实施时的 Swagger 与迁移文件为准。

- 评分新增 `easy`；会话新增秒答计数；复习记录无需新增评分字段类型。迁移需要同时覆盖 PostgreSQL 与 SQLite 基线。
- 不新增 D/R 字段，不保存 FSRS 参数；漏洞规则由现有稳定度、漏答、连续忘记与最近评分日志计算。
- 新增簇聚合读取接口：返回行、列、格子、优先补强与洞察；不把聚合逻辑放到前端。
- 新增批量卡片操作接口：删除、移动、追加标签、重置调度；全量校验后单事务执行。
- 新增单卡重置调度接口，供表现抽屉使用。
- 今日队列读取接口增加新卡上限；默认 20，总量上限 100。
- 创建会话增加显式「新建」语义；已有 active 会话时不得静默返回旧会话，由前端弹层确认。
- 回原文复用现有知识库详情定位，不新增内容渲染链路。
- 统计接口增加秒答分布/趋势/会话计数；保留旧字段，避免前端旧数据崩溃。
- MCP 工具面不变；复习聚合不暴露给 MCP。

## 9. 验收

### 9.1 功能

- 2 次点击内开始今日复习；键盘流单卡 ≤10 秒。
- 今日页任务条、热力图、优先补强、系统洞察均来自真实数据。
- 热力图格子可进入簇详情；重学立即开始手动会话；回原文定位准确。单张严重/警告卡被新卡稀释时，格子仍按较高单卡级别可点击，强度数字显示真实低值。
- 四档评分写回正确；秒答独立统计；重复评分幂等。
- 取消自动暂停；手动暂停与孤儿仍被队列排除；历史自动暂停卡可见且可手动恢复。
- 卡片批量追加标签、移动、删除、重置进度可用；重置保留日志。
- 统计页四档分布/趋势/会话历史正确；空态保留模块；优先建议可用。
- 回原文在来源失效时禁用并提示。
- 600px 以上无页面横向溢出；控制台 0 错误。

### 9.2 数据与回滚

- 新迁移在现有数据库与全新数据库均成功；旧数据可读。
- 秒答历史缺省为 0；旧评分与会话报告不被改写。
- 批量操作可回滚；删除为软删除；重置不清日志。
- 迁移前备份 PostgreSQL、SQLite 与必要数据卷。

### 9.3 视觉

- 复习页浅色/深色、1440px/600px 截图对比。
- 由 owner 实机或截图确认；自动化验收只证明功能与布局，不代表审美通过。
- 旧 TDesign 页面无样式回归。
