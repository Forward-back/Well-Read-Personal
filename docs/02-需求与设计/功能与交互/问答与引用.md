# 问答与引用

> 状态：当前
> 最后更新：2026-11-10
> 目标读者：产品、开发、测试

## 1. 为什么用

让 owner 用自然语言检索自己的知识库，并得到带可定位引用的回答。个人版不做共享、权限过滤或审计，答案质量取决于检索与引用。除知识库检索外，问答还提供直连模型模式：不检索知识库，直接用思考模型回答，可显式开启联网搜索。

## 2. 使用方式

1. 新建会话；默认检索全部知识库，也可在输入栏限定单个知识库。
2. 输入栏选择检索方式：RAG（默认）或直连；RAG 可再选学习/复习模板。
3. 输入问题，选择模型与是否启用网络搜索/技能。
4. 流式查看答案；RAG 模式展示引用，直连模式不产生知识库引用；思考过程可折叠查看。
5. 直连模式可开启联网搜索，答案末尾附带由后端生成的网页来源链接。
6. 从引用打开文档、分块或进入精读。
7. 历史会话按时间分组，可重命名、置顶、删除。

## 3. 业务规则

- RAG 回答必须带可定位引用；引用不可编造。
- 默认跨全部知识库；选择单库时只检索该库。
- 归档与回收站文档不参与检索。
- 技能只影响普通问答；精读固定使用 `grill-with-docs`，不共享可执行技能工具。
- 直连模式不检索知识库、不产生知识库引用与 RAG 图片；使用设置中的直连模型（必须是开启思考的问答模型），未配置时直连不可用。
- 直连与 Agent 模式互斥：切换到直连会退出 Agent，走普通问答流式通道。
- 直连默认携带最近 10 轮会话历史；学习/复习模板仅在 RAG 模式生效。
- 直连联网搜索默认关闭，需显式开启；网页来源由后端根据真实搜索结果追加，模型不得编造链接。
- 会话归 owner；不存在跨用户可见性或共享会话。
- 不记录治理用途的原始问题；检索 trace 只用于本地排障。

## 4. 界面意图

- 问答页是登录后的默认落地页；左侧为历史会话，中间为消息流与输入框。
- 输入栏提供检索方式切换（RAG/直连）；直连时隐藏学习/复习模板。
- 引用以可点击条目展示，打开文档/分块/精读；不显示反馈、协作或共享入口。
- 直连模式的思考过程折叠展示；设置「模型与引擎」提供直连模型选择。
- 输入栏支持知识库、文件、技能、MCP 提及；提及只使用 owner 自有资源。
- 设置中可开启网络搜索；无供应商时相关入口隐藏或提示配置模型。

## 5. 当前实现与差距

| 项 | 当前实现 |
|---|---|
| 检索范围 | 全部/单库；四路召回、RRF、精排由 RAG 完成 |
| 引用 | 文档/分块引用与引用抽屉已保留；直连模式不产生引用 |
| 精读入口 | 引用可进入精读 |
| RAG 租户/ACL | 请求不再携带部门/ACL/密级参数 |
| 检索方式 | 请求字段 `retrieval_mode=rag|direct`；直连走 `qaModeDirect`，复用流式与思考事件 |
| 直连模型 | `tenants.direct_model_id` + 设置 KV `direct-config`；校验 KnowledgeQA 且思考控制非 none |
| 直连历史 | 最近 10 轮（20 条）已完成消息，排除本轮 |
| 联网来源 | 复用 WebSearchService 默认供应商；答案末尾追加真实来源链接 |
| 学习/复习模板 | 仅 RAG 模式生效；直连忽略 `answer_mode` |
| 代码项目检索 | 本地目录与 Git 模式均已真实回归；同步删除会清理 chunks 与引擎文档 |
| 差距 | KB 删除的引擎文档依赖每日 reconcile 清理；直连多轮对要求回传 reasoning_content 的供应商未做兼容 |

## 6. 验收

- 默认全库问答返回带引用答案；限定单库后引用只来自该库。
- 归档/回收站文档不出现在引用中。
- 引用可打开对应文档/分块，并可从文档进入精读。
- 页面不出现部门、共享、协作、反馈或治理入口。
- 直连模式返回答案与可折叠思考过程，无知识库引用；未配置直连模型时提示配置。
- 直连开启联网搜索后，答案末尾出现真实网页来源链接；关闭时无来源块。
