# 问答与引用

> 状态：当前
> 最后更新：2026-11-04
> 目标读者：产品、开发、测试

## 1. 为什么用

让 owner 用自然语言检索自己的知识库，并得到带可定位引用的回答。个人版不做共享、权限过滤或审计，答案质量取决于检索与引用。

## 2. 使用方式

1. 新建会话；默认检索全部知识库，也可在输入栏限定单个知识库。
2. 输入问题，选择模型与是否启用网络搜索/技能。
3. 流式查看答案；引用展示文档、分块与相关页面。
4. 从引用打开文档、分块或进入精读。
5. 历史会话按时间分组，可重命名、置顶、删除。

## 3. 业务规则

- 回答必须带可定位引用；引用不可编造。
- 默认跨全部知识库；选择单库时只检索该库。
- 归档与回收站文档不参与检索。
- 技能只影响普通问答；精读固定使用 `grill-with-docs`，不共享可执行技能工具。
- 会话归 owner；不存在跨用户可见性或共享会话。
- 不记录治理用途的原始问题；检索 trace 只用于本地排障。

## 4. 界面意图

- 问答页是登录后的默认落地页；左侧为历史会话，中间为消息流与输入框。
- 引用以可点击条目展示，打开文档/分块/精读；不显示反馈、协作或共享入口。
- 输入栏支持知识库、文件、技能、MCP 提及；提及只使用 owner 自有资源。
- 设置中可开启网络搜索；无供应商时相关入口隐藏或提示配置模型。

## 5. 当前实现与差距

| 项 | 当前实现 |
|---|---|
| 检索范围 | 全部/单库；四路召回、RRF、精排由 RAG 完成 |
| 引用 | 文档/分块引用与引用抽屉已保留 |
| 精读入口 | 引用可进入精读 |
| RAG 租户/ACL | 请求不再携带部门/ACL/密级参数 |
| 代码项目检索 | 已支持代码知识；真实 Git 仓库检索待回归 |

## 6. 验收

- 默认全库问答返回带引用答案；限定单库后引用只来自该库。
- 归档/回收站文档不出现在引用中。
- 引用可打开对应文档/分块，并可从文档进入精读。
- 页面不出现部门、共享、协作、反馈或治理入口。
