# 技能与问答注入

> 状态：当前
> 最后更新：2026-11-09
> 目标读者：产品、开发、测试

## 1. 为什么用

技能把常用提示词与操作步骤封装成可复用的“过程知识包”。个人版把技能当作 owner 的个人资产：只有一份技能目录，没有部门归属、授权记录或共享空间。技能只提供提示词层面的指引，不执行脚本。

## 2. 使用方式

1. 顶层技能页查看已登记技能、启停状态与描述。
2. 添加技能有两种方式：
   - 上传单个 `.md` 文件；
   - 在线撰写：填写名称、描述、版本（可选）与 Markdown 正文，支持预览。
3. 已登记技能可再次编辑（同一个在线撰写表单预填内容），也可停用或删除。
4. 普通问答时在输入栏选择启用中的技能；系统把该技能的说明注入当轮提示词，并在消息上记录技能 ID、名称、版本与内容哈希。
5. 精读固定使用 `grill-with-docs`，不加载问答技能。

## 3. 业务规则

- 上传文件只接受 `.md`，必须以 YAML frontmatter 开头；`name` 与 `description` 必填。
- 字段上限：文件 ≤ 1MB；名称 ≤ 100 字；描述 ≤ 500 字；版本 ≤ 64 字；正文 1–32000 字。
- 在线撰写由表单自动生成 frontmatter；编辑保存后立即影响后续问答，已发生消息保留原哈希。
- 同名技能再次登记会覆盖同一条目录记录。
- 技能注入只发生在选中且启用时；停用技能不出现在问答选择器。
- 技能归 owner；没有部门、角色或按人授权概念。
- 删除技能不删除已产生的会话或消息。

## 4. 界面意图

- 技能页展示名称、版本、启用状态与描述；操作有编辑、启用/停用、删除。
- 添加弹窗两个标签页：上传 `.md` / 在线撰写；编辑复用在线撰写表单。
- 在线撰写提供 Markdown 预览切换，避免用户手写 frontmatter。
- 问答输入栏的技能选择只列出启用中的技能，默认“不使用技能”。

## 5. 当前实现与差距

| 项 | 当前实现 |
|---|---|
| 技能目录/创建/编辑/启停/删除 | 已实现；支持 `.md` 上传与在线撰写 |
| 问答注入 | 已实现；消息记录 `skill`（ID、名称、版本、内容哈希、注入状态） |
| 源地址导入 | 后端接口保留，前端入口已移除 |
| 沙箱脚本技能 | 本轮不实现；沙箱配置与技能安装仅保留后端代码，前端不展示。后续如需脚本技能，需补沙箱配置 CRUD 接口与页面 |
| 部门/授权 | 已删除 |

## 6. 验收

2026-11-09 浏览器验收通过：

- 上传 `.md` 注册技能；在线撰写创建技能且预览正常；编辑表单预填名称与正文，保存后列表更新。
- 停用技能后问答选择器不再出现该技能；重新启用后恢复。
- 问答选择技能后回答体现注入内容，消息 `skill.injection_status = applied`。
- 设置与技能页无 401/403 循环、无控制台错误。

遗留：RAG 查询改写器中仍有少量支付场景意图模板（`rag/src/retrieval/query_rewriter.py`），不影响技能注入，待后续通用化。
