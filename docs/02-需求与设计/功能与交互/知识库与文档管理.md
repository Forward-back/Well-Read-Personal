# 知识库与文档管理

> 状态：当前
> 最后更新：2026-11-04
> 目标读者：产品、开发、测试

## 1. 为什么用

把散落在本机的文档、网页和代码整理成可检索的知识库。个人版保留多知识库与文件夹/标签，不引入共享、ACL 或审批。

## 2. 使用方式

1. 问答页或知识库页新建知识库，选择文档/FAQ 类型。
2. 在知识库配置中设置嵌入模型、摘要模型、解析器、分块、多模态、存储与数据源。
3. 上传文件、导入网页、手工录入 Markdown，或添加本地目录/Git 代码项目。
4. 用文件夹与标签分类；按解析状态筛选，处理失败文档。
5. 编辑文档前系统自动留版本；可对比与回滚。
6. 不再需要的文档可归档；删除进入回收站，可恢复或彻底删除。

## 3. 业务规则

- 知识库归 owner；没有共享关系或可见性字段。
- 删除知识库会删除其文档、版本、索引与精读关联，不可恢复。
- 文档保存与重新解析前自动生成版本快照；保留最近 50 个，可手动清理。
- 归档文档默认不参与问答与精读检索；回收站文档不可检索。
- 文档状态只保留草稿/解析中/可用/归档/回收站；没有生效/废止日期与定时流转。
- 标签是知识库内分类；没有部门标签或授权主体。
- 代码项目按语言符号在函数/类边界分块；`ContextHeader` 为 `path:line-line · symbol`，重复同步按稳定 ID 更新并清理已删除文件。

## 4. 界面意图

- 知识库列表只展示 owner 的知识库卡片；置顶分组保留，其余按创建时间排序。
- 卡片菜单提供置顶、复制、设置、删除；不显示共享、部门或来源徽章。
- 详情页展示文档列表、处理时间线、分块与预览；标题栏可打开设置与添加代码项目。
- 配置弹窗保留基础、模型、解析、多模态、存储、分块、高级、数据源；没有协作/共享/ACL 标签页。

## 5. 当前实现与差距

| 项 | 当前实现 |
|---|---|
| 版本 | 自动快照、列表、对比、回滚、保留上限已保留 |
| 归档/回收站 | 已保留；无生命周期日期 |
| 代码项目 | 本地目录/Git 同步已实现；真实仓库检索回归待执行 |
| 文档解析 | app + docreader/anydoc；RAG 不再解析文件 |
| 共享/ACL | 已从数据模型、接口与页面删除 |

## 6. 验收

- 可创建多个知识库并在其中上传、导入、手工录入文档。
- 文档编辑后可查看版本并回滚；超过 50 个版本后最旧版本被清理。
- 归档文档不出现在问答检索结果；回收站可恢复/彻底删除。
- 页面与接口不出现部门、共享、ACL、协作概念。
