# 动态图标与动效规范

> 状态：当前
> 最后更新：2026-11-27
> 关联：[界面规范](界面规范.md)、[精读 agent 开发方案](../../03-精读/精读agent/精读agent开发方案.md)

## 1. 结论

`react-useanimations` 是 React 组件库，`peerDependencies` 为 `react>=18`，不能直接用于本项目的 Vue 3 页面；直接安装会把 React 运行时带进前端，违反「全前端统一 TDesign，不引入第二套组件栈」。

可用的是它的 MIT 许可 Lottie `animationData`。本项目采用：

- 动画资产取自 `react-useanimations@3.1.1` 的 `lib/*.mjs`；
- 资产以 JSON 形式 vendoring 到 `frontend/src/assets/animations/useanimations/`；
- 用 `lottie-web` + 自有 Vue 组件 `UseAnimationIcon.vue` 渲染；
- 不安装 React，不引入 React 组件，不新增第二套组件库。

## 2. 资产规则

- 目录：`frontend/src/assets/animations/useanimations/`。
- 每个动画一个 JSON，文件名使用 useAnimations 的小驼峰名，例如 `loading.json`。
- 同目录保留 `NOTICE.md`，记录上游版本、仓库、许可证与已引入动画清单。
- 新增动画只从 `react-useanimations` 的上游包提取，不手写 Lottie、不使用 GIF/emoji/第三方动画 CDN。
- 只引入实际使用的动画；不批量拷贝整个库。
- 动画 JSON 不进入全局主题系统，由组件在渲染前按当前页面主操作色重着色。

## 3. 组件 API

组件：`frontend/src/components/animations/UseAnimationIcon.vue`。

```vue
<UseAnimationIcon
  name="loading"
  :size="20"
  color="currentColor"
  :loop="true"
  :autoplay="true"
  label=""
/>
```

- `name`：已 vendoring 的动画 key；未注册时渲染空节点并输出一次开发警告。
- `size`：16 / 20 / 24 / 32px 四档；默认 20px。
- `color`：CSS 颜色值，默认继承父级 `currentColor`；组件用计算后的颜色重着色 Lottie。
- `loop` / `autoplay`：默认 true；流程结束、失败或非激活态必须停止。
- `label`：为空时 `aria-hidden="true"`；提供时作为 `role="img"` 的可访问名称。
- 组件卸载时销毁 Lottie 实例；主题切换时重新着色。
- `prefers-reduced-motion: reduce` 下只渲染首帧，不自动播放、不循环。

## 4. 使用规则

- 动态图标只表达「正在进行的系统动作」：模型思考、检索、保存、同步、上传。
- 同一操作区最多一个循环动画；不得在列表、表格或静态卡片中循环播放。
- 动画旁必须有文字状态（例如「思考中」「检索中」），不能只靠动画传达状态。
- 操作完成后立即停止或移除动画；禁止后台空转。
- 尺寸、颜色跟随当前页面主操作色；不单独定义动画色板。
- 加载动画优先放在状态标题左侧；不要放在按钮文字中间导致布局跳动。
- 暗色/亮色同一资产，通过重着色适配，不维护两套 JSON。
