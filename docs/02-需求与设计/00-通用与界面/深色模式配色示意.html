深色模式配色示意

全站共用一套中性暖炭暗色基底。页面不再各自定义暗色背景；复习、精读、技能只保留布局与语义色差异。品牌绿与功能主操作色在暗色下自动提亮，静态卡片只用发丝线，阴影只给浮层。

一套底色问答、知识库、精读、复习、技能全部使用同一窗口/纸面/抬高面。
三级表面窗口 → 纸面 → 抬高面；静态卡片无阴影，弹窗/下拉/抽屉才允许阴影。
暖炭而非纯黑不使用 #000 / #fff；正文与背景保持 7:1 以上阅读对比。
主色自动适配UI 设置的主操作色只提供色相；暗色下自动提亮并生成 hover/active/soft/line。

2. 三级表面

窗口承载页面画布；纸面承载卡片、侧栏；抬高面承载输入、菜单、悬浮操作。任何页面不再出现纯白纸面。

窗口 / 画布

--w-window
页面根、顶栏底层、阅读主区

纸面 / 卡片

--w-surface
知识卡、复习卡、技能卡、侧栏

抬高面 / 浮层

--w-surface-raised
输入框、菜单、弹窗内容、抽屉

阴影规则：静态卡片与页面区块只使用 1px 发丝线；只有模态、下拉、抽屉、悬浮预览使用 --shadow-pop。

5. 功能主操作色自动适配

UI 设置中的颜色只作为色相来源。暗色模式统一派生：accent = 70% 源色 + 30% Ink；hover 再提亮；soft/line 与窗口混合。

默认亮绿#07C05F → #5EDB95
复习灰蓝#5A7688 → 提亮灰蓝
技能鼠尾草#5C6B51 → 提亮鼠尾草
陶土危险#A2685C → 提亮陶土
按钮文字：暗色实心主按钮使用 --accent-ink（近黑）而不是白字，避免亮绿/亮蓝底白字对比不足；语义标签只使用低饱和填充。
