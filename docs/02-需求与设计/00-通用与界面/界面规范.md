## 1. 结构

- 登录页：邮箱 + 密码；不含注册、邀请、OIDC。
- 平台壳层：顶部品牌栏 + 左侧功能图标栏 + 右侧辅助栏 + 中央应用窗；无邀请铃铛、空间切换、角色标签与新手运营入口。
- 左侧导航：首页、问答、知识库、精读、复习、技能；设置只在右侧辅助栏，作为普通详情页进入。
- 登录后默认 `/`（落地页）；`/welcome` 重定向到 `/`；`/platform/*` 是业务详情命名空间。
- 设置六分区：账户与助手、UI 设置、模型与引擎、外部接入、系统健康与队列、关于。

## 3. 视觉与交互

目标风格：TDesign 视觉语言 + 品牌绿。组件统一使用 TDesign Vue Next；Tailwind 只做布局与间距；不引入第二套组件库，不采用 shadcn 默认灰黑色板。

共享壳层（落地页 `/` 与 `/platform/*` 详情页）沿用 [ADR 0007](../../06-架构决策/0007-PostHog布局语言落地页与壳层改造.md) 的顶栏 + 左右栏 + 中央窗结构；落地页内容改用 [ADR 0008](../../06-架构决策/0008-落地页改用Notion极简语言.md) 的 Notion 极简语言，详情页继续按现有 TDesign + 品牌绿规则，后续按批次对齐。过渡期同一页面不得混用两套规则。

### 3.1 硬性视觉规则

- 字体：正文 14px，辅助文字 12–13px，页面标题 20–24px；应用界面字重只用 400 / 500 / 600；落地页展示标题按 [ADR 0008](../../06-架构决策/0008-落地页改用Notion极简语言.md) 使用 600 字重与紧字距；正文与控件仍只用 400 / 500 / 600。
- 颜色：主文字用 `--td-text-color-primary`；次要文字用 `--td-text-color-secondary`；不使用 placeholder 灰承载正文级信息。
- 品牌绿 `--td-brand-color` 只用于主 CTA、当前选中、进度与关键品牌数据；不用于状态标签、漏洞强度填充或大面积背景。
- 所有点击与交互高亮（tabs、分段控件、选中行、焦点环、选中图标）统一使用品牌亮绿 `#07c05f`，选中底 `#e9f8ec`，hover `#08dd6e`，active `#06b04d`。Notion 迁移中的莫兰迪色只作辅助语义（严重/警告/观察、图表与装饰），不得替代交互高亮绿。
- 状态色只用于 badge、评分按钮、状态列与小面积提示，不做大面积填充：success 表示已记住/正面结果，warning 表示想得慢/警告簇/提醒，error 表示忘记/严重簇，info 表示秒答/信息提示。
- 漏洞四级色阶独立于品牌绿，只用于热力图格子与漏洞强度条；「暂无数据」使用中性灰，不与品牌绿混排。
- 间距：4px 梯度（4 / 8 / 12 / 16 / 24 / 32）；卡片内边距 16px，紧凑列表 12px；区块间距 16px，页面级间距 24px。
- 容器与卡片圆角 6px；按钮、输入框等控件圆角 3px；边框用 `--td-component-stroke`；默认不用大阴影；同一页面不混用圆角体系。
- 复习页内容/装饰图标使用 Icons8 静态线条 PNG（背景透明）；TDesign 组件自带图标（chevron、关闭、下拉箭头等）保留，两者按实际视觉需要选择。未迁移详情页继续使用 Icons8 手绘静态 PNG；不使用动态 GIF、emoji 或新增 lucide。保留 “Icons by Icons8” 署名。共享壳层与落地页使用 TDesign 图标/自绘 SVG。
- 同类指标使用同一卡片结构：标题、数值、说明、操作的顺序一致。
- 精读工作台是页面级视觉例外（[ADR 0009](../../06-架构决策/0009-精读工作台改用Notion极简与莫兰迪语义点缀.md)）：3/4px 圆角、1px 发丝线、无阴影、留白分区；品牌绿只用于主行动、进度与选中，内容按语义使用鼠尾草绿、雾霾蓝、燕麦米、陶土粉、藕紫淡色。该例外不外溢到其他详情页。
- 详情页画布配色与透明度由「设置 → UI 设置 → 详情页外观」统一控制：配色支持暖米纸、纯白、浅灰、淡绿预设与自定义取色器；透明度 0–100%。字体颜色按主文字、次要文字、占位文字三级分别取色；品牌绿、链接、状态色与代码高亮保持原色。只作用于中央应用窗画布与文字 token，卡片、输入框保持实色；仅亮色模式生效，暗色模式沿用暗色窗底与白色字阶。

### 3.2 页面密度

密度按页面单独确定，不跨页面默认继承；常用三档为紧凑、中等、宽松。每个页面动工前必须由 AI 向 owner 询问或提出建议，确认后写入该页面的设计说明或阶段记录。

| 页面 | 密度 | 结构 |
|---|---|---|
| 复习今日视图 | 双栏中密度 | 左侧约 200px 卡组栏，贯穿内容区上下；右侧任务条 + 热力图 + 优先补强上下排布；1440 首屏可见关键信息 |
| 复习模式 | 居中中密度 | 单卡约 720px；题干、答案、评分固定层次；漏洞信息只对异常卡展开 |
| 漏洞簇详情 | 标准中密度 | 头部强度与主 CTA；异常卡表格约 56px 行高；底部行动出口 |
| 复习卡片页 | 紧凑 | 56px 行高；题干 + 单行元数据；复选框默认隐藏；卡组树形筛选；选中后批量栏吸顶 |
| 复习统计页 | 两栏仪表盘（中等） | 四 KPI；2×2 图表；排行与优先建议；空态保留模块位 |
| 精读工作台 | 三栏中密度 | 左 256px 目录 + 会话摘要；中栏阅读流 680px；右 312px 笔记；进入工作台自动全屏，窗口宽度不足 1100px 时右栏收抽屉 |
| 精读创建配置 | 中等 | 居中 600px；文件树、深度行、目标 chips、预估条、草稿列表 |

760px 以下今日视图变单列，卡组栏收进顶部下拉；热力图与簇详情表格横向滚动，首列与行标题固定，不另做一套卡片流。

### 3.3 页头与信息架构

- 共享壳层：顶部 40px 浮动品牌栏（WellRead 字标 + 个人设置头像），左侧 112px 功能图标栏（首页、问答、知识库、精读、复习、技能），右侧 112px 辅助栏（帮助、设置、主题、GitHub、回到顶部、退出登录），中央为 80%×95%、20px 圆角的应用窗，内容在窗内滚动。
- 设置只放在右侧辅助栏，作为普通详情页进入；左栏不再提供设置入口。窗口内底色浅色为暖米纸色 `#F7F5F0`，暗色使用壳层暗色 token；外层背景默认草地纹理，可在「设置 → UI 设置 → 背景设置」切换为内置壁纸或上传图片。原八键装饰与旧窗口栏已移除。
- 落地页与详情页在顶栏右侧提供全屏切换：方形图标进入全屏，X 图标退出；`/` 与 `/platform/*` 显示。全屏时隐藏左右栏，内容窗从顶栏下沿（距视口顶 48px）开始，左右各留 8px 与顶栏对齐，底部贴到视口底；顶栏下方两角改为直角，退出全屏恢复圆角与居中窗口。落地页全屏后内容宽度扩到窗口的 `calc(100% - 48px)`，避免左右留白过大。
- 精读工作台进入时自动全屏；切换到创建配置时自动退出全屏，配置页保持居中窗口。手动退出全屏后本次停留不强制恢复。
- 壳层内滚动条视觉隐藏，滚轮、触控板与拖拽滚动保留。
- 每个标签只有一个页头：标题、一句说明、操作区。
- 标签页内不得重复页面标题，不再出现第二个一级标题；标签名与页内区块标题不得同义重复。
- 页面级操作只出现在页头一次；上下文操作跟随对应区块。
- 左栏功能按钮：点击未激活功能进入对应页面；再次点击当前功能隐藏中央应用窗（详情页随之下沉淡出），按钮保持激活态，再次点击恢复显示；切换到其他功能、顶栏入口或路由变化都会恢复显示。
- 今日视图唯一主 CTA 是「开始今日复习」；生成、导入、导出收进「更多」；卡片页主 CTA 是「新建卡片」；统计页导出为次级操作。
- 不再提供「刷新」按钮；筛选或数据变更后自动更新。
- 平台壳层已于 2026-11-18 完成共享壳层替换（[ADR 0007](../../06-架构决策/0007-PostHog布局语言落地页与壳层改造.md)）；功能详情页内容尚未逐页重做，后续按各自批次继续对齐。

### 3.4 状态、空态与交互

- 正常/已记住在列表中默认隐藏，只显示异常状态：严重、警告、暂停、孤儿、来源失效；从未复习显示灰点。
- 所有警告必须至少有一个行动按钮；不允许出现只能看、不能处理的警告。
- 图表样本不足时保留模块与卡片位，显示明确引导文案；不得隐藏整张图卡，也不得渲染误导性的空坐标系。
- 空状态必须给出下一步：打标签、开始复习、生成卡片、调整筛选或返回。
- 全站最多 3 个漏洞簇获得视觉强调；热力图仍全量着色，只有优先补强对应的格子获得描边或强调。
- 所有可交互元素必须有可见的 hover、focus-visible、active、disabled、selected 状态；复选框、行点击、右键菜单必须有可见替代入口。
- 复选框、次要操作与选中态不得依赖低对比度表达；不能只用颜色传达状态。
- 键盘：所有按钮可 Tab 到达；Esc 退出复习层；空格翻面不滚动页面；输入框聚焦时不触发快捷键。

### 3.5 现有产品规则

- 品牌绿分层：主 CTA、选中、进度与关键数据使用绿色；选中/高亮文字与图标使用亮绿 `#07c05f`，选中背景 `#e9f8ec`，hover `#08dd6e`，active `#06b04d`。不要用深绿 `#067a3d` / `#056a34` 作为选中态。实心主按钮如白字对比度不足，可局部使用更深填充，但不能回改全局高亮 token。
- 沿用既有 WellRead 视觉语言：浅色容器、品牌绿、卡片化列表；圆角体系统一按 §3.1，不再区分「历史页 8px / 新页 6px」。
- 列表/卡片操作优先图标按钮 + tooltip；破坏性操作需确认。
- 长文档与大列表复用虚拟滚动、分页与 Markdown 渲染管线。
- 流式回答保持滚动跟随；用户上滚时暂停自动跟随。
- 文案不出现公司、部门、成员、共享、ACL、审批、治理、审计等企业概念。
- 浅色/深色跟随 TDesign token；ECharts 在主题切换后重绘；不新增第二套主题开关。
- 600px 以下不承诺布局，但不得出现脚本错误；控制台不得有错误，加载失败显示重试，不显示空白页。

### 3.6 详情页布局（共享壳层）

- 详情页占满中央窗内容区；页面根节点使用 `height:100%` 或 `flex:1` 填满，页面内部自行滚动。
- 新建对话页与聊天页共用 `ChatWorkspace`：桌面（>900px）左侧内联 260px 会话栏，默认展开、可折叠；折叠/展开只使用聊天详情左上角的专用按钮。900px 及以下回退会话抽屉。
- 会话栏折叠/展开按钮位于聊天详情左上角，无边框；会话标题右移让出按钮位置。
- 会话栏只列会话，不提供网页/API 通道筛选；RAG/直连切换保留在输入栏。
- 问答定位波浪：聊天列宽度不足以居中 960px 输入框时贴聊天列左边；会话栏折叠或全屏后，按输入框左侧空白的一半内缩，不贴窗口左边界。
- 引用详情面板：非窄屏绝对定位在聊天详情主区域内，贴主区域右侧，不覆盖顶栏、右侧辅助栏或会话栏；窄屏使用 fixed 遮罩模式。面板打开期间隐藏会话栏折叠/展开按钮。
- 会话栏提供搜索入口：点击后在主区域打开覆盖式历史搜索页（搜索框、对话历史卡片），返回或选中会话后关闭；搜索按标题 keyword，不改变左栏；卡片摘要显示该会话第一条用户问题，不生成摘要。
- 新建对话页：标题距窗顶 48px；推荐问题区域可滚动；输入框常驻页面底部并保留 24px 底部留白。
- 聊天页：消息区占据剩余高度并内部滚动，输入框始终贴底，底部保留 20px 留白。
- 非全屏聊天页左右各留 32px 内容留白，输入框随列宽收窄；全屏保持 960px 内容宽居中，不套用该留白。
- 设置页：作为普通详情页渲染，不使用遮罩层与关闭按钮；页面内「模型未配置」等深链接仍可打开设置弹窗。
- 知识库新建/设置：新建使用 `/platform/knowledge-bases/new`，设置使用 `/platform/knowledge-bases/:kbId/settings`；均为详情页，不使用 body 级弹窗。页面内保留分区导航、表单与底部操作。
- 知识库文件夹新建/移动弹窗挂载在详情主区域，居中显示并虚化详情页背景，不覆盖壳层顶栏与左右栏。
- 知识库设置的分块设置页头随内容滚动，不吸顶、不使用独立白底。
- 详情页底色浅色 `#F7F5F0`；卡片与输入保持 TDesign 容器色；暗色跟随主题。
- 所有详情页共享顶栏全屏控件与滚动条隐藏规则，详见 §3.3。
- 精读工作台：页内 48px 页头承担文档名、工作台/创建切换、进度与动作；左栏目录 + 会话摘要；主栏阅读流；右栏笔记；当前章节原文进入覆盖抽屉。原文抽屉复用知识库 `DocumentPreview`，最大页面半宽、可拖拽调宽并记忆；全屏预览按钮位于抽屉页头右侧。窄屏按 §3.2 收敛，原文抽屉保持可关闭。

## 5. 状态与空态

- 知识库空态引导创建；最近访问空态引导打开文档。
- 未配置模型时创建知识库可进入向导并跳转模型配置。
- 上传进度在列表页展示；刷新后显示最新解析状态。
- 错误提示区分参数错误、未认证、资源不存在与服务端错误。

## 6. UI 组件体系

### 6.1 组件路线与边界

- 全前端统一使用 TDesign Vue Next；不引入第二套组件库。
- 共享壳层按 ADR 0007 使用 PostHog 布局语言，落地页内容按 ADR 0008 使用 Notion 极简语言；两者都只使用 TDesign 组件、自绘 CSS 与 TDesign 图标/自绘 SVG，不引入第二套组件库。
- Tailwind 只用于布局、间距与自定义区块，不承载第二套组件主题。
- 未迁移的功能详情页继续使用 Icons8 手绘 PNG；复习页使用 Icons8 静态线条 PNG（背景透明）与 TDesign 组件自带图标，按实际视觉选择；共享壳层与落地页使用 TDesign 图标或自绘 SVG，不使用 Icons8 图标。旧壳组件（Menu、AppTopBar、AppRightRail、GardenKeys）已删除，旧手绘资源文件保留但不再用于壳层。不使用动态 GIF、emoji 或新增 lucide。
- 用户头像：设置页预览 64×64、圆角 14px；顶栏入口 28×28、圆角 8px；无头像时显示用户名或邮箱首字母；图片使用 `object-fit: cover`，不做圆形裁切。
- 统计图使用 ECharts，按路由异步加载，颜色读取 TDesign CSS 变量。
- 禁止新增 `shadcn-vue`、`reka-ui`、`class-variance-authority`、`cn`、`tw-animate-css` 等 shadcn 相关依赖；V2 复习页试点残留已于 2026-11-17 随 V3 清理删除，`components/ui` 与 Tailwind shadcn token 不再存在。
- 禁止在同一页面混用 TDesign 与 shadcn 组件。

### 6.2 复习页组件映射

复习页的组件映射、V3 实施边界与清理验收见[复习页设计 §13](../04-复习/复习页设计.md#13-组件映射与实施边界)。

## 7. 禁止项

- 不做角色/能力驱动的导航过滤；左侧固定首页 + 问答/知识库/精读/复习/技能，设置只在右侧辅助栏，作为普通详情页。
- 不新增 `requiredCaps` / `requiredAnyOps` 路由元数据。
- 不在前端计算共享、部门或 ACL 可见性。
- 不在日志/控制台打印 API Key、模型 Key 或敏感配置。
- 不新增 shadcn-vue、reka-ui 或其他第二套组件库；不恢复全前端 shadcn 迁移。
- 不在同一页面混用 TDesign 与 shadcn 组件。
- 不使用 emoji 作为图标、状态或行动按钮。
- 不在界面直出 L0/L1、稳定度原始值、材料难度或可撑概率等算法字段；按 §3 与复习设计文档翻译为可读文案。
- 不隐藏样本不足的图表模块，不画空轴或假曲线。
- 落地页不复制 Notion 或 PostHog 的品牌字体、logo、插画、客户素材与文案；不引入 React 实现或第二套组件栈。
