计算机网络 #三次握手
TCP 建立连接为什么需要三次握手？两次握手会导致什么问题？
来源：《TCP/IP 详解 · 卷一》§18.2 · 上次复习 3 天前 · 评分「困难」
Answer · 答案
三次握手的核心是同步双方的初始序列号（ISN）并确认彼此的收发能力。两次握手无法确认「客户端能收到服务端的响应」，会导致——
  • 失效的连接请求到达服务端后，服务端单方面建立连接并等待，造成资源浪费；
  • 双方序列号无法可靠同步，后续数据可能错乱或丢失。
记忆锚点：握手本质 = 确认双方收发能力的最小次数（2 次不够、4 次冗余）。
评分由间隔重复算法（FSRS）实时计算，悬停按钮可预览具体间隔。快捷键：1 / 2 / 3 / 4
屏幕三 · 漏洞簇详情：「严重」砖红 Tag 是本页唯一强高亮；「学习中」为中性灰 Tag；诊断 Callout 图标允许砖红，其余图标一律灰褐。
