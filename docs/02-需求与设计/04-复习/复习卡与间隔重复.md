## 1. 背景与目标

学习闭环目前停在「资料 → 问答理解 → 精读细读」。「复习模式」生成的自测题只存在于当次回答，用户看过即忘，没有积累，也没有第二次接触。个人知识库最有价值的资产不是文档，而是「哪些内容我已经掌握、哪些还没」的记录。

本功能把一次性自测题变成持久复习卡，并用间隔重复安排第二次、第三次接触，补齐「记住」环节。

卡片的基本单位是知识点，不是对话片段。同一知识点只有一张卡；不同对话、不同文档产生的同一知识点通过「吸收」成为该卡的额外来源，避免卡片随对话次数线性膨胀。

目标：

- 复习卡可积累、可检索、可编辑、可导出，成为长期学习资产。
- 每张卡可回溯原文；原文变化时卡片不静默失效。
- 用卡组树组织卡片，卡片量增长后仍能按主题定位。
- 每日复习有明确上限和预计时长；正常负荷控制在 10–15 分钟，总量 100 张是安全上限，不是每日目标。
- 保留每次复习的等级与时间，形成可度量的记忆数据。

非目标：

- 不做 FSRS 等复杂记忆模型，不做 Anki 兼容导入导出。
- 不做推送通知、移动端、多人共享或社交化学习。
- 不新增 MCP 工具，17 个工具面不变（知识面只读，会话面仅自有会话）。
- 不修改知识库入库打标逻辑；卡片只继承已有标签与模型推荐标签。
- 不做纯图片题与看图问答，图片只作为卡背来源材料。
- 不做无来源空白建卡；手动建卡必须绑定知识来源，其余卡片来自自测题保存或文档生成，且带知识来源。
- 本轮不做精读笔记自动成卡，只在来源模型上预留。

## 2. 核心循环与成功度量

核心循环：

1. **捕获**：在复习模式回答中保存自测题，或从知识库/文档生成，存入指定卡组。
2. **调度**：按卡片自适应稳定度计算下次到期时间；每日推荐与手动自选分开，手动不占每日额度。
3. **复习**：按卡组范围翻卡、自评、回原文，单卡 15 秒内完成；每轮复习形成可恢复的会话；忘记卡次日重排，不在当轮重出。
4. **修复**：反复忘记的卡不再自动暂停，而是按漏洞规则标记并聚合为漏洞簇；用户从热力图或优先补强进入簇详情，重学异常卡或回原文。
5. **度量**：保留率、到期预测、漏洞簇强度与复习会话报告反哺下一轮生成与精读。

成功度量（单用户自用，不做增长指标）：

| 指标 | 目标 | 用途 |
|---|---|---|
| 生成预览接受率 | ≥ 60% | 判断生成提示词质量 |
| 每日任务完成率 | ≥ 80% | 判断负荷是否合理 |
| 7 日保留率 | ≥ 80% | 判断调度是否有效 |
| 卡片孤儿率 | < 5% | 判断来源绑定是否可靠 |
| 平均单卡耗时 | 10–20 秒 | 判断卡片是否原子 |
| 重复吸收率 | 持续观察 | 判断自测题是否在制造重复 |
| 严重漏洞簇数量 | 下降或稳定 | 判断「定位弱项 → 补强」是否真的闭环 |

## 3. 非典型设计

以下设计不是行业标配，但对「个人资料型学习」收益明显。

### 3.1 卡片是知识点，来源可以多条

保存新题时先做全局查重。命中同一知识点时默认「吸收」：把新题登记为已有卡的一条新来源，不新建卡片。卡片详情按时间列出全部来源，调度只有一份。

理由：对话式学习会反复问同一概念，如果每次自测题都建卡，卡片量与噪声必然失控。吸收让重复变成证据积累。

### 3.2 来源锚点与孤儿卡降级

每张卡保存来源知识、分块、原文片段与定位信息；卡背固定展示原文摘录，可一键打开分块。来源被删除或重新解析后，先尝试重绑，失败则标记该来源不可用；全部知识来源都不可用时才转为孤儿卡并暂停，由用户重绑或删除。

理由：脱离原文的 AI 生成卡片容易变成无来源断言。孤儿处理把数据腐烂变成可见状态。

### 3.3 失败路由，而不是自动暂停

反复忘记的卡不再累计 3 次自动暂停。它们保持 `active`，按严重程度标记为严重或警告，并聚合到「卡组 × 标签」漏洞簇；用户在今日页看到强度与严重卡数，从簇详情选择「重学这 N 张」或回原文。

理由：自动暂停会把最需要补强的卡从队列与热力图中移走，恰好让漏洞消失；而「记不住」往往不是记忆问题，是理解问题。正确做法是让漏洞可见，并提供回原文与集中重学的出口，而不是静默停用。

手动暂停与孤儿卡仍然不进入队列：前者是用户主动决定，后者是来源失效，二者都不是调度判断。

### 3.4 每日总上限、新卡闸门与债务稀释

每日任务 = 到期卡优先 + 新卡补位，总量封顶 100 张；新卡单独封顶默认 20 张。到期卡用满额度时不出新卡。积压时不显示「欠 143 张」，只显示「今日 N 张，约 M 分钟」。超额部分自然顺延。

理由：复习产品最大的流失原因是积压焦虑。对单用户而言，持续完成比一次性补完更重要；新卡闸门则防止长期中断后，新卡和旧债一起把当日队列撑爆。

### 3.5 键盘优先的复习流

空格/回车翻面，1 = 忘记，2 = 想得慢，3 = 想起来，4 = 秒答，Esc 暂存退出。整轮复习不需要鼠标；输入框聚焦时不响应快捷键。

理由：复习是高频重复动作，操作延迟直接决定坚持率；四档评分让「想得慢」与「秒答」进入不同调度路径，键盘必须同步扩展。

### 3.6 来源版本感知

文档重新上传、代码仓库重新同步后，卡片定位内容可能变化。系统按定位信息重绑：

- 内容哈希一致：静默重绑。
- 位置仍在但内容变化：保留卡片，标记「来源已更新」，提示用户复核。
- 知识条目删除或无法定位：该来源不可用；全部知识来源不可用时卡片转孤儿。

理由：个人知识库会持续更新，卡片必须跟得上版本，否则引用变成过期快照。

### 3.7 生成先预览，全局语义去重

生成结果先进入预览，不直接入库；逐卡接受或拒绝，支持全选。查重分三层：规范化问题哈希精确匹配；字符三元组相似度；向量余弦相似度。命中后默认吸收，用户可显式选择新建。

理由：模型生成卡片质量波动大，预览是最便宜的质量闸门；语义查重能拦住换词重问。

### 3.8 自测题内嵌保存

复习模式回答的「自测题」区每道题旁直接出现「保存为卡片」，自动附带推荐来源、引用与卡组选择；支持手动勾选引用，解析失败时提供整段手动拆分弹窗。批量保存是显式按钮，默认不自动执行。

理由：复制粘贴会杀死转化率；保存动作必须发生在看到题目的当下，但不能默认全量入库。

### 3.9 卡组树与搜索式标签

卡片用多层卡组树组织，一张卡只属于一个卡组节点；标签用于跨卡组主题。标签选择不做全量下拉：生成时模型最多推荐 3 个，其余场景只用实时搜索与回车创建。知识库若已有标签，建卡时继承一份快照。

理由：卡片量增长后，卡组树负责「在哪」，标签负责「是什么」；全量标签下拉在标签数上百后不可用。

### 3.10 学习数据可带走

支持导出全部卡组、卡片、来源、调度状态与复习记录为 JSON，包含来源路径与引用。删除知识库不自动删除卡片，孤儿卡由用户处理。

理由：个人系统必须保证数据所有权；导出也是迁移与备份手段。

### 3.11 漏洞驱动反哺

今日页与统计页按「卡组 × 标签」展示漏洞热力图；卡片无标签时回退所属知识库，仍无来源则归入「未分类」。默认只展示 top-N 行/列，其余进入 other 桶并可展开。优先补强最多 3 条严重/警告簇，提供「重学这 N 张」与「回原文」动作。统计页的优先复习建议同样最多 3 条，不做易忘卡红色 Top10。

理由：复习数据只有回到学习动作才产生价值。把弱项定位到一个可执行的知识块，比给出一张全局仪表盘更接近「补强」。

## 4. 用户流程

### 4.1 从复习回答保存

1. 问答选择 RAG + 复习模板，得到含自测题的回答。
2. 自测题每题旁显示「保存」；点击打开保存弹窗：卡组选择（默认上次使用）、推荐来源与引用、原文摘录、标签搜索。
3. 保存时先查重。命中重复卡时并排展示已有卡与本次题目，默认「附加为来源」；用户可改为移动到当前卡组或仍要新建。
4. 确认后卡片进入待复习队列；当日新卡额度已满时顺延到次日。
5. 答案底部提供「保存全部自测题」，默认不勾选；批量逐题查重并给出来源附加、跳过与新建汇总。

### 4.2 从文档或知识库生成

1. 复习页点击「生成卡片」，选择知识库或若干文档、目标卡组、数量（5/10/20）、卡型（当前仅 Q/A；填空与混合为 P2 未实现）。
2. 系统生成预览，展示题干、答案、来源片段、模型建议标签与去重标记；预览项可直接编辑。
3. 逐卡接受或拒绝，或全选接受；入库后按新卡闸门排队。

### 4.3 每日复习

1. 侧栏「复习」显示今日到期角标。
2. 复习首页展示今日任务：剩余到期数、新卡数、预计分钟与连续天数，合计受总量与新卡上限约束；可把范围限定到某个卡组子树。
3. 开始复习：翻卡、自评四档；忘记的卡次日重排，不在当轮重出；严重/警告卡在题干上方显示可读的漏洞信息。
4. 完成页展示完成数、四档计数、连续天数与次日到期；有进行中会话时首页显示「继续复习」。

### 4.4 卡片与卡组管理

- 卡组树支持新建、重命名、拖拽排序、移动、删除。
- 卡片列表支持卡组子树、标签、状态、卡型筛选，关键词搜索，结果高亮。
- 支持编辑卡片、移动卡组、暂停/恢复、删除、合并重复卡、处理孤儿卡、导出。

## 5. 业务规则

### 5.1 卡片

- 一卡一知识点：问题可独立回答；答案一句话为主，解析可选。
- **当前实现仅 Q/A 卡型。** 填空卡为 P2 未实现能力；实现时必须保留原句、只挖一个空，答案为空缺词，解析可选。
- 每张卡必须归属一个卡组，且至少一条知识来源；一张卡可挂多条来源，调度记录只有一份。
- 状态：`active`、`suspended`、`orphaned`、`deleted`。`source_updated` 是标记，不改变状态。
- 删除为软删除；哈希只检查未删除卡片，允许同名卡重新创建。
- 编辑题目后重算哈希与向量；编辑答案不影响调度。
- 暂停卡不进入队列；恢复暂停卡时连续忘记归零、忘记次数保留。系统不再因累计忘记自动暂停；历史自动暂停卡保持暂停，由用户在卡片页显式恢复。暂停可设置解除日期，到期自动恢复。
- 卡背来源图片（最多 3 张）：按主来源优先合并所有活跃知识来源，按来源分块 `chunk_id` 读取 `image_info` 与正文图片，去重后最多 3 张；点击图片打开对应原文，不参与卡面出题。消息来源不提供图片；来源分块不可用时该图静默省略。

### 5.2 卡组

- 多层树结构，一张卡只属于一个节点；跨主题用标签。
- 同一父节点下名称唯一，名称去首尾空白后比较。
- 首次使用时自动创建「默认卡组」；默认卡组不可删除。
- 卡组可重命名、拖拽排序、移动到另一个卡组下；移动必须防止形成环。
- 卡片移动卡组不改变调度状态与到期时间。
- 删除非空卡组时必须二选一：卡片移到父卡组（顶层则移到默认卡组），或连同卡片删除；默认是移动。子卡组不级联删除，自动挂到被删卡组的父节点或顶层。
- 删除卡组与卡片需要二次确认。

### 5.3 来源与版本

- 来源类型：知识分块来源（可重绑）与会话消息来源（快照，仅作背景）。
- 自测题保存时至少选择一条知识分块来源；默认按题目与引用分块的相似度/排序推荐，用户可勾选调整；只有会话消息、没有知识来源的卡片不允许创建。
- 会话删除不影响卡片；消息来源标记「原会话已删除」，知识来源继续可用。
- 知识条目归档或进回收站不判孤儿；卡片仍可复习，打开原文时提示状态。
- 知识条目硬删除或重新解析后无法定位分块：对该来源先重绑，失败标记不可用。
- 重绑顺序：同知识条目 + 内容哈希；同知识条目 + 路径/符号定位；同知识条目 + 摘录相似度。
- 全部知识来源不可用时卡片转孤儿并暂停；部分来源不可用只标记该来源。
- 代码重同步会重建分块 ID，必须依赖路径、符号、行号定位重绑，不能只存分块 ID。

### 5.4 调度

V3 前后端已按本节实施（2026-11-17 主路由切换）；V2 的三档规则见[复习 V1/V2 设计历史](../../04-历史归档/阶段记录/复习V1V2设计.md)。

等级 L0–L6 只作为兼容与展示字段，界面不直出。

- 每卡维护 `stability`，初始 10；间隔按 `R=e^{-t/S}`、目标保留率 90% 计算，限制 1–180 天。
- 四档评分与调度：

| 评分 | 键 | 稳定度 | 等级 | 到期 |
|---|---|---|---|---|
| 忘记 | 1 | 重置为 5 天 | 回 L0 | 次日，不在当轮重出 |
| 想得慢 | 2 | ×1.5 | 不变 | 按新稳定度计算 |
| 想起来 | 3 | ×3 | +1，封顶 L6 | 按新稳定度计算 |
| 秒答 | 4 | ×5 | +2，封顶 L6 | 按新稳定度计算 |

- 忘记累计漏答与连续忘记；其他评分将连续忘记归零。
- 取消 `lapses >= 3` 自动暂停。严重卡保持 `active`，由漏洞规则标记；用户仍可在卡片页手动暂停。
- 历史数据中已自动暂停的卡不会静默恢复；它们在卡片页可见，由用户选择「恢复复习」后才重新进入队列与热力图。
- 恢复暂停卡时连续忘记归零，但忘记次数保留；累计多次忘记的卡仍可能被判严重，用于继续暴露漏洞，不自动降级。
- 孤儿重绑来源后保持暂停；用户显式恢复后才进入队列与热力图，不因重绑自动回到队列。
- 同一会话同一张卡只评分一次；重复提交按客户端请求 ID 幂等处理，不重复推进调度。
- 旧的无会话评分保留「当日最后一次为准」的兼容行为。
- 日界为本地时间 04:00，凌晨学习计入前一天；到期判断以服务端为准，前端不本地推算。
- 新卡首次评分按 L0 起步；直接选「想起来」进入 L1，「秒答」进入 L2。

### 5.5 每日负荷与会话

V3 前后端已按本节实施（2026-11-17）。

- 今日队列 = 到期卡 + 新卡；到期优先，新卡最多 20 张，总量上限 100。
- 到期包含逾期与今日到期；队列顺序为逾期最久 → 今日到期 → 新卡（按创建时间）。
- 到期卡用满额度时不出新卡；卡组子树只缩小范围，不重置额度。
- 上限只约束 `daily` 会话；`manual` 自选与漏洞簇补强会话不占每日额度，单独记录。
- 今日完成数只统计 `daily` 会话与无会话的历史评分；补强会话中的卡不重复占用每日额度。
- 每轮复习创建会话并保存计划卡快照、四档计数与复习日；刷新可恢复当前会话。
- 04:00 后未完成的 `daily` 与 `manual` 会话过期，未完成卡回到下一次队列；历史会话保留。
- 同一用户同时最多一个 active 会话。从漏洞簇或卡片抽屉发起新会话时，若已有 active 会话，必须先让用户选择「继续当前 / 放弃并开始补强」，不得静默返回旧会话。
- 「放弃并开始」先放弃旧会话再创建新会话；旧会话已完成部分的日志保留，仍计入统计与今日完成数。
- 暂停复习日期（2026-11-26）：卡片可暂停到指定日期或无限期。暂停期间不进入今日队列、热力图与会话；到期后在下一次读取复习数据时自动恢复，连续忘记归零、忘记次数保留；到期日早于恢复日时 `due_at` 顺延到恢复日。手动恢复会清除暂停日期。

### 5.6 生成

- 模型：复用直连模型；未配置时回退默认知识问答模型；两者都没有时明确报错并引导配置。
- 输入：知识库或指定文档；采样文本分块，跳过纯图片块与过短分块；上下文带文档标题与章节路径。
- 必须选择目标卡组，默认上次使用的卡组；可在弹窗内新建卡组。
- 数量：单次 5/10/20，上限 50；上下文预算 12000 字符。
- 输出契约：卡型、问题、答案、解析、来源分块、原文摘录、建议标签（最多 3 个）；来源分块必须来自本次输入集合，越界结果丢弃或在预览中标注无效。
- 填空卡为 P2 未实现；实现时由模型从原文定义句/公式生成，保留原句与出处，只挖一个空。
- 预览不落库；入库走批量接口，重复项按 5.7 处理。
- 若题目涉及原文图片，可把对应来源图附到卡背，最多 3 张；图片按来源分块按需读取，不持久化 URL。

### 5.7 去重、吸收与合并

> 当前 V3 仍只实现第 1、2 层；第 3 层向量查重保留字段与接口，属 P2 未实现，见[当前进度](../../03-进度与交接/当前进度.md) §6 P2。

- 查重范围：租户内全部卡组，不只当前卡组。
- 第一层：规范化哈希（去空白、统一小写、去标点）。精确命中直接视为重复。
- 第二层：题干字符三元组相似度 ≥ 0.85，视为疑似重复。
- 第三层：题干向量余弦相似度 ≥ 阈值（初始 0.90），视为疑似重复。向量使用主要来源知识库的 embedding 模型；只与同一模型生成的向量比较。模型不可用时退回文本层，并记录原因。
- 命中后默认动作是「吸收」：把本次题目登记为已有卡的新来源，保留原卡组与调度；保存弹窗提供「移动到当前卡组」与「仍要新建」。
- 吸收时若新来源答案与已有卡答案冲突，提示差异，由用户选择保留原答案、替换答案或暂不附加。
- 批量生成入库：精确重复自动跳过；疑似重复默认不选中，可强制接受或吸收。
- 已存在的重复卡可在管理页合并：选择一个目标卡，其余卡的来源全部并入目标卡，目标卡调度不变；被合并卡软删除，其复习记录保留但不再计入统计。
- 编辑题目可能产生新的疑似重复，保存时再查一次，只提示不阻断。

### 5.8 标签

- 标签全局于租户，用于跨卡组主题；卡组树负责归属，标签负责属性。
- 建卡时继承主要来源知识已有标签的快照；知识库标签后续变化不自动同步，用户可手动编辑。
- 生成卡片时模型最多推荐 3 个标签，进入预览可编辑。
- 标签选择器不展示全量下拉：只提供实时搜索匹配与回车创建；创建时按去空白、忽略大小写去重。
- 自测题保存不调用模型推荐标签；沿用继承快照，用户可搜索添加。
- 不修改知识库入库自动打标逻辑。知识库开启既有 `auto_tag_config` 时，卡片只继承打标结果，不主动创建新标签。
- 标签重命名、同义合并不在本轮范围；卡片上可直接移除错误标签。

### 5.9 搜索与筛选

- 关键词子串搜索题干、答案与来源标题，忽略大小写，结果高亮。
- 叠加筛选：卡组子树、标签、状态（正常/暂停/孤儿）、卡型。
- 排序：最近添加、最近复习、到期时间、漏答次数。
- 不做向量语义搜索；语义能力只用于保存时查重。

### 5.10 统计

V3 统计已按本节口径实施（2026-11-17）。

- 全局口径，不跟随卡组选择；进入统计时卡组栏隐藏或显示只读的「全部卡组」。
- KPI：总卡片、已复习、保留率（附「健康区间 ≥80%」）、连续天数。
- 保留率 =（想起来 + 秒答）/ 总评分次数；没有评分时显示「—」，不显示 0%。
- 图表：四档评分分布、评分趋势、到期预测、遗忘曲线；秒答独立成色，不与「想起来」合并。
- 会话历史显示四档计数；历史会话没有秒答数据时按 0 显示，不反推。
- 空态阈值：评分分布总次数 < 5、遗忘曲线有效卡 < 10、卡组数 < 3 时显示明确引导文案，但保留模块与卡片位，不隐藏、不画空轴。
- 卡组排行与优先复习建议各占一卡；优先建议最多 3 条，使用建议性文案 + CTA，不做易忘卡 Top10 红色列表。
- 连续复习天数：当日至少完成 1 张即计入；按任意会话的有效评分统计，与「今日完成额度只算 daily」分开。
- 导出包含秒答；旧 CSV 列保持兼容，新增列放在末尾。

## 6. 概念数据模型

五类实体，字段级定义以迁移与 Swagger 为准。

**卡组**：租户、父卡组、名称、排序、状态。支持树形查询与子树计数。

**复习卡**：租户、卡组、卡型、题干、答案、解析、标签、状态、等级、稳定度、下次到期、漏答计数、连续忘记、复习次数、题干哈希、题干向量与向量模型、来源更新时间标记。

**卡片来源**：卡片、来源类型（知识分块/会话消息）、知识与分块、定位信息（路径/符号/行号/章节/内容哈希）、原文摘录、来源图片（按需从分块读取，不落库）、主来源标记、可用状态。

**复习记录**：卡片、会话、评分（V3 增加 `easy`）、评分前后等级、评分前后稳定度、间隔天数、复习时间、可选反应时长、客户端请求 ID（幂等）。

**复习会话**：租户、模式（`daily`/`manual`）、状态（`active`/`completed`/`abandoned`/`expired`）、计划卡快照、四档计数、复习日、开始与结束时间。历史会话的秒答计数缺省为 0，不回填、不反推。

关键不变量：

- 卡片必须属于一个卡组；一张卡不能跨卡组。
- 一张卡至少一条知识来源；来源可多条；调度状态属于卡片，不属于来源。
- 全部知识来源不可用时卡片才转孤儿并暂停；会话消息来源失效不算孤儿。
- 卡组删除时卡片与子卡组按 5.2 规则处理，不使用数据库级联删除。
- 卡片哈希不做数据库唯一约束，避免软删除墓碑阻塞重建；由服务层校验。
- 同一会话同一张卡最多一条有效评分；会话计划卡快照不随卡片后续编辑改变。
- 到期队列按租户 + 状态 + 下次到期建立索引；复习记录按卡片 + 时间、会话 + 卡建立索引。

## 7. 接口轮廓

全部挂在 `/api/v1/review/*`，只接受 JWT；API Key 网关默认拒绝，MCP 不暴露。

- 卡组：树查询、创建、重命名、移动、删除（带卡片处置参数）。
- 卡片：列表（卡组子树、标签、状态、卡型、关键词、排序）、详情、表现（V3 为四档计数、近 5 次忘记率、连续忘记、稳定度、漏洞级别）、创建、编辑、移动、删除、恢复、暂停/恢复、合并、重绑来源。
- 卡片批量：删除、移动卡组、追加标签、重置调度；全量校验后单事务执行，上限 100 张；另提供单卡重置调度接口。
- 查重：保存前检查与保存时校验，返回候选卡与相似度来源。
- 复习：今日摘要、到期队列（可选卡组子树，带新卡上限）、创建/恢复/放弃/查询会话、提交四档评分（可带 `session_id` 与客户端请求 ID）。
- 会话创建：显式「新建」语义；已有 active 会话时不得静默返回旧会话，由前端弹层确认。
- 漏洞聚合：按卡组、标签/来源聚合热力图行、列、格子、优先补强与系统洞察；聚合在服务端完成，前端不拉全量日志。
- 生成：预览与批量入库分离；预览带来源与建议标签。
- 标签：按关键词搜索候选（不返回全量列表）、创建；随卡片保存。
- 统计：四档分布/趋势、7 日预测、保留率、卡组排行、优先复习建议、会话历史；保留旧字段避免前端旧数据崩溃。
- 导出：JSON/CSV，含四档计数与会话；新增列放在末尾。
- 每日上限与新卡上限随创建 `daily` 会话的请求参数传入，不新增设置 KV。

## 8. 界面意图

V3 目标界面；页面结构、密度与交互细节以[复习页设计](复习页设计.md)为准。

- 第六导航项「复习」，带今日到期角标；前端菜单、路由与界面规范均为六导航。
- 路由保持 `/platform/review`，默认进入今日视图；「今日 / 卡片 / 统计」为同路由标签，漏洞簇详情是独立子路由页面，复习模式是全屏层。
- 今日视图：约 200px 全高卡组栏 + 任务条 + 漏洞热力图 + 今日优先补强；热力图与优先补强上下排布，首屏只看「今天做什么、从哪开始」。
- 漏洞热力图：行是当前 scope 的下一层卡组并可下钻，列是标签；无标签回退知识库，再无来源归「未分类」；默认 top-N + other，可「显示全部」。只有观察/警告/严重格可点击进入簇详情，健康格与 other 桶不可点击。
- 漏洞簇详情：独立页面，头部公式/强度与主 CTA「重学这 N 张」；参数表约 56px 行高；行内「回原文」；四出口为重学、回原文、拆分卡片、生成新角度卡；根因按需 LLM，失败回退规则。
- 复习模式：单卡约 720px 居中；题干、答案、评分固定层次；全宽「显示答案（空格）」；四档评分 1–4；严重卡红色横幅，警告卡橙色标签，不伪造算法参数。
- 卡片页：56px 紧凑行；搜索、状态、卡组、标签、仅今日到期筛选；卡组筛选为树形下拉；复选框默认隐藏，hover/focus 出现；批量追加标签、移动、删除、重置进度。
- 统计页：全局口径两栏仪表盘；四 KPI + 2×2 图表 + 排行与优先建议；空态保留模块位。
- 组件统一使用 TDesign Vue Next；Tailwind 只做布局与间距；复习页使用 Icons8 静态线条 PNG（背景透明）或 TDesign 组件自带图标，按实际视觉选择；未迁移详情页使用 Icons8 手绘 PNG；共享壳层与落地页使用 TDesign/自绘 SVG；不使用 emoji，不新增 lucide。
- V3 页面已整体替换为 TDesign 三视图，V2 的 shadcn 组件目录与依赖已删除。

## 9. 与现有系统的边界

- 问答：只增加保存入口与复习模板结构化契约，不改普通问答链路。
- RAG：卡片生成复用模型服务，不进入检索索引，不影响问答引用。
- 知识库：删除知识库不删卡片；知识/分块变更触发来源重绑与孤儿判定；不改入库自动打标逻辑。
- 代码同步：依赖路径、符号、行号重绑；分块 ID 变化不直接判孤儿。
- 会话：删除会话不删卡片，只让消息来源失效。
- 精读：本轮不自动成卡；孤儿卡与薄弱项可跳转精读，属后续扩展点。
- MCP：工具面保持 17 个（知识面只读，会话面仅自有会话），不新增复习工具。
- 设置：复习不新增设置 KV；每日上限随创建会话的请求参数传入。
- Embedding：使用主要来源知识库的 embedding 模型生成题干向量；跨模型不比较，模型缺失时退回文本相似度。

## 11. 风险与开放问题

- 跨知识库 embedding 模型可能不同，语义查重会漏检；靠文本层兜底，后续可引入统一向量模型。
- 卡组树是多层结构，拖拽、移动、统计与删除规则需要完整单测，否则容易产生环或丢失子树。
- 模型生成标签可能噪声大；限制最多 3 个且可编辑，标签管理只做搜索式选择。
- 自测题结构解析脆弱：提示词固定输出契约，解析失败回退手动拆分；契约变更需同步前端。
- 重绑逻辑复杂：先实现内容哈希与定位匹配，摘录相似度作为兜底；重绑失败必须显式标记来源不可用，不得静默保留。
- 六导航规则已同步到菜单、路由与文档；后续新增导航需同批更新实现与规则，避免再次漂移。
- 无推送通知，依赖应用内角标；用户长期不打开应用时无法提醒。
- V2 统计页依赖 ECharts 与新聚合查询；样本不足时必须显示占位，不得画假曲线。
- 开放：标签重命名与同义合并、Anki 兼容导出、精读笔记成卡、考试日期与学习计划映射。

## 12. V3 漏洞驱动复习闭环（已完成 2026-11-17）

> 页面结构与视觉细节见[复习页设计](复习页设计.md)；本节的边界情况与 §5 规则共同构成实施依据。

### 12.1 目标与范围

V2 解决了「卡能留下来、每轮有会话、统计有趋势」，但没有回答「哪个知识块弱、现在该做什么」。V3 的目标是把复习从「按队列翻卡」升级为「看见漏洞 → 进入簇 → 补强或回原文」的闭环。

本轮包含：

1. 四档评分与秒答独立统计。
2. 今日队列的新卡上限与总量上限。
3. 单卡漏洞级别、簇强度、热力图 v2（行下钻、标签/知识库列、top-N）、独立簇详情与优先补强。
4. 取消自动暂停；手动暂停与孤儿规则保持不变。
5. 卡片批量删除、移动、追加标签、重置进度；单卡重置调度。
6. 显式新建会话与已有会话冲突弹层。
7. 复习页整体改用 TDesign，清理 shadcn-vue 组件与依赖。
8. 统计页四档口径、空态阈值与优先建议。
9. 簇详情四出口：重学、回原文、拆分卡片、生成新角度卡；根因按需 LLM，失败回退规则。

不包含：完整 FSRS、D/R 持久化、自动标签、后台批量拆卡/生成、知识图谱、设置页、移动端（<600px）、多会话并存、推送通知。MCP 工具面不变。

### 12.2 四档评分

规则见 §5.4。设计要点：

- 「秒答」是主观自评，不做前端计时，也不因停留时间自动判档；用户选 4 才记为 easy。
- 秒答用于区分「记得但想得慢」与「完全自动化」；因此稳定度 ×5、等级 +2，且必须独立计数，不能并入「想起来」。
- 忘记仍重置稳定度 5、等级回 L0、次日到期；不在当轮重出，避免同一轮反复打击。
- 评分为一次不可逆推进；重复点击由前端立即禁用按钮，服务端按客户端请求 ID 与会话内卡唯一性幂等。
- 评分请求失败时保留当前卡与已翻面状态，显示重试；不自动进入下一张。
- 历史会话与旧日志没有秒答时按 0 显示；不按「想起来」反推，不改写旧报告。

### 12.3 今日队列

- 今日队列 = 到期卡 + 新卡；到期优先，新卡最多 20 张，总量最多 100 张。
- 到期包含逾期与今日到期；排序为逾期最久 → 今日到期 → 新卡（按创建时间）。
- 到期卡用满额度时不出新卡；新卡额度也受总量约束。新卡指复习次数为 0 的卡，评分后立即退出新卡额度。
- 卡组子树只缩小范围，不重置总量或新卡额度；额度按用户按日计算，不按卡组分配。
- `manual` 与漏洞簇补强会话不占每日额度；只有 `daily` 会话与旧无会话评分计入今日完成数。
- 队列为空但存在 active 会话时，优先显示「继续复习」，不显示「今日暂无待复习」。
- 队列为空且今日已完成时显示完成统计；队列为空且今日未完成时引导创建或生成卡片，并给行动入口。
- 04:00 为日界；跨日未完成的 `daily` 与 `manual` 会话过期，未完成卡回到下一次队列，历史会话保留。
- 所有到期判断以服务端为准，前端不本地推算；时区使用服务端配置。

### 12.4 漏洞级别、簇强度与热力图

只对 `active` 卡评估。手动暂停、孤儿、历史自动暂停且未恢复的卡不进入热力图、优先补强与重学会话。

| 级别 | 条件 |
|---|---|
| 严重 | 可撑 < 3 天，或连续忘记 ≥ 2 |
| 警告 | 非严重，且可撑 < 10 天，或最近一次忘记，或最近两次忘记/想得慢 |
| 观察 | 非以上，且逾期 ≥ 3 天，或最近一次为想得慢 |
| 健康 | 非以上，且至少复习 1 次 |
| 暂无数据 | 复习次数为 0 |

- 多条件命中取最高级别，并返回可读原因；累计忘记次数不单独决定级别，避免历史忘记一次永久警告。
- 「最近两次」取最新 2 条日志；0 次记录直接归「暂无数据」，不判健康。
- 「可撑天数」由当前稳定度与距上次复习时间计算，不新增持久化字段。
- 簇 = 卡组 × 列。行取当前 scope 的直接子卡组并聚合子树；scope 自身挂卡且有子组时增加「本组卡片」行；默认 8 行，超出合并「其他卡组」，可展开到 50。
- 列优先取卡片标签；无标签回退 active 知识来源所属知识库；再无来源归入「未分类」；不再默认按来源文档分列；默认 10 列，超出合并「其他主题」，可展开到 30。
- 多标签卡分别计入每个标签列；各列卡数允许重叠，分母也重叠；禁止把多列百分比相加当作整体覆盖率。
- 知识库名称来自知识库记录；同名知识库按 ID 分列。
- 主要来源失效但仍有其他 active 知识来源时，使用下一条 active 来源所属知识库；全部知识来源失效的卡是孤儿，不进入热力图。
- 簇强度 = 簇内权重和 ÷ 簇内 active 卡总数；严重 1、警告 0.5、观察 0.25、健康 0、暂无数据 0 但计入分母。
- 簇级别取强度分档与簇内最高卡级别的较高者；强度数字仍按加权公式显示，避免单张严重/警告卡被新卡稀释后隐藏。例：10 张卡中 1 张严重、9 张未复习 → 强度 10%，级别仍为严重。
- 基础级别按强度分档：严重 ≥60%，警告 40%–59%，观察 20%–39%，健康 <20% 且簇内至少一张已复习卡；没有已复习卡时为「暂无数据」灰格。
- 只有观察、警告、严重格可点击进入独立簇详情；健康格、other 桶不可点击，other 桶只提供「显示全部」。
- 全站最多 3 个簇获得视觉强调（优先补强排序前 3 名，不足 3 个按实际数量），但热力图仍全量着色；强调不是只计算 3 个簇。
- 优先补强只列严重与警告簇，按强度降序、严重卡数降序、名称稳定排序；观察簇只在底部显示数量摘要。
- 簇详情为独立子路由，建议列只显示可读动作：严重/警告「重学」、有可用来源「回原文」、观察「再观察」；根因按需 LLM，失败回退规则；四出口为重学、回原文、拆分卡片、生成新角度卡。
- 系统洞察为规则引擎，不做 ML：同一行出现 ≥2 个严重簇时提示卡组多子主题告急；同一列跨卡组出现 ≥2 个严重簇时提示主题普遍薄弱；多条命中按严重簇数降序、行优先于列稳定排序，只显示一条。
- 热力图列顺序按列内最高簇级别、列强度总和、名称稳定排序，刷新不跳动；列数超过宽度时横向滚动，不截断数据。
- 所有卡都未复习或只有新卡时，热力图全部为「暂无数据」，提示完成一次复习后生成漏洞图，并提供「开始今日复习」入口。

### 12.5 会话、补强与冲突

- 同一用户同时最多一个 active 会话；今日页显示「继续复习」。
- 创建会话必须显式区分「继续当前」与「新建」。服务端不得静默返回旧会话。
- 从簇详情或卡片抽屉发起补强时，若已有 active 会话，前端弹层二选一：「继续当前」或「放弃并开始补强」；不得静默进入旧会话。
- 「放弃并开始」先放弃旧会话，再创建新会话；旧会话已完成部分的日志保留，仍计入统计与今日完成数。
- 补强会话的 N = 簇内严重 + 警告卡数量；观察与健康卡不进入强化会话；N 为 0 时不生成入口。
- 强化会话的卡与今日队列重复时，只影响本次手动会话，不重复占用每日额度。
- 同一会话同一卡最多评分一次；两个标签页同时评分时，服务端按会话与客户端请求 ID 幂等，第二个重复请求不重复推进调度。
- 卡在会话中被删除、暂停或转孤儿时，提交评分返回冲突；前端提示跳过该卡并继续剩余队列，不得静默吞错。
- 会话跨 04:00 时旧会话过期，未完成卡回队列；不长期悬挂。跨 04:00 后继续评分返回会话过期，前端提示重新开始，已完成日志保留。
- 重置进度不改变已存在的会话计划快照；会话内该卡后续评分照常写回，但调度以重置后状态为起点。

### 12.6 卡片批量与重置

- 批量操作先校验全部卡片的归属、存在性与状态，再在单事务内执行；任一卡片不存在、已删除或不属于当前 owner 时整批失败，不做部分成功。
- 批量上限 100 张；达到上限后禁止继续选择并提示。
- 批量删除为软删除，可在卡片页恢复；复习日志、来源与统计保留；恢复后不自动回到今日队列。
- 批量移动只改卡组，不改调度状态与到期时间。
- 批量追加标签与已有标签求并集，不覆盖、不删除；标签去首尾空白、忽略大小写去重；单标签 1–32 字符；每卡最多 10 个；超限整批失败并提示具体数量，不静默截断。
- 空字符串或全空白标签拒绝保存；大小写不同视为同一标签。
- 重置进度只重置调度：等级回 L0、稳定度回初始 10、漏答与连续忘记归 0、到期设为当前复习日并立即进入今日队列（仍受每日额度限制）；日志、统计与历史保留。
- 重置后漏洞按新调度字段与最近 5 次评分重算；日志保留，近期多次忘记的卡可能仍为警告，不立刻变健康。
- 单卡编辑题干命中重复哈希时拒绝保存并提示已有卡，不自动合并。
- 答案超过 200 字在簇详情显示「建议拆卡」提示，并提供拆分卡片入口；拆分需用户确认并暂停原卡。
- 当前来源失效时先尝试下一条 active 知识来源；全部来源失效时行内「回原文」禁用并提示原因，不跳到空页。

### 12.7 统计

- 全局口径，不跟随卡组选择；进入统计时卡组栏隐藏或只读显示「全部卡组」，避免误以为已过滤。
- 保留率 =（想起来 + 秒答）/ 总评分次数；没有评分时显示「—」。
- 评分分布总次数 <5 显示「需要至少 5 次评分才能绘制」；遗忘曲线有效卡 <10 显示「需要至少 10 张卡多次复习才能绘制」；卡组数 <3 时排行模块保留并显示引导。
- 到期预测全为 0 时显示空态，不画全零柱；优先建议没有异常时显示「暂无需要优先处理的卡」，不显示红色列表。
- 会话历史显示四档计数；历史会话秒答按 0 显示。
- 导出包含秒答，旧列保持兼容，新列放在末尾。

### 12.8 界面、术语与交互边界

- 界面禁止出现 L0/L1、稳定度原始值、材料难度、可撑概率等算法黑话；统一翻译为「已记住 · 复习 N 次」「记忆可撑约 N 天」「第 N 次复习就忘记」等可读文案。
- 严重卡横幅根据可用字段选文案：有忘记次数用「第 N 次忘记」或「连续忘记 N 次」，否则用「记忆可撑不足 3 天」，不伪造 0 次忘记。
- 正常/已记住不显示 badge；严重、警告、暂停、孤儿、来源失效显示语义标签；从未复习显示灰点。
- 所有警告必须至少有一个行动按钮；空态必须给出下一步：打标签、开始复习、生成卡片、调整筛选或返回。
- 不再提供「刷新」按钮；筛选或数据变更后自动更新。
- 每个标签只有一个页头；今日页唯一主 CTA 是「开始今日复习」；生成、导入、导出收进「更多」。
- 复习模式 Esc 暂存退出，空格翻面，1–4 评分；输入框聚焦时不响应快捷键；空格翻面不滚动页面。
- 600–760px 今日页单列，卡组栏收进顶部下拉；热力图与簇详情表格横向滚动、首列固定；600px 以下不承诺布局，但不得出现脚本错误。
- 浅色/深色跟随 TDesign token；ECharts 主题切换后重绘；热力图色阶在深色下保持对比度。
- 所有按钮可 Tab 到达、焦点可见；加载失败显示重试，不显示空白页；控制台 0 错误。
- 千卡规模热力图目标 ≤500ms；聚合在服务端完成；前端不拉全量日志自行计算。
