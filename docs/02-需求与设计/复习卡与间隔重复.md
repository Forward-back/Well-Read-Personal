# 复习卡与间隔重复

> 状态：规划
> 最后更新：2026-11-12
> 目标读者：产品、后端、前端、测试
> 关联：[学习场景与RAG](学习场景与RAG.md)、[问答与引用](问答与引用.md)、[交互式精读](交互式精读.md)、[复习卡身份与吸收模型](../06-架构决策/0001-复习卡以知识点为单位并吸收重复来源.md)、[当前进度](../03-进度与交接/当前进度.md)

## 1. 背景与目标

学习闭环目前停在「资料 → 问答理解 → 精读细读」。「复习模式」生成的自测题只存在于当次回答，用户看过即忘，没有积累，也没有第二次接触。个人知识库最有价值的资产不是文档，而是「哪些内容我已经掌握、哪些还没」的记录。

本功能把一次性自测题变成持久复习卡，并用间隔重复安排第二次、第三次接触，补齐「记住」环节。

卡片的基本单位是知识点，不是对话片段。同一知识点只有一张卡；不同对话、不同文档产生的同一知识点通过「吸收」成为该卡的额外来源，避免卡片随对话次数线性膨胀。

目标：

- 复习卡可积累、可检索、可编辑、可导出，成为长期学习资产。
- 每张卡可回溯原文；原文变化时卡片不静默失效。
- 用卡组树组织卡片，卡片量增长后仍能按主题定位。
- 每日复习有明确上限和预计时长，10–15 分钟可完成，能长期坚持。
- 保留每次复习的等级与时间，形成可度量的记忆数据。

非目标：

- 不做 FSRS 等复杂记忆模型，不做 Anki 兼容导入导出。
- 不做推送通知、移动端、多人共享或社交化学习。
- 不新增 MCP 工具，17 个只读工具面不变。
- 不修改知识库入库打标逻辑；卡片只继承已有标签与模型推荐标签。
- 不做纯图片题与看图问答，图片只作为卡背来源材料。
- 不做手动空白建卡；卡片必须来自自测题保存或文档生成，且带知识来源。
- 本轮不做精读笔记自动成卡，只在来源模型上预留。

## 2. 核心循环与成功度量

核心循环：

1. **捕获**：在复习模式回答中保存自测题，或从知识库/文档生成，存入指定卡组。
2. **调度**：三档简化 SM-2 计算下次到期时间，每日总量封顶。
3. **复习**：按卡组范围翻卡、自评、回原文，单卡 15 秒内完成。
4. **修复**：反复忘记的卡暂停并引导回原文或精读，而不是无限重复。
5. **度量**：保留率、到期预测、薄弱知识点反哺下一轮生成与精读。

成功度量（单用户自用，不做增长指标）：

| 指标 | 目标 | 用途 |
|---|---|---|
| 生成预览接受率 | ≥ 60% | 判断生成提示词质量 |
| 每日任务完成率 | ≥ 80% | 判断负荷是否合理 |
| 7 日保留率 | ≥ 80% | 判断调度是否有效 |
| 卡片孤儿率 | < 5% | 判断来源绑定是否可靠 |
| 平均单卡耗时 | 10–20 秒 | 判断卡片是否原子 |
| 重复吸收率 | 持续观察 | 判断自测题是否在制造重复 |

## 3. 非典型设计

以下设计不是行业标配，但对「个人资料型学习」收益明显。

### 3.1 卡片是知识点，来源可以多条

保存新题时先做全局查重。命中同一知识点时默认「吸收」：把新题登记为已有卡的一条新来源，不新建卡片。卡片详情按时间列出全部来源，调度只有一份。

理由：对话式学习会反复问同一概念，如果每次自测题都建卡，卡片量与噪声必然失控。吸收让重复变成证据积累。

### 3.2 来源锚点与孤儿卡降级

每张卡保存来源知识、分块、原文片段与定位信息；卡背固定展示原文摘录，可一键打开分块。来源被删除或重新解析后，先尝试重绑，失败则标记该来源不可用；全部知识来源都不可用时才转为孤儿卡并暂停，由用户重绑或删除。

理由：脱离原文的 AI 生成卡片容易变成无来源断言。孤儿处理把数据腐烂变成可见状态。

### 3.3 失败路由，而不是无限重复

同一张卡累计 3 次「忘记」自动暂停，标记「回原文」，一键跳转来源分块或进入精读。恢复时重置漏答计数。

理由：反复记不住的卡通常不是记忆问题，而是理解问题。继续刷只会消耗时间，应该回到资料。

### 3.4 每日总上限与债务稀释

每日任务 = 到期卡优先 + 新卡补位，总量封顶默认 30 张。积压时不显示「欠 143 张」，只显示「今日 30 张，约 10 分钟」。超额部分自然顺延。

理由：复习产品最大的流失原因是积压焦虑。对单用户而言，持续完成比一次性补完更重要。

### 3.5 键盘优先的复习流

空格/回车翻面，1 = 忘记，2 = 模糊，3 = 记住，S 暂停，E 编辑，O 回原文，Esc 退出。整轮复习不需要鼠标。

理由：复习是高频重复动作，操作延迟直接决定坚持率。

### 3.6 来源版本感知

文档重新上传、代码仓库重新同步后，卡片定位内容可能变化。系统按定位信息重绑：

- 内容哈希一致：静默重绑。
- 位置仍在但内容变化：保留卡片，标记「来源已更新」，提示用户复核。
- 知识条目删除或无法定位：该来源不可用；全部知识来源不可用时卡片转孤儿。

理由：个人知识库会持续更新，卡片必须跟得上版本，否则引用变成过期快照。

### 3.7 生成先预览，全局语义去重

生成结果先进入预览，不直接入库；逐卡接受或拒绝，支持全选。查重分三层：规范化问题哈希精确匹配；字符三元组相似度；向量余弦相似度。命中后默认吸收，用户可显式选择新建。

理由：模型生成卡片质量波动大，预览是最便宜的质量闸门；语义查重能拦住换词重问。

### 3.8 自测题内嵌保存

复习模式回答的「自测题」区每道题旁直接出现「保存为卡片」，自动附带推荐来源、引用与卡组选择；支持手动勾选引用，解析失败时提供整段手动拆分弹窗。批量保存是显式按钮，默认不自动执行。

理由：复制粘贴会杀死转化率；保存动作必须发生在看到题目的当下，但不能默认全量入库。

### 3.9 卡组树与搜索式标签

卡片用多层卡组树组织，一张卡只属于一个卡组节点；标签用于跨卡组主题。标签选择不做全量下拉：生成时模型最多推荐 3 个，其余场景只用实时搜索与回车创建。知识库若已有标签，建卡时继承一份快照。

理由：卡片量增长后，卡组树负责「在哪」，标签负责「是什么」；全量标签下拉在标签数上百后不可用。

### 3.10 学习数据可带走

支持导出全部卡组、卡片、来源、调度状态与复习记录为 JSON，包含来源路径与引用。删除知识库不自动删除卡片，孤儿卡由用户处理。

理由：个人系统必须保证数据所有权；导出也是迁移与备份手段。

### 3.11 弱项反哺

统计页按卡组子树与标签展示 30 天保留率，低于 60% 且样本足够的主题进入「薄弱项」，提供两个动作：针对该主题生成新卡组，或进入精读重读原文。

理由：复习数据只有回到学习动作才产生价值，否则只是仪表盘。

## 4. 用户流程

### 4.1 从复习回答保存

1. 问答选择 RAG + 复习模板，得到含自测题的回答。
2. 自测题每题旁显示「保存」；点击打开保存弹窗：卡组选择（默认上次使用）、推荐来源与引用、原文摘录、标签搜索。
3. 保存时先查重。命中重复卡时并排展示已有卡与本次题目，默认「附加为来源」；用户可改为移动到当前卡组或仍要新建。
4. 确认后卡片进入待复习队列；当日新卡额度已满时顺延到次日。
5. 答案底部提供「保存全部自测题」，默认不勾选；批量逐题查重并给出来源附加、跳过与新建汇总。

### 4.2 从文档或知识库生成

1. 复习页点击「生成卡片」，选择知识库或若干文档、目标卡组、数量（5/10/20）、卡型（Q/A、填空、混合）。
2. 系统生成预览，展示题干、答案、来源片段、模型建议标签与去重标记；预览项可直接编辑。
3. 逐卡接受或拒绝，或全选接受；入库后按新卡闸门排队。

### 4.3 每日复习

1. 侧栏「复习」显示今日到期角标。
2. 复习首页展示今日任务：到期 N 张、新卡 M 张，合计不超过上限，附预计时长；可把范围限定到某个卡组子树。
3. 开始复习：翻卡、自评三档；忘记的卡在当轮末尾重出一次。
4. 完成页展示完成数、记住率、连续天数、次日到期与薄弱项入口。

### 4.4 卡片与卡组管理

- 卡组树支持新建、重命名、拖拽排序、移动、删除。
- 卡片列表支持卡组子树、标签、状态、卡型筛选，关键词搜索，结果高亮。
- 支持编辑卡片、移动卡组、暂停/恢复、删除、合并重复卡、处理孤儿卡、导出。

## 5. 业务规则

### 5.1 卡片

- 一卡一知识点：问题可独立回答；答案一句话为主，解析可选。
- 卡型：Q/A 与填空。填空卡必须保留原句，只挖一个空；答案为空缺词，解析可选。
- 每张卡必须归属一个卡组，且至少一条知识来源；一张卡可挂多条来源，调度记录只有一份。
- 状态：`active`、`suspended`、`orphaned`、`deleted`。`source_updated` 是标记，不改变状态。
- 删除为软删除；哈希只检查未删除卡片，允许同名卡重新创建。
- 编辑题目后重算哈希与向量；编辑答案不影响调度。
- 暂停卡不进入队列；恢复时漏答计数清零。
- 卡背可附最多 3 张来源图片，图片不参与卡面出题。

### 5.2 卡组

- 多层树结构，一张卡只属于一个节点；跨主题用标签。
- 同一父节点下名称唯一，名称去首尾空白后比较。
- 首次使用时自动创建「默认卡组」；默认卡组不可删除。
- 卡组可重命名、拖拽排序、移动到另一个卡组下；移动必须防止形成环。
- 卡片移动卡组不改变调度状态与到期时间。
- 删除非空卡组时必须二选一：卡片移到父卡组（顶层则移到默认卡组），或连同卡片删除；默认是移动。子卡组不级联删除，自动挂到被删卡组的父节点或顶层。
- 删除卡组与卡片需要二次确认。

### 5.3 来源与版本

- 来源类型：知识分块来源（可重绑）与会话消息来源（快照，仅作背景）。
- 自测题保存时至少选择一条知识分块来源；默认按题目与引用分块的相似度/排序推荐，用户可勾选调整；只有会话消息、没有知识来源的卡片不允许创建。
- 会话删除不影响卡片；消息来源标记「原会话已删除」，知识来源继续可用。
- 知识条目归档或进回收站不判孤儿；卡片仍可复习，打开原文时提示状态。
- 知识条目硬删除或重新解析后无法定位分块：对该来源先重绑，失败标记不可用。
- 重绑顺序：同知识条目 + 内容哈希；同知识条目 + 路径/符号定位；同知识条目 + 摘录相似度。
- 全部知识来源不可用时卡片转孤儿并暂停；部分来源不可用只标记该来源。
- 代码重同步会重建分块 ID，必须依赖路径、符号、行号定位重绑，不能只存分块 ID。

### 5.4 调度

三档简化 SM-2，等级 L0–L6，间隔固定为 1、3、7、15、30、60、120 天。

| 评分 | 等级变化 | 下次到期 |
|---|---|---|
| 记住 | 升一级，封顶 L6 | 今天 + 新等级间隔 |
| 模糊 | 等级不变 | 今天 + 当前间隔的一半（向上取整，最少 1 天） |
| 忘记 | 回到 L0 | 今天 + 1 天，并在当轮末尾重出一次 |

- 同一张卡当日多次评分以最后一次为准。
- 漏答计数累计，达到 3 次自动暂停；恢复后清零。
- 日界为本地时间 04:00，凌晨学习计入前一天。
- 新卡首次评分按 L0 起步；直接选「记住」进入 L1。

### 5.5 每日负荷与暂停

- 每日完成总量上限默认 30，可在复习页调整，范围 10–100；配置存设置 KV `review-config`。
- 上限全局共享，不按卡组拆分；按卡组子树复习只改变队列范围，不重置额度。
- 队列顺序：逾期卡（最久优先）→ 今日到期 → 新卡（按创建时间）。
- 到期卡已超过上限时不出新卡；未用完额度才补新卡。
- 同一张卡当日重复出现只计一次完成数。
- 暂停复习 N 天：设置恢复日期，期间不进入队列；到期日早于恢复日的卡顺延到恢复日，避免积压。

### 5.6 生成

- 模型：复用直连模型；未配置时回退默认知识问答模型；两者都没有时明确报错并引导配置。
- 输入：知识库或指定文档；采样文本分块，跳过纯图片块与过短分块；上下文带文档标题与章节路径。
- 必须选择目标卡组，默认上次使用的卡组；可在弹窗内新建卡组。
- 数量：单次 5/10/20，上限 50；上下文预算 12000 字符。
- 输出契约：卡型、问题、答案、解析、来源分块、原文摘录、建议标签（最多 3 个）；来源分块必须来自本次输入集合，越界结果丢弃或在预览中标注无效。
- 填空卡由模型从原文定义句/公式生成，保留原句与出处，只挖一个空。
- 预览不落库；入库走批量接口，重复项按 5.7 处理。
- 若题目涉及原文图片，可把对应来源图附到卡背，最多 3 张。

### 5.7 去重、吸收与合并

> 首轮只实现第 1、2 层；第 3 层向量查重保留字段与接口，见 §13。

- 查重范围：租户内全部卡组，不只当前卡组。
- 第一层：规范化哈希（去空白、统一小写、去标点）。精确命中直接视为重复。
- 第二层：题干字符三元组相似度 ≥ 0.85，视为疑似重复。
- 第三层：题干向量余弦相似度 ≥ 阈值（初始 0.90），视为疑似重复。向量使用主要来源知识库的 embedding 模型；只与同一模型生成的向量比较。模型不可用时退回文本层，并记录原因。
- 命中后默认动作是「吸收」：把本次题目登记为已有卡的新来源，保留原卡组与调度；保存弹窗提供「移动到当前卡组」与「仍要新建」。
- 吸收时若新来源答案与已有卡答案冲突，提示差异，由用户选择保留原答案、替换答案或暂不附加。
- 批量生成入库：精确重复自动跳过；疑似重复默认不选中，可强制接受或吸收。
- 已存在的重复卡可在管理页合并：选择一个目标卡，其余卡的来源全部并入目标卡，目标卡调度不变；被合并卡软删除，其复习记录保留但不再计入统计。
- 编辑题目可能产生新的疑似重复，保存时再查一次，只提示不阻断。

### 5.8 标签

- 标签全局于租户，用于跨卡组主题；卡组树负责归属，标签负责属性。
- 建卡时继承主要来源知识已有标签的快照；知识库标签后续变化不自动同步，用户可手动编辑。
- 生成卡片时模型最多推荐 3 个标签，进入预览可编辑。
- 标签选择器不展示全量下拉：只提供实时搜索匹配与回车创建；创建时按去空白、忽略大小写去重。
- 自测题保存不调用模型推荐标签；沿用继承快照，用户可搜索添加。
- 不修改知识库入库自动打标逻辑。知识库开启既有 `auto_tag_config` 时，卡片只继承打标结果，不主动创建新标签。
- 标签重命名、同义合并不在本轮范围；卡片上可直接移除错误标签。

### 5.9 搜索与筛选

- 关键词子串搜索题干、答案与来源标题，忽略大小写，结果高亮。
- 叠加筛选：卡组子树、标签、状态（正常/暂停/孤儿）、卡型。
- 排序：最近添加、最近复习、到期时间、漏答次数。
- 不做向量语义搜索；语义能力只用于保存时查重。

### 5.10 统计

- 今日：完成数、记住率、用时。
- 7 日到期预测。
- 30 天按卡组子树与标签的保留率。
- 连续复习天数：当日至少完成 1 张即计入。
- 薄弱项：保留率 < 60% 且复习次数 ≥ 5 的卡组或标签。

## 6. 概念数据模型

四类实体，字段级定义以迁移与 Swagger 为准。

**卡组**：租户、父卡组、名称、排序、状态。支持树形查询与子树计数。

**复习卡**：租户、卡组、卡型、题干、答案、解析、标签、状态、等级、下次到期、漏答计数、复习次数、题干哈希、题干向量与向量模型、来源更新时间标记。

**卡片来源**：卡片、来源类型（知识分块/会话消息）、知识与分块、定位信息（路径/符号/行号/章节/内容哈希）、原文摘录、来源图片、主来源标记、可用状态。

**复习记录**：卡片、评分、评分前后等级、间隔天数、复习时间、可选反应时长。

关键不变量：

- 卡片必须属于一个卡组；一张卡不能跨卡组。
- 一张卡至少一条知识来源；来源可多条；调度状态属于卡片，不属于来源。
- 全部知识来源不可用时卡片才转孤儿并暂停；会话消息来源失效不算孤儿。
- 卡组删除时卡片与子卡组按 5.2 规则处理，不使用数据库级联删除。
- 卡片哈希不做数据库唯一约束，避免软删除墓碑阻塞重建；由服务层校验。
- 到期队列按租户 + 状态 + 下次到期建立索引；复习记录按卡片 + 时间建立索引。

## 7. 接口轮廓

全部挂在 `/api/v1/review/*`，只接受 JWT；API Key 网关默认拒绝，MCP 不暴露。

- 卡组：树查询、创建、重命名、移动、删除（带卡片处置参数）。
- 卡片：列表（卡组子树、标签、状态、卡型、关键词、排序）、详情、创建、编辑、移动、删除、暂停/恢复、合并、重绑来源。
- 查重：保存前检查与保存时校验，返回候选卡与相似度来源。
- 复习：今日摘要、到期队列（可选卡组子树）、提交三档评分。
- 生成：预览与批量入库分离；预览带来源与建议标签。
- 标签：按关键词搜索候选（不返回全量列表）、创建；随卡片保存。
- 统计：今日、7 日预测、30 天保留率、薄弱项。
- 导出：JSON 下载，含卡组树、卡片、来源、复习记录。
- 设置：`/api/v1/settings/kv/review-config` 读写每日上限与暂停日期。

- 第六导航项「复习」，带今日到期角标；`CLAUDE.md` 五项导航规则同步改为六项，前端菜单、路由与界面规范一并更新。
- 复习首页：左侧卡组树与智能列表（全部、今日、待复核、孤儿、最近添加、最近复习）；中间今日任务、开始按钮、连续天数、7 日预测、薄弱项；右侧或顶部设置入口。

## 9. 与现有系统的边界

- 问答：只增加保存入口与复习模板结构化契约，不改普通问答链路。
- RAG：卡片生成复用模型服务，不进入检索索引，不影响问答引用。
- 知识库：删除知识库不删卡片；知识/分块变更触发来源重绑与孤儿判定；不改入库自动打标逻辑。
- 代码同步：依赖路径、符号、行号重绑；分块 ID 变化不直接判孤儿。
- 会话：删除会话不删卡片，只让消息来源失效。
- 精读：本轮不自动成卡；孤儿卡与薄弱项可跳转精读，属后续扩展点。
- MCP：工具面保持 17 个只读工具，不新增复习工具。
- 设置：新增 `review-config` KV；单 Key 与既有设置分区不变。
- Embedding：使用主要来源知识库的 embedding 模型生成题干向量；跨模型不比较，模型缺失时退回文本相似度。

## 10. 验收

功能：

- 卡组树可建、改名、移动、排序、删除；删除非空卡组按选择移动或删卡，子卡组正确重挂。
- 从复习回答保存自测题为卡片，卡组、来源、引用、标签正确；批量保存给出汇总。
- 重复保存命中时默认吸收，卡组与调度不变；可移动到当前卡组；可强制新建。
- 从文档与知识库生成预览，接受后入库；重复项被跳过或吸收。
- 三档评分按规则推进；忘记卡当轮回出；累计 3 次忘记自动暂停。
- 每日总量上限全局生效；到期超限时不出新卡；按卡组子树复习不重置额度；暂停后到期日顺延。
- 文档删除与代码重同步分别触发来源不可用与重绑；全部来源失效才显示孤儿；会话删除不判孤儿。
- 合并卡片后来源完整、目标调度不变、旧卡不再出现在队列。
- 标签选择器只提供搜索与创建；生成时最多 3 个建议标签；继承标签快照正确。
- 卡背来源图片可显示并回原文。
- 键盘全流程可完成一轮复习；导出 JSON 含卡组树与调度状态。

验证：

- 调度器单测覆盖等级推进、模糊半数、漏答暂停、日界、全局上限与暂停顺延。
- 查重单测覆盖哈希、三元组、向量、跨卡组吸收、答案冲突与合并。
- 生成契约校验、来源白名单、标签上限与批量入库有单测。
- 浏览器完成 4.1–4.4 全流程，控制台 0 错误。
- 后端全量测试、前端 type-check/测试/build、镜像重建通过。
- PostgreSQL 与 SQLite 基线同步更新。

质量度量：

- 预览接受率、每日完成率、7 日保留率、孤儿率、重复吸收率按第 2 节目标观察，首轮用真实数据记录。

## 11. 风险与开放问题

- 跨知识库 embedding 模型可能不同，语义查重会漏检；靠文本层兜底，后续可引入统一向量模型。
- 卡组树是多层结构，拖拽、移动、统计与删除规则需要完整单测，否则容易产生环或丢失子树。
- 模型生成标签可能噪声大；限制最多 3 个且可编辑，标签管理只做搜索式选择。
- 自测题结构解析脆弱：提示词固定输出契约，解析失败回退手动拆分；契约变更需同步前端。
- 重绑逻辑复杂：先实现内容哈希与定位匹配，摘录相似度作为兜底；重绑失败必须显式标记来源不可用，不得静默保留。
- 第六导航改动触达多份文档与测试，需与功能同批提交，避免规则与实现不一致。
- 无推送通知，依赖应用内角标；用户长期不打开应用时无法提醒。
- 开放：标签重命名与同义合并、Anki 兼容导出、精读笔记成卡、考试日期与学习计划映射。

## 13. 首轮 MVP 决议（2026-11-14）

首轮目标是把「复习回答里的自测题保存成卡，按三档调度复习」跑成真实闭环，不追求设计文档的全量能力。

### 13.1 范围

首轮包含：

1. 数据模型与迁移：卡组树、复习卡、卡片来源、复习记录；PostgreSQL 与 SQLite 各新增 `000001` 增量迁移，`000000_init` 保持冻结，见 [ADR 0002](../06-架构决策/0002-保留单基线并新增增量迁移.md)。
2. 卡组与卡片基础管理：树查询、创建、重命名、移动、删除处置；卡片创建、编辑、移动、暂停/恢复、软删除与恢复。
3. 调度与队列：三档简化 SM-2、04:00 日界、每日上限、卡组子树范围、暂停顺延。
4. 自测题保存：复习模板输出稳定结构标记；保存弹窗选择卡组、来源与标签；解析失败提供手动拆分；保存前做查重与吸收。
5. 第六导航「复习」、复习首页、复习流、键盘操作、今日到期角标。
6. 来源基础能力：来源锚点保存稳定 ID、路径/符号/行号与内容哈希；来源失效标记；全部知识来源失效时转孤儿并暂停。
7. 使用安全：最近一次评分可撤销；刷新或重新进入可恢复当前复习轮次；删除卡片可恢复；第一张卡、今日无到期、模型未配置、来源失效均有明确空状态。

首轮不包含，留待后续：

- 从文档或知识库生成卡片、生成预览与批量入库。
- 统计、薄弱项、导出 JSON、合并重复卡、卡背来源图片。
- 填空卡；首轮只做 Q/A。
- 标签重命名、同义合并、向量查重。
- MCP 工具、移动端、推送通知。

### 13.2 去重

首轮实现规范化哈希与字符三元组相似度；题干向量字段、查重接口与后续模型配置保留，但不参与判定。命中后的默认动作仍是「吸收为来源」，用户可显式新建。

### 13.3 自测题结构

复习模板的「自测 2 题」必须带稳定标记，保存时只解析该区块；解析失败不回退为整段自动猜测，而是打开手动拆分弹窗。首轮不增加第二次模型抽取调用。

### 13.4 验收调整

设计文档 §10 的全量验收按首轮范围裁剪：

- 首轮必须验证：保存、查重吸收、三档调度、每日上限、来源失效与孤儿、撤销评分、刷新恢复、删除恢复、空状态。
- 首轮不验收：文档生成、统计、导出、合并、卡背图片、填空卡、向量查重。
- 真实数据验收：不少于 20 张卡，连续两轮复习；删除来源后卡片状态正确；恢复卡片后调度不丢。
- 迁移验收：现有数据库升级到 `000001` 后原知识库与问答数据可读；全新数据库从基线加增量启动成功。
