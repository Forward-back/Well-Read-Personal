# 落地页设计（PostHog 布局语言）

> 状态：优化中
> 最后更新：2026-11-19
> 目标读者：产品、前端、设计
> 关联：[ADR 0007](../06-架构决策/0007-PostHog布局语言落地页与壳层改造.md)、[界面规范](界面规范.md)、[系统总览](../01-项目总览/系统总览.md)

## 1. 目标与非目标

目标：

- 以 posthog.com 首页为版式参考，做一个登录后可访问的 WellRead 落地页，验证 PostHog 布局语言在 Vue + TDesign 技术栈下的还原度。
- 把版式、背景系统、字体层级、间距与动效沉淀成可复用规则，为后续全壳层替换提供依据。
- 用指标化验收代替整页像素对比，保留可回归的设计 token 与证据。

非目标：

- 首版不做公开营销站、SEO、注册与转化追踪；不做多语言版本。
- 不重做功能详情页（问答、知识库、精读、复习、技能、设置），后续逐页单独对齐。
- 不复制 PostHog 的 logo、吉祥物、客户 logo、评价与图库素材。
- 不引入 React 实现或第二套组件库；不使用 shadcn-vue / reka-ui。
- 支持跟随壳层暗色主题，不新增独立主题开关。

## 2. 路由与入口

- 路由 `/`：共享 `AppShell` 下的落地页，`meta.requiresAuth = true`；`/welcome` 重定向到 `/`。
- 左侧导航固定「首页」入口指向 `/`；其余功能走左栏，设置只在右侧辅助栏。
- 登录成功默认进入 `/`；若带安全的 `redirect` 参数则回到原业务页。
- Hero 提问提交后跳转真实问答页并预填问题；预填方式复用现有草稿/query 机制，不新增后端接口。

## 3. 参考结构与分区映射

采集结论（2026-11-18）：posthog.com 首页不是传统整页滚动的营销站，而是「模拟应用」结构。

- 顶部浮动导航条：1424×40，`#cbd5b9` 面，4px 圆角，`0 25px 50px -12px rgba(0,0,0,.25)` 阴影；左侧品牌与 Products/Pricing/Docs/Community/Company/More，右侧 Get started CTA（32px 高、6px 圆角、`#cd8407`）。

- 右侧图标栏：112px 宽、84px 项；About us、Changelog、Company handbook、Store、Careers、Trash。
- 窗内 reader 文章：内容宽 979px（窗口内左右各 80px 内边距），顶部留白 48px；正文 18/32、字重 500、`#374151`。

## 5. 字体策略

- 不引入 RoundHog、Squeak 等品牌或商业字体。
- 正文候选 DM Sans；展示/标题候选 Bricolage Grotesque；等宽使用开源等宽字体。
- 字体文件自托管，避免运行时依赖外部 CDN；中文回退到系统中文无衬线栈。
- 替换后按参考站逐项校准字号、行高、字重与字距；中文换行与标点挤压单独检查。
- 字重：应用界面正文与控件只用 400 / 500 / 600；落地页展示标题按参考站允许 400 / 500 / 600 / 700 / 800；不引入第五种以上字重。
- 实测参考字阶：H1 36/40、字重 800、字距 -0.9px；H2 24/32、字重 700、字距 -0.6px；正文 18/32、字重 500；Hero 副文 17/25.5；全局 16/24。替代字体按此校准，不改变层级比例。

## 6. 动效与交互

范围：完整交互，按采集到的 transition spec 与运行时证据还原。

- 页头：吸顶、滚动后的背景模糊/透明度变化、下拉菜单。
- 卡片与按钮：hover、focus-visible、active、disabled 状态。
- 入场与滚动：分区进入动画、滚动驱动的位移/透明度。
- 列表类效果：logo/场景跑马灯（如参考站存在）。
- Hero 提问：输入交互、建议问题点击、提交跳转。
- 移动端：导航收起与展开。

实现优先级：CSS transition/animation → VueUse / IntersectionObserver → 现有 Swiper 12。某个效果若无法在 Vue 中等价实现，先报告差异与替代方案，不得静默降级。尊重 `prefers-reduced-motion`。

采集到的动效事实：

- 页面使用内部滚动容器，未检测到滚动驱动的状态变化（`scroll-transitions.json` 为空）；顶栏与左右栏固定，窗内内容滚动。
- hover 规律以 CSS 为主：0.15s `cubic-bezier(0.4, 0, 0.2, 1)` 位移/描边；左栏项 hover 上移 0.5px；部分 hover 为 0s 即时变化。
- 检测到 Framer Motion（9 处 bundle 命中），SVG path 描边动画约 164–800ms、linear，另有 3–5s 循环装饰动画。
- `.group:hover > .human-coded-glint::after` 的 glint 动画（0.65s ease-out）无法稳定观测，记录为 unsupported；实现时可作为可选装饰，不作为验收硬项。

## 7. 素材策略

- 页面外层背景使用仓库现有草地素材 `frontend/src/assets/img/app-bg/grass.jpg`（个人本地使用，不新增 PostHog 装饰 JPG）。
- 渐变、噪声、箭头等其余通用装饰用 CSS/SVG 还原，优先从提取到的样式复现。
- 产品展示区使用 Vue 自绘的界面示意面板（真实 DOM），不使用截图，避免数据泄露与过期。
- 图标使用 TDesign 图标或自绘 SVG；不使用 emoji，不新增 lucide 图标。
- 不下载、不打包 PostHog 的品牌位图、吉祥物与客户素材。

  - 找出我复习里最薄弱的知识块

### 8.3 知识如何被消化

标题：**不是把整本书丢给模型**

1. 收进来：上传文档、网页或代码项目。
2. 切开来：解析、分块，建立向量与关键词索引。
3. 查得到：提问时先检索到最相关的分块。
4. 说得清：回答附带可定位的引用，能回到原文。

### 8.4 核心能力

标题：**把知识用起来的四件事**

- 问答：RAG与直连双模式，流式回答，引用可回原文。

- 复习：四档评分与漏洞热力图，每天补强最该补的那几张。
- 技能：把你的提问习惯沉淀成可复用的技能。

### 8.5 使用场景

标题：**一个人也能用得起来**

- 读论文：先精读方法，再把关键细节放进复习队列。
- 写代码：把项目文档和代码库收进知识库，随时可查。
- 长期学习：把每次问答沉淀成卡片，隔几天再见一次。

## 9. 验收清单

主视口 1440px；768px 与 390px 做响应式抽查。每项在阶段记录中写明测量值与偏差。

- 背景：外层草地素材、顶栏 `#cbd5b9`、窗口暖米纸 `#F7F5F0`、卡片 `#fdfdf8`/`#fff`；点阵与光晕参数与参考测量一致（色差 ΔE ≤ 3）；壳层内滚动条视觉隐藏但滚动可用。
- 结构：顶栏 40px、左右栏各 112px、窗口 80%×95% 且 20px 圆角；1440 视口下窗口约 1139×802，偏差 ≤ 4px。
- 滚动：页面外层不滚动，滚动发生在窗内容器；滚动条与内容高度行为与参考一致。
- 容器：内容宽约 979px，左右内边距 80px；偏差 ≤ 4px；栅格列数一致，列间距偏差 ≤ 2px。
- 分区留白：上下留白偏差 ≤ 8px（参考分区间距 48px）。
- 字体：字号偏差 ≤ 1px，行高偏差 ≤ 2px，字重一致；H1/H2/正文比例与参考一致。
- 圆角、边框、阴影：采用提取值，不自行近似。
- 按钮：高度、内边距、圆角偏差 ≤ 2px；品牌绿 hover/active/focus 状态完整，文字对比度 ≥ 4.5:1。
- 响应式：三档宽度无横向溢出；栅格按参考断点折叠。
- 动效：时长偏差 ≤ 50ms，缓动曲线与采集一致；关键交互逐项回放通过。
- 可访问性：可 Tab 到达，focus-visible 可见，不以颜色单独传达状态。
- 工程质量：`npm run type-check`、`npm run build` 通过，控制台 0 错误。
- owner 目视签收，结果记入阶段记录；自动化通过不等于审美通过。

## 12. 风险

- 完整交互可能依赖 React 生态实现，Vue 等价方案存在降级风险，出现时必须先报告。
- 中文字体度量与参考站不同，字号与行高校准可能产生可接受范围内的偏差。
- 窗内滚动是国内/桌面浏览器容易踩坑的结构，需要单独验证滚动条、锚点与键盘行为。
- 参考站的整页插画背景为位图资产，不复用；CSS 替代方案可能与原图在氛围上有差异。
- 参考站结构可能随改版变化，采集时间点与证据路径必须记录。
