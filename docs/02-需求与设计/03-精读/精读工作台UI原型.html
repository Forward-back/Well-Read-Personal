本轮阅读结论

当核心同时收到多个中断请求时，优先级仲裁发生在登记之后、现场保存之前[1]。这意味着高优先级请求不会打断已开始的现场保存动作——这是本章最容易被忽略的设计决策。

作者用「先到先服务」描述默认策略，但 §8.2 中出现了与之冲突的表述[2]，已列入下方矛盾卡。
