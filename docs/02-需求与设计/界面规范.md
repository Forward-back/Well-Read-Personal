# 界面规范

> 状态：当前
> 最后更新：2026-11-14
> 目标读者：产品、前端、设计

## 1. 结构

- 登录页：邮箱 + 密码；不含注册、邀请、OIDC。
- 平台壳层：左侧六项导航 + 内容区；无邀请铃铛、空间切换、角色标签与新手运营入口。
- 六项目导航：问答、知识库、精读、复习、技能、设置。
- 登录后默认 `/platform/creatChat`；`/platform/*` 是唯一业务命名空间。
- 设置五分区：账户与助手、模型与引擎、外部接入、系统健康与队列、关于。

## 2. 页面

| 页面 | 关键内容 |
|---|---|
| 问答 | 历史会话、消息流、引用、技能/知识库提及、模型与网络搜索开关 |
| 知识库 | 知识库卡片、置顶、创建/复制/删除、文档列表、处理时间线、分块、代码项目入口 |
| 精读 | 运行列表、计划、三栏工作台、问题卡、笔记、报告与导出 |
| 复习 | 卡组树、今日任务、翻卡与三档评分、键盘快捷键、卡片暂停/恢复/删除；回答内自测题保存弹窗 |
| 技能 | 个人技能列表、创建/编辑/启停/删除 |
| 设置 | 账户与助手、模型与引擎、外部接入、健康与队列、关于 |

## 3. 视觉与交互

- 沿用既有 WellRead 视觉语言：浅色容器、品牌绿、卡片化列表、圆角 8px。
- 列表/卡片操作优先图标按钮 + tooltip；破坏性操作需确认。
- 长文档与大列表复用虚拟滚动、分页与 Markdown 渲染管线。
- 流式回答保持滚动跟随；用户上滚时暂停自动跟随。
- 文案不出现公司、部门、成员、共享、ACL、审批、治理、审计等企业概念。

## 4. 设置面

| 分区 | 内容 |
|---|---|
| 账户与助手 | 个人资料、密码、全局系统提示词（可恢复默认） |
| 模型与引擎 | 模型、Ollama、解析器、检索、存储后端 |
| 外部接入 | 单只读 API Key 的查看/生成/重置/删除与调用示例 |
| 系统健康与队列 | 系统信息、运行时队列 |
| 关于 | 个人版定位、版本与组成服务 |

## 5. 状态与空态

- 知识库空态引导创建；最近访问空态引导打开文档。
- 未配置模型时创建知识库可进入向导并跳转模型配置。
- 上传进度在列表页展示；刷新后显示最新解析状态。
- 错误提示区分参数错误、未认证、资源不存在与服务端错误。

## 6. UI 组件体系与迁移策略

### 6.1 来源与边界

- `shadcn.com.cn` 的组件实现是 React + Tailwind，当前前端是 Vue 3 + TDesign + Less；不能直接复制 React 组件源码。
- Vue 侧采用社区的 `shadcn-vue` 落地相同的组件结构、交互与可访问性模式。`shadcn.com.cn` 作为组件选择、组合方式与 API 语义参考。
- 全前端最终迁移到 shadcn-vue；本轮只改复习页，其他页面继续使用 TDesign，禁止在同一页面混用两套组件。
- 配色保持当前 WellRead 视觉语言：品牌绿、浅色容器、8px 圆角；不采用 shadcn 默认灰黑色板。
- shadcn-vue 组件源码复制到 `src/components/ui`，可修改；不引入以组件库全量包形式发布的 UI 依赖。

### 6.2 安装与添加方式

前置：Vue 3 + Vite + TypeScript，`@` 指向 `src`，Tailwind CSS v4。

```bash
npm install -D tailwindcss @tailwindcss/vite
npx shadcn-vue@latest init
npx shadcn-vue@latest add button dialog dropdown-menu context-menu tabs sheet card badge progress table input select tooltip separator skeleton
```

`init` 生成 `components.json`、`src/lib/utils.ts` 与基础主题；`add` 把组件源码写入 `src/components/ui`。

`components.json` 至少确认：

```json
{
  "aliases": {
    "components": "@/components",
    "ui": "@/components/ui",
    "lib": "@/lib",
    "utils": "@/lib/utils",
    "composables": "@/composables"
  }
}
```

使用方式：

```ts
import { Button } from '@/components/ui/button'
import { Tabs, TabsList, TabsTrigger, TabsContent } from '@/components/ui/tabs'
```

只添加实际使用的组件；组件文件就是项目代码，不再封装一次同名薄壳。

### 6.3 Tailwind 与主题映射

- `vite.config.ts` 加入 `@tailwindcss/vite` 插件。
- 首版不全局引入 Tailwind Preflight，避免重置 TDesign 既有页面的基础样式；组件需要的基础重置放到 `src/components/ui` 的局部样式中。全前端迁移完成后再评估是否启用全局 Preflight。
- shadcn 语义 token 映射当前 TDesign CSS 变量，不复制默认主题：

| shadcn token | 当前来源 |
|---|---|
| `--background` / `--foreground` | `--td-bg-color-page` / `--td-text-color-primary` |
| `--card` / `--card-foreground` | `--td-bg-color-container` / `--td-text-color-primary` |
| `--primary` / `--primary-foreground` | `--td-brand-color` / 白色 |
| `--secondary` / `--muted` | `--td-bg-color-container-hover` / `--td-text-color-placeholder` |
| `--border` / `--input` | `--td-component-stroke` |
| `--ring` | `--td-brand-color` |
| `--destructive` | `--td-error-color` |
| `--radius` | 当前 8px 圆角体系 |

- 深色模式沿用现有 `html[theme-mode="dark"]`；shadcn 组件如依赖 `.dark`，在主题切换处同步 class，不新增第二套主题开关。
- 统计页图表用 ECharts，不用 shadcn-vue Chart 组件；图表颜色同样映射品牌 token。

### 6.4 复习 V2 组件范围

- 复习页标签：`Tabs`。
- 卡组右键/悬停菜单：`Context Menu` + `Dropdown Menu`。
- 卡片详情：`Sheet` 或 `Dialog`。
- 列表与状态：`Card`、`Badge`、`Progress`、`Separator`、`Skeleton`。
- 表单与操作：`Button`、`Input`、`Select`、`Tooltip`。
- 质量要求：键盘可操作、焦点可见、暗色/浅色可读、加载/空态/错误态齐全；不用默认 shadcn 配色替代现有品牌色。

### 6.5 迁移验收

- 复习页完成 shadcn-vue 改造后，未迁移页面截图对比无样式回归。
- `npm run type-check`、`npm test`、`npm run build` 通过。
- 浅色/深色、窄屏、键盘操作与控制台错误检查通过。
- 组件目录、主题映射和新增依赖记录在 `frontend/README.md`；完整迁移另立批次，不在复习 V2 内扩散。

## 7. 禁止项

- 不做角色/能力驱动的菜单过滤；菜单固定六项。
- 不新增 `requiredCaps` / `requiredAnyOps` 路由元数据。
- 不在前端计算共享、部门或 ACL 可见性。
- 不在日志/控制台打印 API Key、模型 Key 或敏感配置。
