# 界面规范

> 状态：当前
> 最后更新：2026-11-04
> 目标读者：产品、前端、设计

## 1. 结构

- 登录页：邮箱 + 密码；不含注册、邀请、OIDC。
- 平台壳层：左侧五项导航 + 内容区；无邀请铃铛、空间切换、角色标签与新手运营入口。
- 五项目导航：问答、知识库、精读、技能、设置。
- 登录后默认 `/platform/creatChat`；`/platform/*` 是唯一业务命名空间。
- 设置五分区：账户与助手、模型与引擎、外部接入、系统健康与队列、关于。

## 2. 页面

| 页面 | 关键内容 |
|---|---|
| 问答 | 历史会话、消息流、引用、技能/知识库提及、模型与网络搜索开关 |
| 知识库 | 知识库卡片、置顶、创建/复制/删除、文档列表、处理时间线、分块、代码项目入口 |
| 精读 | 运行列表、计划、三栏工作台、问题卡、笔记、报告与导出 |
| 技能 | 个人技能列表、创建/编辑/启停/删除 |
| 设置 | 账户与助手、模型与引擎、外部接入、健康与队列、关于 |

## 3. 视觉与交互

- 沿用既有 WellRead 视觉语言：浅色容器、品牌绿、卡片化列表、圆角 8px。
- 列表/卡片操作优先图标按钮 + tooltip；破坏性操作需确认。
- 长文档与大列表复用虚拟滚动、分页与 Markdown 渲染管线。
- 流式回答保持滚动跟随；用户上滚时暂停自动跟随。
- 文案不出现公司、部门、成员、共享、ACL、审批、治理、审计等企业概念。

## 4. 设置面

| 分区 | 内容 |
|---|---|
| 账户与助手 | 个人资料、密码、全局系统提示词（可恢复默认） |
| 模型与引擎 | 模型、Ollama、解析器、检索、存储后端 |
| 外部接入 | 单只读 API Key 的查看/生成/重置/删除与调用示例 |
| 系统健康与队列 | 系统信息、运行时队列 |
| 关于 | 个人版定位、版本与组成服务 |

## 5. 状态与空态

- 知识库空态引导创建；最近访问空态引导打开文档。
- 未配置模型时创建知识库可进入向导并跳转模型配置。
- 上传进度在列表页展示；刷新后显示最新解析状态。
- 错误提示区分参数错误、未认证、资源不存在与服务端错误。

## 6. 禁止项

- 不做角色/能力驱动的菜单过滤；菜单固定五项。
- 不新增 `requiredCaps` / `requiredAnyOps` 路由元数据。
- 不在前端计算共享、部门或 ACL 可见性。
- 不在日志/控制台打印 API Key、模型 Key 或敏感配置。
