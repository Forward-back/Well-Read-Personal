# 学习场景与 RAG 需求

> 状态：规划
> 最后更新：2026-11-02
> 目标读者：产品、后端、RAG、前端、测试
> 关联：[个人版需求与范围](../个人版改造/需求与范围.md)、[系统总览](../01-项目总览/系统总览.md)

## 1. 背景

WellRead Personal 主要服务单个用户的学习与资料沉淀，而不是企业知识管理。典型资料包括考研/考证教材与真题、项目学习文档、代码仓库、网页与电子书。RAG 的目标从“带权限的企业检索”转为“个人学习资料的可靠检索与引用”。

## 2. 使用场景

| 场景 | 典型资料 | 需要的动作 |
|---|---|---|
| 考研/考证学习 | 教材、讲义、真题、错题笔记 | 按章节/知识点检索，解释概念，生成复习卡片与自测题，引用可回原文 |
| 项目学习资料 | 项目文档、教程、会议记录、网页 | 按项目聚合检索，跨资料问答，提炼要点与决策 |
| 代码项目沉淀 | 本地代码目录、Git 仓库、README/设计文档 | 按文件/函数/类/模块检索，解释实现，定位行号，沉淀设计决策 |
| 通用阅读资料 | 网页、文章、电子书、说明书 | 全文检索、带引用问答、主题聚合 |

### 2.1 代码入库方式

- 支持本地目录与 Git 仓库作为来源，由 App 扫描/拉取。
- 需要可配置忽略规则（构建产物、依赖目录、二进制、密钥文件）。
- 支持按提交或文件哈希做增量同步；删除的文件从索引移除。
- 代码分块优先按函数/类/模块边界，保留仓库、文件路径、语言、符号名与行号范围。

## 3. RAG 职责边界

### 3.1 RAG 负责

- 索引构建与持久化（向量、关键词、元数据）。
- 文档/代码块的入库、更新、删除与幂等 upsert。
- 检索与融合：向量召回、关键词召回、元数据过滤、重排。
- 返回带定位信息的证据：文档 ID、知识库、页码/章节（文档）或仓库/路径/符号/行号（代码）。

### 3.2 App 负责

- 文件解析：PDF、DOCX、Markdown、TXT、XLSX、网页等。
- OCR（如有需要）与文本清洗。
- 文档分块与代码感知分块：标题层级、段落边界、函数/类边界、行号范围。
- 生成稳定 chunk ID、来源元数据与增量同步计划。
- 精读、复习卡片、自测题、主题聚合等上层生成逻辑。

RAG 不再自带 PDF/DOCX 解析器、领域分块器或 OCR；入库请求必须携带 App 已生成的 chunks。

## 4. 功能需求

### 4.1 文档入库

1. App 解析文档并生成 chunks，每块包含：chunk_id、顺序、文本、章节路径、页码（可得时）、来源文件、类型。
2. RAG 只做校验、索引与持久化；重复推送同一 document_id 时替换旧版本。
3. 元数据过滤支持：知识库、来源类型（文档/网页/代码）、项目/仓库、语言、标签、时间。

### 4.2 代码入库

1. App 扫描仓库并输出代码块：repo、commit、branch、path、language、symbol、symbol_type、start_line、end_line、content。
2. 分块优先落在函数/类边界；超长函数按行窗口切分并保留符号与行号。
3. Markdown/README 与代码文件分开标记，检索时可只查文档或只查代码。
4. 删除/重命名文件与历史提交清理需要同步更新索引。

### 4.3 检索与引用

1. 默认跨全部知识库检索，可限定单个知识库或单个项目/仓库。
2. 回答必须可定位：文档引用带文件与章节/页码；代码引用带仓库、路径、符号与行号。
3. 支持代码符号检索：按函数名、类名、模块名、路径精确或模糊匹配。
4. 支持跨资料主题聚合：同一主题下按来源类型、项目、时间组织证据。

### 4.4 学习输出（上层能力）

- 复习卡片/自测题：RAG 返回证据，App 生成题目与答案并保留引用。
- 代码解释/改动影响：按符号与调用关系组织证据。
- 学习路线/决策记录：跨资料聚合，标注来源与时间。

## 5. 运行约束

- 学习资料与索引保存在本地，不主动上传外部；生成阶段允许调用已配置的云端模型。
- 模型与解析器可配置；本地 embedding 与云端生成可混合。
- 单机 Docker 部署，数据目录可备份、可迁移。

## 6. 非目标

- RAG 内不再实现文件解析、OCR、领域分块与企业权限过滤。
- 不在本轮重做向量算法或索引结构；先完成职责拆分与代码感知入库。
- 不保留部门、角色、密级、ACL 或共享语义。

## 7. 验收

1. 从根目录 `data/` 选取一个文档完成入库与检索，回答带可定位引用。
2. 选择一个本地代码目录或 Git 仓库完成增量入库，能按符号/路径检索并返回行号。
3. RAG 镜像内不存在 PDF/DOCX/XLSX 解析与分块入口；入库请求缺少 chunks 时拒绝或明确报错。
4. 删除文件后重新同步，检索不再返回已删除块。
5. `cd rag && python -m compileall -q src` 通过；后端 `go build ./internal/...` 通过。
