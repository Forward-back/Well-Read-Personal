## 6. 归档规则

- 归档文件保留原貌，不按当前账号/路径/命名重写；需要时加“历史快照”说明。
- 归档内部的旧链接可能指向已删除文件或迁移前路径，只作追溯线索，不做当前导航。
- 不把密钥、真实文档、员工个人信息放进归档；迁移前已清理的凭据不在此恢复。
- 当前有效文档只放 `01`–`03`、`05`、`06`；`04` 不参与日常导航。
- 历史代码快照不再放入 `docs/`；需要追溯时使用 git 历史。
- 归档新增时更新本索引；删除归档需确认无追溯需求。
