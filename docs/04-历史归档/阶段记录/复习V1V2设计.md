## 1. 首轮实施切片（V1）

1. 数据模型与迁移：卡组树、复习卡、卡片来源、复习记录；PostgreSQL 与 SQLite 基线。
2. 卡组与卡片服务：树 CRUD、卡片 CRUD、移动、暂停/恢复、删除处置；接口与单测。
3. 调度与队列：三档 SM-2、日界、全局上限、卡组子树范围、暂停顺延、连续天数。
4. 查重、吸收与合并：哈希、三元组、向量、跨卡组候选、答案冲突、合并；单测。
5. 生成服务：采样、提示词、输出契约、标签建议、预览与批量入库。
6. 前端：第六导航、卡组树、复习首页、复习流、卡片管理、搜索与筛选。
7. 自测题保存：解析契约、保存弹窗、来源勾选、批量保存、重复对比。
8. 来源重绑与孤儿、卡背图片、统计与薄弱项、导出、浏览器验收、导航规则与文档同步。

## 2. 首轮 MVP 决议（2026-11-14，V1 历史）

首轮目标是把「复习回答里的自测题保存成卡，按三档调度复习」跑成真实闭环，不追求设计文档的全量能力。

### 2.1 范围

首轮包含：

1. 数据模型与迁移：卡组树、复习卡、卡片来源、复习记录；PostgreSQL 与 SQLite 各新增 `000001` 增量迁移，`000000_init` 保持冻结，见 [ADR 0002](../../06-架构决策/0002-保留单基线并新增增量迁移.md)。
2. 卡组与卡片基础管理：树查询、创建、重命名、移动、删除处置；卡片创建、编辑、移动、暂停/恢复、软删除与恢复。
3. 调度与队列：三档简化 SM-2、04:00 日界、每日上限、卡组子树范围、暂停顺延。
4. 自测题保存：复习模板输出稳定结构标记；保存弹窗选择卡组、来源与标签；解析失败提供手动拆分；保存前做查重与吸收。
5. 第六导航「复习」、复习首页、复习流、键盘操作、今日到期角标。
6. 来源基础能力：来源锚点保存稳定 ID、路径/符号/行号与内容哈希；来源失效标记；全部知识来源失效时转孤儿并暂停。
7. 使用安全：最近一次评分可撤销；刷新或重新进入可恢复当前复习轮次；删除卡片可恢复；第一张卡、今日无到期、模型未配置、来源失效均有明确空状态。

首轮不包含，留待后续：

- 从文档或知识库生成卡片、生成预览与批量入库。
- 统计、薄弱项、导出 JSON、合并重复卡、卡背来源图片。
- 填空卡；首轮只做 Q/A。
- 标签重命名、同义合并、向量查重。
- MCP 工具、移动端、推送通知。

### 2.2 去重

首轮实现规范化哈希与字符三元组相似度；题干向量字段、查重接口与后续模型配置保留，但不参与判定。命中后的默认动作仍是「吸收为来源」，用户可显式新建。

### 2.3 自测题结构

复习模板的「自测 2 题」必须带稳定标记，保存时只解析该区块；解析失败不回退为整段自动猜测，而是打开手动拆分弹窗。首轮不增加第二次模型抽取调用。

### 2.4 验收调整

设计文档 §10 的全量验收按首轮范围裁剪：

- 首轮必须验证：保存、查重吸收、三档调度、每日上限、来源失效与孤儿、撤销评分、刷新恢复、删除恢复、空状态。
- 首轮不验收：文档生成、统计、导出、合并、卡背图片、填空卡、向量查重。
- 真实数据验收：不少于 20 张卡，连续两轮复习；删除来源后卡片状态正确；恢复卡片后调度不丢。
- 迁移验收：现有数据库升级到 `000001` 后原知识库与问答数据可读；全新数据库从基线加增量启动成功。

## 3. V2 复习闭环（已完成，2026-11-15）

> 决策记录：[ADR 0004](../../06-架构决策/0004-复习V2自适应稳定性与会话报告.md)。
> 历史说明：本节记录 V2 已交付状态。三档评分、每日 30 张、累计 3 次忘记自动暂停与 shadcn-vue 复习页已由 V3 取代，见 §15、[ADR 0005](../../06-架构决策/0005-UI组件沿用TDesign并停止shadcn-vue迁移.md)、[ADR 0006](../../06-架构决策/0006-复习V3采用四档评分与漏洞驱动闭环.md)。V3 前后端均已完成，本节整体为历史。

### 3.1 目标

把首轮「系统发什么就复习什么」升级为可控、可观察、可复盘的学习闭环：

- 每日推荐与手动自选并存。
- 每张卡有自己的遗忘速度。
- 每轮复习有会话、可恢复、有报告。
- 单卡可看表现与预警。
- 卡组管理使用右键/悬停菜单。
- 统计页展示趋势、保留率、易忘卡、到期预测与会话历史。

### 3.2 已定规则

- **双模式**：`daily` 每日推荐与 `manual` 自选复习；手动不占每日 30 张额度，单独记录。
- **自适应调度**：初始 stability 10；记住 ×3、模糊 ×1.5、忘记重置 5；`R=e^{-t/S}`，目标保留率 90%，间隔 1–180 天。
- **会话**：保存计划卡快照、三档计数、复习日；刷新可恢复，04:00 后 active 会话过期；同一会话同一卡只评分一次。
- **预警**：连续 2 次忘记或近 5 次忘记 ≥40% 标易忘；累计 3 次忘记自动暂停。
- **卡组**：右键节点新建子卡组/重命名/删除；右键空白新建顶层；悬停「…」入口；删除非空卡组默认移动卡片，可选连带删除。
- **统计**：7/30/90 天切换；评分分布、保留率、卡组排行、易忘卡 Top10、7 天到期预测、连续天数、评分趋势、实际 vs 理论遗忘曲线、会话历史、JSON/CSV 导出；样本不足显示「数据不足」。
- **UI**：复习页迁移到 shadcn-vue + Tailwind，语义色映射现有 TDesign 变量，保持当前配色；旧页面继续 TDesign，禁止同页混用。

### 3.4 当前不包含

- 完整 FSRS/Anki 参数校准。
- 移动端专项、推送通知、社交化。
- 多会话并存不在 V2 范围；全前端 shadcn-vue 迁移方向已由 ADR 0005 停止。

### 3.5 V2 验收

- 手动选择 1–100 张正常卡可开始会话；暂停/孤儿卡不可进入。
- 刷新中途会话可继续；跨日 active 会话过期，历史保留。
- 单卡详情计数、占比、连续忘记、稳定度、历史和预警正确。
- 统计页曲线与数字来自真实日志，样本不足不画假曲线。
- 右键卡组新建/重命名/删除；删除非空卡组默认移动卡片。
- 旧 TDesign 页面在引入 Tailwind 后无样式回归；复习页浅色/深色、窄屏、键盘可操作。

## 4. V1 验收

当前验收以 §12.10 为准；V1/V2 历史验收见[复习 V1/V2 设计历史](../../04-历史归档/阶段记录/复习V1V2设计.md)。

功能：

- 卡组树可建、改名、移动、排序、删除；删除非空卡组按选择移动或删卡，子卡组正确重挂。
- 从复习回答保存自测题为卡片，卡组、来源、引用、标签正确；批量保存给出汇总。
- 重复保存命中时默认吸收，卡组与调度不变；可移动到当前卡组；可强制新建。
- 从文档与知识库生成预览，接受后入库；重复项被跳过或吸收。
- 三档评分按规则推进；忘记卡当轮回出；累计 3 次忘记自动暂停。
- 每日总量上限全局生效；到期超限时不出新卡；按卡组子树复习不重置额度；暂停后到期日顺延。
- 文档删除与代码重同步分别触发来源不可用与重绑；全部来源失效才显示孤儿；会话删除不判孤儿。
- 合并卡片后来源完整、目标调度不变、旧卡不再出现在队列。
- 标签选择器只提供搜索与创建；生成时最多 3 个建议标签；继承标签快照正确。
- 卡背来源图片可显示并回原文。
- 键盘全流程可完成一轮复习；导出 JSON 含卡组树与调度状态。

验证：

- 调度器单测覆盖等级推进、模糊半数、漏答暂停、日界、全局上限与暂停顺延。
- 查重单测覆盖哈希、三元组、向量、跨卡组吸收、答案冲突与合并。
- 生成契约校验、来源白名单、标签上限与批量入库有单测。
- 浏览器完成 4.1–4.4 全流程，控制台 0 错误。
- 后端全量测试、前端 type-check/测试/build、镜像重建通过。
- PostgreSQL 与 SQLite 基线同步更新。

质量度量：

- 预览接受率、每日完成率、7 日保留率、孤儿率、重复吸收率按第 2 节目标观察，首轮用真实数据记录。
