# 演示指南

> 状态：当前
> 最后更新：2026-11-04
> 目标读者：使用者、演示者、测试

## 1. 准备

```bash
cp deployments/.env.example deployments/.env
# 填写 DB_PASSWORD、JWT_SECRET、SYSTEM_AES_KEY、OWNER_EMAIL、OWNER_PASSWORD 与模型密钥
mkdir -p data/rag/{Data,models}
docker compose -f deployments/docker-compose.yml up -d --build
```

访问：

- 前端：`http://localhost:6151`
- 后端健康：`http://localhost:6152/health`
- Swagger（非 release）：`http://localhost:6152/swagger/index.html`

## 2. 登录

使用 `OWNER_EMAIL` / `OWNER_PASSWORD` 登录。首次启动会自动建号；没有注册、邀请或工作区选择。

## 3. 演示流程

1. **知识库**：新建知识库，配置模型、解析器与分块。
2. **入库**：上传一份文档，或用「添加代码项目」同步本地目录/Git 仓库；查看处理时间线。
3. **问答**：在问答页选择知识库，提问并展示流式答案与引用；打开引用查看文档/分块。
4. **版本**：编辑文档后查看版本并回滚。
5. **精读**：从文档进入精读，生成计划，记录笔记并导出报告。
6. **技能**：创建技能，在普通问答中选择并展示注入效果。
7. **设置**：查看全局提示词、模型与引擎配置；在外部接入生成单 Key。
8. **MCP**：用单 Key 启动 `mcp/`，调用 `list_knowledge_bases` 与 `hybrid_search`。

## 4. 演示注意事项

- 不要使用真实密钥或敏感文档；演示环境使用独立 `.env`。
- `data/rag/Data` 与模型目录不提交 git；演示前确认挂载存在。
- 首次镜像构建较慢；提前构建好 `gaze-app`、`gaze-ui`、`gaze-ylsw`、`gaze-docreader`。
- Windows 本机后端测试可能因 CGO 失败，演示只依赖容器运行。
- 若使用 SQLite 或本地开发，确认迁移为全新库；旧企业库不兼容。
