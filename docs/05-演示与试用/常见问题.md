# 常见问题

> 状态：当前
> 最后更新：2026-11-04
> 目标读者：使用者、运维、测试

## 启动与登录

### 启动报 owner 配置错误

必须配置 `OWNER_EMAIL` / `OWNER_PASSWORD`，且密码满足复杂度要求。缺失或不合规时 app 会直接退出，这是预期行为。

### 登录后没有数据

个人版要求全新数据库；旧企业库不能升级。确认 PostgreSQL 卷是新库，并已执行单基线迁移。

## 知识库与入库

### 文档一直解析中/失败

查看处理时间线；确认 docreader 容器健康、文件格式受支持、解析器配置正确。失败文档可重试解析或删除后重新上传。

### 代码项目同步失败

本地路径必须位于 app 容器可访问的挂载目录；Git 需要容器内可访问仓库地址与分支。依赖目录、隐藏目录、二进制、密钥文件与超过 1MB 的文件默认跳过。

### 检索结果为空

确认文档已解析完成且未归档；确认 ylsw `/ingest` 已收到 chunks（RAG 不再自行解析文件）；检查 `data/rag` 挂载与索引状态。

## 问答与精读

### 回答没有引用

检查知识库是否选中、文档是否可检索、模型是否支持当前流程。引用由 app 与 RAG 返回，不应由客户端拼造。

### 精读无法开始

确认文档可用且未在回收站；精读固定使用 `grill-with-docs`，不使用普通问答技能。模型或 token 预算不足时会提前停止。

## 外部接入

### MCP 返回 401/403

确认 `WELLREAD_API_KEY` 是设置页生成的单只读 Key，且未被重置。写工具、模型工具、租户与共享空间工具已从 MCP 删除。

### 网络传输启动失败

SSE/HTTP 必须设置 `MCP_SERVER_AUTH_TOKEN`；客户端需发送 `Authorization: Bearer <token>` 或 `X-MCP-Auth-Token`。

## 部署与数据

### 端口冲突

修改 `FRONTEND_PORT` / `APP_PORT`；ylsw、postgres、redis、docreader 只在 Docker 内网。

### 如何备份

至少备份 PostgreSQL 卷、`data-files` 卷与 `data/rag/`（Data、models、faiss_index.bin）。外部 MySQL 只承载 RAG chunks/Text2SQL。

### 能否修改项目名

不能随意改 compose 项目名 `app`，否则会创建新卷，表现为数据库与上传文件“消失”。

### Windows 本机测试失败

duckdb 静态链接与 gojieba CGO 在 Windows 可能失败，以 Linux 容器测试结果为准。
