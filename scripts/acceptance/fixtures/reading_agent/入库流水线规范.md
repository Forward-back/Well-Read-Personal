# 阅读评测：入库流水线规范（虚构）

> 本文是精读引擎评测用虚构文档，不是产品或业务需求，只用于测量精读链路。

## 1. 范围

本规范描述阅读评测系统的文档入库流水线，包括批次、重试、删除、幂等与对账。不描述解析器实现，也不涉及模型选型。

## 2. 批次与重试

分块按批推送，每批最多 200 个分块。嵌入调用失败时最多重试 3 次；3 次仍失败则把该分块标记为 failed，并在每日对账报告中列出，不阻塞其他批次。

## 3. 删除语义

知识库删除时，引擎侧文档必须在 60 秒内级联删除。向量索引不执行物理删除，只标记为不可检索。

累计删除超过 10000 条后，运维必须运行一次索引重建 rebuild，否则检索召回率会持续下降。

## 4. 幂等

同一 document_id 与 version 的重复推送视为幂等：后到的重复请求被忽略，不重复写入。不同 version 的推送以事务替换语义覆盖旧数据。

## 5. 监控与对账

每日 03:30 执行一次全量对账。对账不一致比例超过 0.5% 时触发告警，并要求当天人工复核。
