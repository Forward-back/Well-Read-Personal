# 阅读评测：缓存一致性协议（虚构）

> 本文是精读引擎评测用虚构文档，不是产品或业务需求，只用于测量精读链路。

## 1. 目的与范围

本协议描述阅读评测系统在多区域部署下的缓存一致性要求。适用对象是检索服务与文档服务，不涉及用户权限、计费或对外接口。

## 2. 缓存键与过期时间

缓存键固定为 tenant_id + document_id + chunk_index（租户、文档、分块序号）。键中禁止使用文档标题，因为标题可以随时重命名。

本地缓存过期时间 TTL 为 300 秒。文档更新后，缓存必须在一次请求内失效，不允许依赖 TTL 自然过期。

## 3. 失效流程

文档服务收到更新后，先删除缓存，再写入新版本号。删除失败时最多重试 3 次，避免阻塞写入主流程。

重试间隔没有规定，由实现自行决定。评测要求指出这个缺口。

## 4. 跨区域同步

跨区域副本通过异步复制同步，允许的同步窗口为 ±5 分钟。

为保证副本可用，跨区域缓存 TTL 配置为 600 秒。该值与第 2 节的 300 秒不一致，评测要求把这一冲突列为矛盾。

## 5. 回退策略

缓存不可用时回退到数据库查询。回退最多允许 20 个并发查询，单次回退超时为 200 毫秒。超时后直接返回旧缓存或错误，不无限等待。
